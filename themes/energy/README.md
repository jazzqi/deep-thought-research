# 能源

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

全球能源市场：原油（WTI/Brent）、天然气、能源板块股票、OPEC+ 策略、能源转型 vs 传统能源投资周期。

## 分析框架

- **供需平衡** — 全球原油库存、OPEC+ 产出决策、美国页岩油产量响应
- **地缘溢价** — 中东冲突、俄罗斯制裁、航运通道安全对供给风险的影响
- **能源转型** — 清洁能源投资对化石燃料长期需求的侵蚀速度，但过渡期传统能源仍需 capex
- **通胀传导** — 能源价格对 CPI、货币政策、消费者信心和经济活动的反馈链
