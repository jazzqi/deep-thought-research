# 全球 AI 产业 — 报告结构模板 v1

> 本文件是 `themes/ai-industry/index.md` 的结构蓝本（v1，2026-08-08 冷启动创建）。
> **读者定位**：专业宏观/跨资产投资人。回答三个问题——
> ① 全球 AI 产业当前处于什么阶段（S-curve 位置/资本开支周期/竞争格局），市场定价了多少？
> ② 哪些驱动因素（训练 vs 推理、模型竞争、应用变现、监管）正在改变产业斜率，上行/下行尾部被低估多少？
> ③ 我该怎么参与（算力/模型/应用/Agent/数据各层），什么信号会推翻我的判断？
>
> **结构 = SEED 顶层节（publish 识别）+ AI 产业层级子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；层级子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许「产业景气速览表」首列用 emoji，正文一律用文字；
> ③ **数字带单位与时间**（`云厂商 capex 指引 2026 全年 $XXXB（2026-08 财报季）`），所有判断给置信度或概率。

## 二、各维度分析 — AI 产业层级子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的层级就写哪些，可合并可增删。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。
>
> **每个层级子节必须回答三件事**：
> 1. **当前状态** — 该层级最值得注意的新证据（带来源与日期，工具查询，不注入数值）
> 2. **产业定位** — S-curve 位置/景气度（渗透率、收入兑现、竞争烈度、单位经济性）
> 3. **投资信号** — 方向判断 + 跟踪指标 + 时间窗口 + 置信度

### ### 算力层 / 基础设施（GPU·ASIC·云 capex）

**覆盖范围**：AI 加速器供需、云厂商资本开支指引、训练 vs 推理算力分配、数据中心电力瓶颈。**主导视角**：tech_generalist + ai_specialist。**上游**：semiconductor/nvda 的 `index.md` 结论，不重复产业链细节。

```
**当前状态：** 一句话（含最新新闻证据与日期）
**capex 周期：** 云厂商/大模型公司资本开支指引（来源与日期）、训练 vs 推理分配
**供需缺口：** GPU 供给紧张度、ASIC 渗透、CoWoS/电力瓶颈对放量的约束
**投资信号：** 算力链 beta 方向 + 跟踪指标（capex 指引、订单能见度、利用率）
```

### ### 模型层 / 前沿大模型

**覆盖范围**：前沿模型梯队竞争（OpenAI/Anthropic/Google/Meta 开源）、Scaling Law 进展、推理成本下降、多模态/Agent 能力跃迁。**主导视角**：karpathy + ai_specialist。

```
**当前状态：** 一句话
**模型竞争：** 前沿能力差距、开源 vs 闭源格局变化、下一代模型发布节奏
**成本曲线：** 推理成本下降速度、单位经济性（对应用层变现的含义）
**投资信号：** 模型层本身难直接投资，关注其对算力/应用两层的传导
```

### ### 应用层 / 变现

**覆盖范围**：企业软件（Copilot/AI 办公）、消费级产品（搜索/助手）、AI 广告、垂直行业（金融/医疗/法律/编程）。**主导视角**：tech_generalist + ai_specialist + munger。

```
**当前状态：** 一句话
**变现验证：** AI 收入占比、ARPU 提升、客户留存、哪些场景真正产生了付费
**竞争与护城河：** 应用层价值分配、大模型厂商 vs 垂直应用的博弈
**投资信号：** 已兑现收入的标的 vs 纯叙事标的的区分（叙事≠订单=blocker）
```

### ### Agent / 工作流自动化

**覆盖范围**：Agentic AI 产品化、多 Agent 协作、企业流程自动化、编程 Agent。**主导视角**：karpathy + ai_specialist。

```
**当前状态：** 一句话
**产品化进度：** 从 Demo 到可交付产品的跨越、可靠性/成本/评估闭环
**渗透信号：** 企业采用率、API 调用量、开发者生态的可观察指标
**投资信号：** 平台型 vs 垂直型 Agent 的机会与风险
```

### ### 数据层 / 基础设施服务

**覆盖范围**：数据标注/合成数据、向量数据库、AI 基础设施软件（MaaS/推理平台）、电力与数据中心。**主导视角**：tech_generalist。

```
**当前状态：** 一句话
**需求驱动：** 数据/算力服务的订单能见度、客户结构
**投资信号：** 基础设施软件化趋势的受益者
```

### ### 监管 / 地缘 / 泡沫风险（跨层级）

**覆盖范围**：AI 监管立法（欧盟 AI Act/美国行政令）、中美 AI 竞争与出口管制、AI 泡沫辩论、就业冲击的宏观反馈。**主导视角**：munger（泡沫）+ dalio（宏观）+ taleb 缺席时 ai_specialist 代管尾部。

```
**当前状态：** 一句话（含最新新闻证据与日期）
**监管动态：** 立法/执法进展（工具查询 news，禁止凭空写）
**泡沫信号：** 估值 vs 收入兑现的缺口、一级市场狂热、叙事强度（引用 market-sentiment）
**风控视角（munger）：** 逆向检查——市场最一致的假设可能是最危险的
```

### ### 其他子节（按需）

**覆盖范围**：中国 AI 生态（DeepSeek/阿里/字节）、具身智能/机器人、AI 能源（核能/电力）等。
**主导视角**：按实际涉及选择。

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / QueryLongbridgeByRouteTool /
  query_indicators），禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- AI 产业状态断言必须有新闻来源支撑（禁止无来源的模型发布/capex 指引断言）。
- 区分「叙事/预期」与「实际收入/订单」：AI 叙事强但必须落到 capex 指引、收入占比、
  ARPU、客户留存等可验证数据（G-01 教训：执笔 agent 必须能访问真实数据）。
- 涉及公司财务的数字必须标注来源工具 + 关键参数 + 日期，记入 reference.md 溯源
  （`- {数据点}: {来源工具}({关键参数}) = {值}`）。
- 判断给置信度或概率；预测给可证伪的触发条件或数值区间。
- 服务资本市场投资决策，不输出政治立场。
