# 市场每日追踪

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

每日全球金融市场简报，为其他 theme 提供市场全景背景。

覆盖：美股、港股、A股、加密、黄金、油价、其他地区。

## 分析框架

- **风险偏好** — 当前 risk-on/off 状态、核心驱动力
- **跨资产联动** — 股票/债券/商品/外汇之间的一致性和背离
- **关键事件** — 当日/本周可能改变 current regime 的事件
- **为其他 theme 提供的上下文** — 市场背景的摘要，供各 theme 的 Lead Agent 引用
