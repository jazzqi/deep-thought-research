# 研究报告书写规范（Writing Guide）

> 主题文档工厂（theme_update flow）所有 agent 输出研究报告的统一书写规范。
> 适用阶段：roundtable 观点征集 / relay 接力写作 / theme_review 交叉审查产出。
> 权威来源：本文件 + THEME_SPEC.md §4（各 phase 的产物约定）。
> 运行时路径：`~/.deep-thought/WRITING_GUIDE.md`（与 `defaults/WRITING_GUIDE.md` 同步）。

---

## 0. 三条总纲

1. **集体署名，个人归属** — 报告是集体作者的产物。共识/结论/综合判断一律用
   **「我们」**；具体某个 agent 的个人观点段必须带归属标注
   `**{agent_id} 视角：**`，**禁止**无署名的「我的判断」「我的观点」等第一人称表述。
2. **简洁准确，关键着墨** — 行文精炼、无废话、无歧义；但在关键判断、
   核心矛盾、数据异常处可以充分展开把逻辑讲透，不因求简而牺牲关键信息。
3. **金字塔原理** — 任何段落/章节都遵循「结论先行 → 分层论据 → 数据/来源支撑」。
   读者 30 秒内应能抓住结论，1 分钟能理解论证，想深挖时能找到数据出处。

---

## 1. 集体署名规则（约束①）

- **共识/集体结论**：用「我们判断」「我们认为」「我们的结论是」。
- **个人观点**：`**buffett 视角：**` 开头（`{agent_id} 视角：`），保留归属。
- **禁止**：`**我的判断：**`、`我的观点是`、`我认为`、`我觉得`、
  `在我看来` 等无署名第一人称表达。
- 引用其他 agent 的观点时保留其原归属标注，不要改写成自己口吻。
- 例外：圆桌讨论过程稿（discussion_log / roundtable/scratchpad）允许
  agent 用第一人称陈述自己的思考，但**最终报告**（index.md / README.md /
  publish_candidate / reports/）必须遵守上述规则。

---

## 2. 简洁准确规范（约束②）

- **一句话原则**：每段先给出可独立成立的结论句，再展开。
- **删废话**：不写「值得注意的是」「众所周知」「总的来说」等空转连接词；
  不重复前面已说过的内容；不堆砌形容词。
- **准确无歧义**：数字带单位与时间（`PE 9.81x（2026-07-27）`）；
  结论用确定词（「下滑」「Miss」「收缩」），避免「可能大概也许」堆叠；
  关键判断明确置信度或前提假设。
- **关键处着墨**：核心矛盾、拐点信号、数据背离处，用足够篇幅把因果链条
  讲清楚（可 2-4 段展开），这是报告的价值所在。
- **篇幅纪律**：观点段一般 200-400 字；单节不超 1500 字；超过即自我精简，
  不要靠堆字数证明工作。

---

## 3. 金字塔原理书写规范（约束③）

### 3.1 结构（自上而下）

```
结论（一句话，段首）
├── 论据 1（事实/数据）
├── 论据 2（事实/数据）
└── 论据 3（事实/数据）
    └── 每条例证标注来源（reference.md 溯源）
```

- 每个 `## / ###` 章节：**结论先行**，标题本身就是结论或问题的答案。
- 论据按重要性/逻辑序排列，互不重叠（MECE），共同支撑结论。
- 数据必须有来源（QueryIndicatorsTool / QueryLongbridgeByRouteTool /
  reference.md 溯源），无真实来源的数字不写。

### 3.2 全文骨架（theme_update 报告）

1. **Big Picture（宏大叙事）** — 200-400 字，回答「这家公司/标的是谁、
   核心业务、商业模型、当前核心矛盾」。
2. **共识** — 3-6 条多 agent 一致结论（标「共识」，用「我们」）。
3. **各维度分析**（叙事/情绪面、基本面、宏观背景）— 每维度：结论 → 论据 → 数据。
4. **分歧地图** — 观点 A/B 带 agent 归属（`agent_id: 观点`）。
5. **重大事件与深度报告**（如适用）— 事件结论 → 影响链 → 数据。
6. **预测时间线** — 结论式条目 + 数据支撑。

### 3.3 段落级写法

- 首句给结论（「Temu 本地化方向正确但时机不佳，因为…」），
  不要铺垫背景再绕到结论。
- 数字结论优先量化（「净利润 -12.2%（FY2025 vs FY2024）」优于「利润下降」）。
- 因果链完整（因为 A → 所以 B → 影响 C），不跳步。

## 4. 常见违例与修正

| 违例 | 修正 |
|---|---|
| `**我的判断**：` | `**{agent_id} 视角：**` 或并入「我们判断」 |
| `我认为 PDD 被低估` | `我们判断 PDD 当前 PE 9.81x 处于历史低位` |
| `值得注意的是，Temu 增长很快` | `Temu 收入占比 FY2025 已达 X%（数据来源…）` |
| `整体来看，基本面还不错` | `基本面稳健：营收 +10.6%，但利润 -12.2%（FY2025）` |
| 先讲背景再给结论 | 结论前置，背景作为论据后置 |
