# 加密货币 (Cryptocurrency)

> 跟踪区块链技术栈与加密资产市场的结构性演进——从共识机制升级到稳定币基础设施，从 DeFi 流动性层到 institutional onramp 的 S-curve 扩散。这是一个协议层价值捕获与技术采用交织的叙事。

## 范围

**覆盖：**
- BTC/ETH 及主要 L1/L2 资产的价格发现与网络健康度
- 稳定币供应量、流通路径与支付基础设施成熟度
- DeFi 总锁仓价值（TVL）趋势、借贷市场利率、DEX 交易量
- 机构化进程：ETF 资金流、托管基础设施、企业 treasury 配置
- 监管框架演化：SEC/CFTC 执法、MiCA 实施、香港/新加坡政策
- Web3 基础设施：钱包抽象、账户抽象、跨链互操作
- 叙事与情绪：Meme coin 周期、NFT 市场、ZK/模块化/意图中心等技术周期

**不覆盖：**
- 单一矿币或低流动性山寨币的微观交易策略
- 具体的智能合约漏洞审计（属于安全 research scope）
- 纯链上数据科学不关联市场影响的分析

## 核心问题

- **稳定币是否正在成为加密的"杀手级应用"？** — 稳定币总市值、月活地址、汇款/支付流向的变化趋势表明，稳定币可能比"数字黄金"叙事更快实现产品-市场契合。
- **机构采用是线性增长还是 S-curve？** — ETF 流量、上市公司资产负债表、养老金配置的数据是否指示了一个 phase transition？
- **DeFi 在利率正常化后是否回到增长轨道？** — RWA（现实资产代币化）和 LRT（流动性再质押）是真正的产品创新还是叙事驱动？
- **监管是确定性风险还是尾部风险正在定价？** — 不同司法管辖区的监管清晰度对资本流动和技术迁移的影响如何量化？
- **L1/L2 竞争格局是否已经收敛？** — 应用链（AppChain）和模块化区块链是提高还是降低了 Layer 2 生态的整体护城河？
- **加密资产定价的边际驱动因子是谁？** — 宏观流动性（Fed 政策）、技术叙事（ZK/并行 EVM）、还是散户情绪（Meme/Cex 上币）？
- **Web3 用户增长的真实留存率是多少？** — 排除空投 farming 后的 DAU retention 曲线能反映真正的 product-market fit 吗？

## 数据源

- **CoinGecko / CoinMarketCap** — 全局市场数据、交易量、衍生品持仓
- **DeFiLlama** — TVL、DEX volume、yield 市场全景
- **Dune Analytics / Glassnode** — 链上指标、地址行为、资金流追踪
- **The Block / Messari** — 机构级研究报告、资金流、投资融资
- **稳定币供应链（链上 + CEX 快照）** — USDT/USDC/Dai 供应量、交易频次、交易所净流入
- **ETF 日频数据** — IBIT/GBTC/FBTC 等 ETF 净流入/流出、AUM
- **监管日历** — SEC 听证、FOMC 表述、各国政策文件
- **Funding rate / OI 数据** — 永续合约资金费率、未平仓量、清算级联

## 技术框架

本主题的分析采用三层框架：

1. **基础设施层 (Infrastructure Layer)** — 共识协议、L1/L2 可扩展性、跨链通信、隐私技术。核心问题是：技术瓶颈被清除了吗？下一个瓶颈在哪？
2. **中间件/协议层 (Protocol Layer)** — DeFi 原语、借贷市场、AMM、稳定币机制、预言机。核心问题是：协议层的价值捕获是否可持续？
3. **应用层 (Application Layer)** — 支付、游戏、社交、RWA 代币化。核心问题是：哪个垂直领域正在跨越早期采用者鸿沟？

> 每一层都经历"技术突破 → 过度预期 → 幻灭低谷 → 实质性采用"的 cycle。判断各层在 cycle 上的位置是 theme 的核心分析任务。
