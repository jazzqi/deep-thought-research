# 半导体产业链 — 报告结构模板 v1

> 本文件是 `themes/semiconductor/index.md` 的结构蓝本（v1，2026-08-08 冷启动创建）。
> **读者定位**：专业宏观/跨资产投资人。回答三个问题——
> ① 半导体周期当前处于什么位置（库存/产能利用率/capex），市场定价了多少？
> ② 哪些驱动因素（AI 需求、地缘重塑、技术节点）正在改变景气度，上行/下行尾部被低估多少？
> ③ 我该怎么参与（龙头/设备/存储/代工/产业链 beta），什么信号会推翻我的判断？
>
> **结构 = SEED 顶层节（publish 识别）+ 产业链子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；产业链子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许「景气度速览表」首列用 emoji/国家，正文一律用文字；
> ③ **数字带单位与时间**（`TSMC 3nm 产能利用率 85%（2026-08）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← 半导体周期总判断（宏大叙事，200-400 字，结论先行）
## 共识                 ← 3-6 条共识 + 少数派（relay 最后一人维护）
## 各维度分析            ← ★ 唯一大容量节：按产业链环节组织（下挂 ### 子节）
## 预测时间线            ← 6 列表格（可证伪预测，只追加不修改）
## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
## 更新日志              ← publish 自动维护，无需写
```

> **重要**：`## 各维度分析` 是唯一大容量内容节。所有产业链分析写在这里的
> `### 子节` 中。**不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。

## 二、各维度分析 — 产业链子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的环节就写哪些，可合并可增删。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。
>
> **每个产业链子节必须回答三件事**：
> 1. **当前状态** — 该环节最值得注意的新证据（带来源与日期，工具查询，不注入数值）
> 2. **景气度定位** — 周期位置（库存消化/补库、产能利用率、capex 强度、价格/ASP 趋势）
> 3. **投资信号** — 方向判断 + 跟踪指标 + 时间窗口 + 置信度

### ### 逻辑芯片 / 设计（AI 计算与通用计算）

**覆盖范围**：AI 加速器（GPU/ASIC）、CPU、定制芯片、云厂商 capex 传导。**主导视角**：tech_generalist + ai_specialist。

```
**当前状态：** 一句话（含最新新闻证据与日期）
**需求视角（ai_specialist）：** AI capex 周期位置——训练 vs 推理需求占比、云厂商资本开支指引
**产业视角（tech_generalist）：** 产品周期——Blackwell/下一代节点 adoption、ASIC 对 GPU 的替代
**财务视角（如有数据）：** 龙头收入/指引、毛利率趋势（QueryLongbridgeByRouteTool 查询）
```

### ### Foundry / 代工

**覆盖范围**：TSMC/Samsung/Intel Foundry，先进制程产能利用率、定价、客户结构。**主导视角**：tech_generalist。

```
**当前状态：** 一句话
**产能利用率：** 先进 vs 成熟制程分化（有数据写区间，无则标注「数据缺失」）
**定价与客户：** 代工涨价/降价信号、大客户（NVIDIA/Apple/AMD）订单能见度
```

### ### 存储 / HBM

**覆盖范围**：DRAM/NAND 价格周期、HBM 供需、三星/SK 海力士/美光。**主导视角**：soros + tech_generalist（周期弹性最大环节）。

```
**当前状态：** 一句话
**价格周期：** DRAM/NAND 合约价与现货价趋势（现货市场通常领先合约 1-2 季度）
**HBM：** 供给受限 vs 需求爆发、三星认证进度、定价与毛利率弹性
```

### ### 设备 / 材料

**覆盖范围**：ASML/LAM/AMAT/KLA、光刻机出货、晶圆厂 capex 指引、国产替代。**主导视角**：tech_generalist + soros。

```
**当前状态：** 一句话
**capex 强度：** 全球晶圆厂 capex 指引（含美国 CHIPS / 日本 Rapidus / 欧洲 Intel 扩产）
**设备订单：** 龙头新接订单/积压订单趋势、中国占比（制裁影响）
```

### ### 地缘 / 出口管制 / fab 布局重塑

**覆盖范围**：美国对华出口管制、CHIPS 法案落地、台海风险溢价、日本/欧洲 fab 复兴。**主导视角**：taleb（尾部）+ soros（宏观）。

```
**当前状态：** 一句话（含最新新闻证据与日期）
**管制动态：** 出口管制升级/豁免进展（工具查询 news，禁止凭空写）
**台海风险溢价：** 供应链多元化进度、保险/库存/客户行为的可观察信号
**风控视角（taleb）：** 尾部情景——若 fab 集中地断供，资产影响与对冲
```

### ### 其他子节（按需）

**覆盖范围**：先进封装/CoWoS、汽车/工业半导体、国产替代（中芯/华虹）等。
**主导视角**：按实际涉及选择。

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / QueryLongbridgeByRouteTool /
  query_indicators），禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- 地缘状态断言必须有新闻来源支撑（禁止无来源的冲突/管制升级断言）。
- 涉及公司财务的数字必须标注来源工具 + 关键参数 + 日期，记入 reference.md 溯源
  （`- {数据点}: {来源工具}({关键参数}) = {值}`）。
- 判断给置信度或概率；预测给可证伪的触发条件或数值区间。
- 服务资本市场投资决策，不输出政治立场。
