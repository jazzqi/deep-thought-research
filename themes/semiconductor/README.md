# 半导体产业链

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

半导体全产业链周期跟踪：逻辑/存储/HBM 景气度、foundry 产能利用率、设备 capex、地缘对 fab 布局的重塑。

## 分析框架

- **周期定位** — 库存消化 vs 补库、资本开支强度、产能利用率的位置
- **地缘重塑** — 美国 CHIPS 法案落地、台海风险溢价、日本/欧洲 fab 复兴的实质进展
- **技术节点** — 先进制程（3nm/2nm/GAA）的演进速度和客户 adoption

- soros（宏观周期对半导体需求的影响）
- taleb（地缘 fab 布局的尾部风险审查）
