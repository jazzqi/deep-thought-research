# Tesla

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

Tesla 在电动车、自动驾驶和机器人三大赛道中的竞争地位、利润率演变、产量/交付趋势、估值驱动力。

## 分析框架

- **EV 竞争** — 全球 EV 渗透率曲线、中国市场竞争烈度、价格战对 margin 的侵蚀
- **自动驾驶** — FSD 技术进展、监管审批里程碑、robotaxi 商业化时间表
- **机器人** — Optimus 的技术突破和产业化路径（远期期权）
- **估值驱动力** — 当前市场在给 Tesla 的哪部分折现（汽车利润？FSD？机器人？）
