# 量子破密倒计时 2030、开源权重将吃下 75-90% 的 token、SaaS 走向大整合 —— Arvind Krishna & Nikesh Arora · All-In Podcast · 2026-10-21


> **总览**
>
> IBM CEO Arvind Krishna 与网络安全厂商 CEO Nikesh Arora 把三条看似独立的叙事拧成一条链：量子计算机将以 2030 年为中点击穿今天的密码体系——这是既定现实而非假设，而后量子密码迁移"已经晚了 3 年"；在量子到来前的窗口里，AI 已把网络战改造成"攻击者只需一个漏洞、防守者必须补全全部"的不对称战争，军备竞赛因此无人能停，唯一不需要全球共识就能生效的约束是产品责任；承载这场战争的软件产业本身，则被开源权重模型的 40 倍成本优势推垂直栈对抗与供应商大整合。
>
> 全集最锋利的数字反差有两组：前沿模型生成约 $20-50/百万 token，而用中国开源权重模型 Kimi-K3（约 8000 亿参数）自跑 GPU、一周工程优化即可压到 $1-2——便宜 10-40 倍且完成 95% 的工作，Arvind Krishna 据此判断 75-90% 的 token 使用将流向开源权重；另一端，全球约 $5 万亿 IT 基础设施无法在一年内重建，而企业年度 IT 预算中约 50% 仍花在非量子安全设施上。
>
> 可迁移框架有两个：战争制胜三技法——联盟共享漏洞、让防守便宜到对称、单侧技术优势（IBM 的目标是第三者）；垂直栈利润搬迁论——控制整条栈的人决定哪一层被商品化、把利润在层间搬家，这解释了 IBM 六十年大型机与 NVIDIA 生态资助的同构逻辑。

## TL;DR

1. **量子迁移必须今天开始**：2030 中点击穿现有密码是"现实而非假设"，IT 栈无法一年重建，按 2030 排期等于已晚 3 年。
2. **75-90% 的 token 将归开源权重**：40 倍成本差 + IP 自主权 + 地缘三重驱动，中西开源模型差距最多 6-12 个月。
3. **AI 攻防不对称性锁死军备竞赛**：攻击者只需 1 个真漏洞、防守者需补全全部，中西无人会停手，监管落点是产品责任而非停工协定。
4. **SaaS 走向大整合**：企业平均 500-5000 家软件供应商将收敛到 5-10 个主平台，交互密集型软件被 AI 替代、10⁻¹⁵ 可靠性场景除外。
5. **算力分化是供给问题不是价格问题**：离中美"震中"越远越拿不到算力；资本与劳动的历史循环中，重资本者此前 7-8 个周期全胜。

## 核心论点（金字塔：结论 → 论据 → 理解）

### 论点 1：量子破密时间线已锁定 2030 中点，防御迁移晚了 3 年——今天就该换量子安全基础设施
- 论据：DARPA 的量子基准挑战赛（Quantum Benchmarking Initiative, QBI）从数百家参赛公司筛到约 13 家；建成时间争论在 2028/2029/2033 之间，取中点 2030——"它将击破今天的密码学，这不是假设，是现实"。后量子密码的理论、代码早已齐备，只是"人们太懒没去用"。Nikesh Arora 测算：全球约 $5 万亿 IT 基础设施不可能在一年内重建，现场每家公司年度 IT 预算数亿美元、约 50% 花在非量子安全设施上；过渡手段是现在就用后量子密钥包裹流量。
- 理解：迁移时钟不归企业自己管——攻击者今天偷走加密硬盘、囤五年再解密的"先收割后解密"模式，让"等量子成真再迁移"的方案从第一天就失效。

### 论点 2：开源权重将吃下 75-90% 的 token 使用，这是经济学、IP 与地缘的合流而非单纯价格战
- 论据：Arvind Krishna 给出三重驱动——① 经济学：前沿模型 $20-50/百万 token，Kimi-K3 自跑 GPU 一周优化降到 $1-2，便宜 10-40 倍且完成 95% 工作；② IP：思维链被第三方捕获、记录、审计即泄露商业秘密，而前沿模型没有一家允许私有部署，只能回到开源权重；③ 地缘：最好的开源权重模型今天来自中国（沙箱自跑风险小、云上调用另当别论），但西方 1-2 年内会出现同等能力的开源模型，差距最多 6-12 个月。Nikesh Arora 补充任务分层：端点流量检查每端点每年仅 $20-25（机器学习在边缘跑 20-40MB 载荷、准确率 99.9%），把全部流量换成前沿模型 token 是"给 OpenAI 送一年收入"；只有遭遇十亿美元级 breach 或做药物发现时客户才不计成本上前沿模型；实验阶段应放开（其公司 2 万人过去 12-18 个月才刚用上 AI），生产阶段必须加成本闸门，因为"开发者懒，不加控制就用最贵的答案"。
- 理解：剩余 10-25% 的前沿 token 里相当部分是默认惯性而非刚需——这正是"闸门该装在实验转生产那一刻"的原因。

### 论点 3：AI 把网络战锁进不对称陷阱，军备竞赛不可停，责任只能落在产品责任上
- 论据：AI 漏洞发现的真实率约 60-80%、幻觉约 20%（早期版本幻觉率 30%）——攻击者只需 1 个真漏洞，防守者必须找全并修完，模型对攻击者的边际价值天然更高。Arvind Krishna 给出战争制胜三技法：联盟（各公司共享漏洞、可信方统一修补分发）、对称化（让防守便宜到与攻击成本持平）、技术优势（找漏洞、打补丁、划边界让对方成本极高——IBM 的目标）。agentic 代码将优于人类代码：IBM 内部约一半代码由 coding agent 编写且质量更优，因为 agent 自带评测、发布前修完能找到的缺陷——但只能找到"已知如何找"的缺陷，完整验证在输入无限时计算上不可行。停赛不可能：中国、日本、印度不会跟停，"你慢下来正好给我追上的机会"。TSA 类比：飞机诞生时安全从来不是并行建设的，社会对 AI 黑暗面的过度关注扭曲了叙事；造出来就要负责——商业企业收取经济价值即承担产品责任，"是我的 agent 745565 写的"不成立。
- 理解：产品责任把 AI 治理从"全球手拉手"的国际谈判，降维到既有的责任法框架——这是唯一不依赖共识就能生效的约束。

### 论点 4：软件终局是垂直栈对抗 + 供应商大整合，SaaS 终局价值 5-8 年内无法计算
- 论据：企业平均使用 500-5000 家软件供应商，本身即攻击面——"能否把其中 490 家换成 AI 能力、收敛到 5-10 个主平台"意味着 Massive Consolidation，支出随之集中。网络安全重演整合史：Nikesh Arora 早期在 Fidelity 见证 23 个系统 30 年合并为单一 CRM，"客户买 40 个方案自己拼接"将重演同一路径；但网络安全因 Mythos 事件走高的估值会理性回归。应用层栈之争：OpenRouter 式路由层会消失——模型所需内存、上下文越来越大，上下文与记忆无法和推理分离，端到端栈按动作计费（cost per action），个人 agent 用全部上下文、API、连接训练后即成护城河；未来 3 个月每个前沿实验室将全力押注消费级助手概念（此前 6-9 个月试过未成，Facebook 示范后全员跟进），每个 iPhone 应用都要变成无界面（headless）。软件分两类：交互密集型可被 AI 替代，而需要 10⁻¹⁵ 可靠性的数据库查询、零售银行、结账难以替代——且数字孪生要跑数年才敢切换，届时无成本优势。Arvind Krishna 的并购态度：标的"年初很诱人、一个月前不那么诱人，再看几个季度"。
- 理解：上下文与记忆构成迁移摩擦，这就是"栈锁定"的机制——依赖越厚，换栈成本越高，垂直整合的护城河由此自动生成。

### 论点 5：算力分化是供给约束而非价格问题，资本-劳动的历史循环决定国家胜负
- 论据：Nikesh Arora 判断不会出现"有/无"国家分化——技术会便宜到任何经济上可行的企业都用得起；真正的挑战是算力供给集中于两个大国，"离震中越远越拿不到算力，纯属供给约束而非经济原因"，欧洲公司意图再好也可能断供。对话中的历史类比：劳动与资本的权衡在 17/18/19 世纪重演，此前 7-8 个类似周期中重资本者全胜，而两个大国恰恰愿意资本密集、接受劳动重要性下降；死守"每个现有岗位都必须保护"而非"创造替代机会"的社会哲学将决定输赢——岗位置换应被接受，因为它可能带来更好的工作。

## 关键细节

- **量子里程碑时间线**：QBI 数百家→约 13 家；Arvind Krishna 预测 2027 年前有人宣称实现量子纠错（需第三方验证），2027 年有 1-2 家取得非规模化纠错进展；门计算现状约 10,000（对比 iPhone 每分钟数十亿次），每年加一个零 → 2029 年达 1000 万，"会吓所有人一跳"；10,000 物理量子比特约折 200 逻辑量子比特（纠错会摊薄有效容量）。
- **量子 vs AI 破密之争**：某资深 AI 研究者称 AI 模型能先于量子计算机破解密码（本周 OpenAI 数学成果或为早期迹象）；Arvind Krishna 用费曼论点反驳——量子计算机不做算术运算，量子算法在经典硬件上慢 1000-10000 倍，AI 可发现新算法、可证明可行，但拿不到效率收益；经典路径（如素数分布的更好预测器）理论可能，但"10 年破一个密钥，多数人早已安息"，不具实用性。
- **漏洞发现的实战数据**：企业测试 Mythos 类模型的结果约 60-80% 真实、20% 幻觉；即便如此无人敢不经重测就用 Claude Code 打补丁；零数据保留（ZDR）之外，没有一家模型承诺不生成合成数据——"全是后门和逃生舱，你们该去看看"。
- **监管现场**：某资深议员转述——某全球最大公司 CEO 对网络攻击"彻底崩溃"；Q4 或现 50 州数据中心禁令讨论，Arvind Krishna 判断 50 州不可能、30 州可能、"剩下 20 州会搓着手偷乐"；AI 与数据中心监管"由民粹主义而非现实驱动"，时间线从 2022 参议院闭门听证、2023 公开听证到两届白宫反复打转，当前平衡正确但一场选举可翻转。
- **垂直整合谱系**：IBM 60 年代从沙子、晶圆、fab 到机壳全自建——零 IP 泄漏、利润全留栈内，大型机因此存续 65 年；今天 IBM 只差 fab 一项。NVIDIA 是现代同构体：Jensen 从泥土做到大模型、买入 Hugging Face、资助整个生态以防伙伴脱离其垂直栈——控制整条栈者决定哪层被商品化、利润在层间搬迁。
- **SaaS 时点**：非网络安全软件的终局价值难算——AI 正在打破 product-market fit，"哪些软件能活过未来 5-8 年"无从判断；网络安全估值因 Mythos 事件享受的溢价将随支出狂热一起回归。

## Key Takeaways（核心精华）

- **量子迁移的约束是物理时间表而非意愿**：5 年囤密文 + $5 万亿栈无法年建 + 50% 预算仍在非量子安全设施，"等量子成真再迁移"从第一天就失效。
- **开源权重的 75-90% 是三重驱动合流**（40 倍价差、IP 自主、地缘），不是单纯价格战；且中西开源差距只有 6-12 个月——开源不是中国的永久护城河。
- **AI 攻防的不对称性（攻 1 守全）使模型对攻击者边际价值天然更高**，防守方唯一出路是联盟共享漏洞 + 单侧技术优势，而非祈祷对手停手。
- **AI 治理的实际锚点是产品责任而非国际协定**——不需要中、日、欧、美达成任何共识即可生效。
- **算力分化是供给约束**：离中美震中越远越拿不到算力，与价格和意愿无关。
- **10⁻¹⁵ 可靠性是 AI 替代软件的硬边界**（银行查询、结账），且数字孪生数年切换期会吞噬成本优势。
- **垂直栈利润搬迁论可直接复用**：控制整条栈者决定哪层被商品化——IBM 大型机与 NVIDIA 生态是同一逻辑的两代表达。

- **与常见认知的差异**：量子密码迁移的正确排期是"已晚 3 年"，按 2030 安排是错的；AI 不会先于量子破解密码（量子优势必须跑在量子硬件上）；最强开源模型在中国但窗口仅 6-12 个月，地缘判断不应固化；前沿 token 份额中含大量"开发者懒"的惯性而非刚需。
- **待验证问题**：2027 年的量子纠错宣称能否通过第三方验证、门计算是否年增一个数量级（2029 → 1000 万）；75-90% 开源份额目前只是两位 CEO 的判断，无行业统计支撑；50 州数据中心禁令走向（30 州可能）；IBM"一半代码由 agent 写且更优"与漏洞 60-80% 真实率能否跨企业复现。
