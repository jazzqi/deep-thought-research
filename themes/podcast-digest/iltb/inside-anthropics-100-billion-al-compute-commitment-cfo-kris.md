# Inside Anthropic's $100 Billion AI Compute Commitment — CFO Krishna Rao · 2026-05-13

> **总览**
>
> Anthropic CFO Krishna Rao 首次系统披露了公司如何管理其最核心的战略资源——算力。他的核心判断是：**算力采购是公司最重要也最艰难的决策**，买多了会破产，买少了会掉队。为此，Anthropic 构建了一套跨三种芯片平台（AWS Trainium、Google TPU、Nvidia GPU）的灵活调度体系，使同等算力在公司内部发挥出远高于同行的价值。
>
> 最具冲击力的数据是：**Anthropic 的年化经常性收入（ARR）从年初约 90 亿美元飙升至 Q1 末超过 300 亿美元**，四个月增长超过两倍。这一爆发式增长的驱动力正是模型智能的代际跃迁——每一代新模型不仅能力更强，推理效率也显著提升，从而在保持价格稳定甚至降价的同时实现收入倍增。
>
> 本集最可迁移的框架是 Rao 对「算力不确定性锥」的阐述：在指数增长的业务中，微小的周增长率差异会通过复利效应导致截然不同的结果，因此必须以情景规划而非点估计来管理算力投资，并始终保持灵活性以应对指数级变化。

## TL;DR

1. **算力是生死线**：Anthropic 的三大用途——模型开发、内部加速、客户服务——都依赖同一算力池，CFO 每天花 30-40% 的时间管理算力。
2. **三种芯片灵活调度**：Anthropic 同时使用 AWS Trainium、Google TPU 和 Nvidia GPU，并为每种芯片构建了自研编译器，实现了跨平台的工作负载迁移。
3. **前沿智能回报极高**：在企业市场，每一代新模型都能解锁新的 TAM（总可寻址市场），这也是 ARR 从 90 亿飙升至 300 亿+的核心驱动力。
4. **规模定律未见放缓**：Rao 明确表示，从 Anthropic 内部观察，模型的 scaling laws 仍在正常运行，没有减速迹象。
5. **Jevons 悖论效应**：降价 Opus 家族后，客户消耗量不降反增，远超预期，验证了「降价→用量暴涨→收入增长」的飞轮。

## 核心论点（金字塔：结论 → 论据 → 理解）

### 论点 1：算力采购是 Anthropic 最高优先级的战略决策，买多买少都是灾难
- 论据：Rao 表示算力是公司的「生命线」（lifeblood），是所有其他业务的「画布」。买太多会破产，买太少则无法服务客户且无法保持前沿地位。他个人每天花 30-40% 的时间在算力相关事务上。
- 理解：传统企业通常将固定资产视为「沉没成本」，但在 Anthropic 这样的前沿 AI 实验室，算力既是研发燃料又是生产资料——同一块芯片上午跑推理服务客户，下午做模型训练，这种复用模式彻底改变了资本效率的计算逻辑。

### 论点 2：跨三种芯片平台的灵活调度是 Anthropic 的核心竞争力
- 论据：Anthropic 同时采购 AWS Trainium、Google TPU 和 Nvidia GPU，且对这些芯片「可互换使用」（fungibly）。公司为每种芯片平台构建了自研编译器和编排层（orchestration layer），从芯片层级向上定制。Rao 声称 Anthropic 是「所有前沿实验室中最高效的算力使用者」。
- 理解：多平台策略的核心价值在于：降低对单一供应商的依赖风险，同时在不同芯片的性能价格曲线上寻找最优组合——某些芯片适合强化学习，某些适合训练，某些适合高速推理，灵活调度可以最大化每美元的产出。

### 论点 3：「不确定性锥」框架管理指数增长下的算力投资
- 论据：Rao 解释，在指数增长的业务中，微小的周/月增长率差异会通过复利导致结果的巨大差异。Anthropic 在 1-2 年的时间窗口内建模多种情景场景，从未来目标倒推当前需要采购的算力量。他特别提到，即使公司可以将内部员工使用的算力转售获得数十亿美元收入，公司仍选择保留这部分算力以支持长期研发。
- 理解：这是对传统 SaaS「需求预测→按需扩容」模式的彻底颠覆——在指数增长的业务中，线性思维是致命的，必须提前 12 个月锁定算力产能，同时为不同增长情景准备弹性空间。

### 论点 4：前沿智能的回报在企业市场尤其显著，驱动 ARR 爆发式增长
- 论据：Anthropic 的 ARR 从年初约 90 亿美元增长至 Q1 末超过 300 亿美元（四个月三倍+）。Rao 指出，模型智能是多维度的——不仅是「IQ 分数」，还包括长周期任务能力、工具使用、计算机使用、代理任务等。每一代新模型都解锁新的企业用例，客户在测试后大规模投入。净收入留存率（NDR）年化超过 500%，Fortune 100 中有 9 家是客户。
- 理解：企业市场的「前沿溢价」在于：旧模型做不了的任务，新模型能做——这不仅是「更好的版本」，而是「能用 vs 不能用」的质变，因此客户会为新模型支付多倍的 token 消耗。

### 论点 5：Anthropic 正将 AI 深度嵌入自身运营，形成「递归自我改进」飞轮
- 论据：Anthropic 内部 90% 以上的代码由 Claude Code 编写，Claude Code 自身的代码也由 Claude Code 编写。财务团队开发了 70 多个 Claude 技能（skills），月度财务报告（MFR）已实现 90-95% 自动化生成。所有法律实体的法定财务报表均由 Claude 生成，人类仅做审核。首席税务官是公司最大的 token 消费者。
- 理解：这是一个「用 AI 做 AI」的正反馈循环：模型帮助研发下一代模型，模型帮助内部运营提效，提效释放的人力又投入更多研发——这正是 Rao 所说的「递归自我改进」在商业组织中的体现。

## 关键细节

- **算力采购的硬约束**：无法临时采购——「你不能买一吉瓦的算力然后下周就收到」，必须提前规划。
- **三种芯片平台**：AWS Trainium（与 Annapurna Labs 深度合作，影响其芯片路线图）、Google TPU（从第 3 代开始规模化使用）、Nvidia GPU。Anthropic 是唯一同时在三大云平台上提供模型的语言实验室。
- **重大合约**：与 Google 和 Broadcom 签署了 5 吉瓦 TPU 协议（2027 年起），与 Amazon 签署了最高 5 吉瓦 Trainium 协议，总承诺超过 1000 亿美元。
- **xAI 合作**：与 SpaceX 旗下 xAI 的 Colossus 设施（孟菲斯）达成短期算力合作，用于消费端和专业消费端扩张。
- **模型效率迭代**：从 Opus 4.4 → 4.5 → 4.6 → 4.7，每代模型的 token 处理效率都有倍数级提升；在模型代际之间还持续部署效率改进。
- **定价策略**：Opus 家族定价相对稳定，最大一次调整是推出 Opus 4.5 时降价——原因是发现 Opus 级模型「相对于其能力被低估了」，降价后消耗量暴涨（Jevons 悖论）。
- **Mythos 定价**：作为最新最强大的模型，定价较高，但 Rao 表示已从之前的经验中学到——降价反而能带来更高的整体收入。
- **融资历程**：Series D 时公司仅有第一个前沿模型，FTX 正在清算 Anthropic 股份；Series E 关闭当天恰逢 DeepSeek 消息发布，引发市场剧烈波动。
- **Co-work 增长**：Rao 透露，Co-work（Claude Code 的知识工作扩展）的增长速度已超过 Claude Code 在同一时间点的表现。

## Key Takeaways（核心精华）

- **算力管理的本质是「期权定价」**：在指数增长的业务中，算力投资不是简单的固定资产采购，而是在不确定性锥中为不同增长情景买期权——买对了享受复利，买错了可能破产。
- **多平台策略不是「分散风险」那么简单**：跨芯片平台的核心价值在于工作负载级的最优匹配——同一任务在不同芯片上的成本效率可能差数倍，灵活调度能力本身就是壁垒。
- **企业 AI 的采纳是「用过就回不去」的**：500%+ 的净收入留存率说明，一旦企业将 AI 嵌入工作流，token 消耗只会持续增长，因为新模型不断解锁新用例。
- **「降价→增收」飞轮在 AI 领域特别有效**：Jevons 悖论在 token 经济中被放大——降价不仅刺激需求，还因为效率提升使供给端成本下降更快，形成正循环。
- **递归自我改进已从论文概念变成商业现实**：90%+ 的代码由 AI 编写、AI 辅助研发下一代 AI——这不是未来愿景，而是 Anthropic 当前的日常运营状态。

- **与常见认知的差异**：
  - 常见认知认为 AI 公司是「烧钱换增长」，但 Rao 强调算力投资的回报率是 robust（稳健的），且计算逻辑与传统软件完全不同——不能用 SaaS 的「可变成本」框架来理解 AI 实验室的成本结构。
  - 常见认知认为开源模型会快速追赶前沿，但 Rao 明确表示 Anthropic 不区分「开源 vs 闭源」，只看「是否在前沿」，而前沿模型的价值在于解锁传统模型无法完成的任务。
  - 常见认知认为 AI 会取代人类工作，但 Rao 观察到的是「Jevons 悖论适用于劳动力」——生产力提升后，公司反而雇用了更多人，因为工作量永远做不完。

- **待验证问题**：
  - 当算力供给从短缺转向充足时，Anthropic 的「灵活调度」优势是否会贬值？
  - 1000 亿+ 的算力合约承诺是否会成为沉重的固定成本负担？
  - 企业客户的扩散速率（diffusion rate）是否会遇到「组织变革疲劳」的天花板？
  - 规模定律是否真的没有放缓——Anthropic 的判断是否受其作为 scaling laws 论文作者的创始偏见影响？
