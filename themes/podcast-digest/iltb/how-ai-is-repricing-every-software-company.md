# AI 正在重估每一家软件公司 —— Christina Cacioppo（Vanta 创始人兼 CEO）· @ILTB_Podcast · 2026-10-20


> **总览**
>
> Vanta 创始人兼 CEO Christina 用自己公司的亲历给出核心判断：AI 对软件行业的第一波冲击不是技术性的，而是**定价与估值双重重估**——旧 SaaS 的高增长高毛利模型仍是"史上最佳商业模式"，但市场给它的倍数只剩四年前的 1/3 甚至 1/10；而任何按 token 计费的尝试都会让用户直接拿你与 Claude 比价，应用层必然在那场比较中落败。她的应对是：吞下 token 成本、放弃短期毛利，用 agent-first 的产品体验换取留存，把商业化的答案推迟到"部署完成之后"。
>
> 最有冲击力的反差来自两组数字与两个故事。其一，Vanta 增速与毛利俱佳，估值倍数却跌至原来的 1/3~1/4，部分投资人如今直言"只投实验室和爱荷华州的拖拉机（数据中心），中间什么都不投"；其二，公司内部最优秀的团队推进 AI 改造时，最大障碍不是技术而是**"不被允许失败"的心理安全**——他们反复拿传统的"引导安装向导"方案交差，直到创始人拍板"破釜沉舟，让 LLM 路径必须跑通"。而顶级人才的总包 5 年涨了约 10 倍且仍在加速。
>
> 可迁移的方法论有三层：**创始人必须每两周亲手用一遍模型**，否则无法在"我要裁掉全部 SDR"式的狂热面前做出真伪判断；**把 8 年旧代码模块化**是让编码 agent 真正生效的前提（Notion 比 Vanta 早做了约 9 个月）；**安全领域正在被 AI 颠倒优先级**——模型的持久性会把 17 个各自"低危"的漏洞拼成真实攻击链，修复速度必须追上机器，否则一切分级体系失效。Christina 的总结是：AI 开启了一个"高热情、低信任"的时代，而证明"工业级可靠性"本身正在成为最值钱的生意。

## TL;DR

1. **按 token 计费是应用层的陷阱**：用户会立刻拿你与 Claude 直接比价，"你只是把 Claude 的 token 加价转卖"——这个比较应用公司必输；Vanta 选择自己消化 token 成本、接受更低毛利。
2. **SaaS 估值重估是认知失调式打击**：Vanta 这类"高增长+高毛利"企业的估值倍数只剩过去的 1/3~1/4，部分投资人只投 AI 实验室与算力，"中间什么都不投"。
3. **Agent-first 不是加个聊天框，而是让 agent 主动带着成果来找你**：Vanta 的 agent 会自动生成 UI、在获得许可后直接执行操作，目前 25% 客户已进入该流程，目标 75%。
4. **企业 AI 落地的最大障碍是"不被允许失败"**：顶尖且有动力的团队宁可交传统的引导向导方案，也不愿赌 LLM 路径——解法是领导层明确"这条路径必须成，不许回退"。
5. **AI 让安全攻防彻底换了节奏**：模型会不知疲倦地组合 17 个"低危"问题形成真实攻击链，人工的 90 天修复排期体系整体失效——"修复速度赶上机器，就不需要排优先级"。

## 核心论点

### 论点 1：token 计费把应用公司拖进与基础模型的直接比价，必输；正确姿势是先吞成本换部署
- 论据：Christina 形容与客户讨论 token 计价的实况——客户一听就说"你只是把 Claude 的 token 加价了 X，你和 Claude 一样好吗？我试试看"。一旦按 token 报价，应用就被迫与模型同台竞技；用"积分（credits）+ 内部汇率"包装也会被用户识破。Vanta 现在全额消化 token 成本、接受更低毛利，逻辑是：agent 主动替用户做事的体验能带来更好的留存，"这是技术的部署期和使用期，先解决部署，商业化以后再谈"。她的场景（合规决策与执行）token 消耗远低于编码 agent，因此可以优先保质量而非抠成本。
- 理解：问题的本质是 token 计费暴露了应用的价值密度——如果 agent 只是转发模型调用，用户没有理由为加价买单；只有当定价锚定"工作成果"时，应用层的溢价才成立。

### 论点 2：所有人想要成果计价（outcome-based pricing），但"什么算成果"在认知上无法收敛
- 论据：Christina 曾是微观经济学教授，理论上认同成果计价的激励对齐，但实操卡在单位定义：客服关掉一个工单只是"产出（output）"，真正的"成果"是"我的 Sonos 音响修好了"；即便用相对无争议的工单口径，一旦列举可能的工作单元（草稿文档、已关闭通知、已删除账户……她估计还能再举 47 个），用户就要不断追问"agent 做的收费、我自己做的不收费吗"——认知开销本身摧毁计价方案。
- 理解：这解释了为什么行业集体停在"嘴上要成果计价、手上收订阅费"——不是不想，而是成果的可验证边界在 B2B 场景里根本画不出来。

### 论点 3：旧 SaaS 商业模式没变差，是市场把它的倍数砍掉了 2/3 到 3/4——真正的代价在人才战场
- 论据：Vanta 增速比历史上更快、毛利依然很高，正是四年前公认的"史上最佳商业模式"，但估值倍数只剩过去的 1/3 甚至 1/4（对比某些 AI 原生公司高增长低毛利反而拿到 3-4 倍溢价）。Christina 形容这种认知失调：长期看 80% 增速+80% 毛利的生意不输 160% 增速+30% 毛利的生意，但今天后者估值可能是前者的 10 倍。投资人层面出现"只投实验室和爱荷华州拖拉机（数据中心），中间什么都不投"的极端 AI 信仰；人才层面，顶级员工 5 年总包涨约 10 倍且"还在加速"，薪酬带形同虚设，要价能力最强的一批人每半年一次要价（tender）已成行业常态，不给就要用别的东西补偿。她的对策是把公司真实业务数据全部摊开给候选人，用"实数据"对抗"氛围估值（vibes）"。
- 理解：估值折扣本身不致命——真正致命的是估值差通过人才市场变成运营约束：竞争对手用"下个月就有 100 亿美元估值"的叙事抢人，理性的老公司被迫参与非理性的定价游戏。

### 论点 4：企业推进 agent 化，最大敌人是"优秀团队不被允许失败"的心理约束，不是模型能力
- 论据：Vanta 要求提升客户迁移采用率时，一支有动力、有能力的产品团队连续多次产品评审都端出传统的"引导安装向导（四步+进度条+彩带）"方案。Christina 反复叫停："用 LLM，别做向导。"最终摊牌原因令她意外：团队坦承"我们不确定拖拉拖拽迁移能成，向导我们做过、肯定成，这个项目我们不被允许失败。"她拍板"烧掉船只，让 LLM 路径必须跑通"，次日评审团队就交出了新方案。最终产品形态：一块类 Claude 的大画布，客户把混乱的文件、截图拖进去，agent 提问补齐，完成迁移。她的配套方法论：创始人必须每两周亲手用一遍模型，才知道模型强弱边界在哪——否则有人拿着"我做了个 agent 就要裁掉全部 SDR"来找你时，你无法反驳。
- 理解：这是"AI 转型是组织问题而非技术问题"的最生动注脚——约束不是员工抗拒，而是组织对失败的隐性零容忍，让团队系统性退回到已知安全解。

### 论点 5：AI 让安全攻防从"零日漏洞叙事"变成"低危拼图叙事"，修复必须快过人的排期体系
- 论据：Christina 判断，模型攻击者比人类持久得多——人类试 9000 次就放弃，模型能试"九千万亿次"，并在过程中把 17 个各自"严重度低、90 天内修"的良性问题拼接成真实攻击链；她引用 OpenAI 在 RSA 大会关于该现象的演讲（持久性+组合）。这直接颠倒了"重要但低危、先修别的"的优先级体系，而"全部标成关键"同样无意义；唯一出路是"发现多快就修复多快，快到机器速度就不需要排优先级"。Vanta 的对应产品方向：常驻渗透 agent + 配对的修复 agent，先从云配置错误（对标 Wiz 的市场：客户不愿付 15 万美元、但愿付 40-50 美元的中小企业）切入；企业端终端安全仍让位给 CrowdStrike——"关键是选好战场"。她对 Vanta 未来 5 年的单字回答是"扩张（expansive）"。

## 关键细节

- **Vanta 现状**：成立约 8 年，全球约 16,000 客户、5 条产品线；集成 400 余个工具、汇总成"信任图谱（trust graph）"安全数据湖，是其 agent 与自动化的数据底座。
- **Agent 采用进度**：25% 客户已在 agent 主动工作流中，目标 75%；示例场景——员工离职未撤权，agent 现场写好注销脚本问"要我开吗"，再问"要常开吗"。
- **对"AI 公司"标签的自评**：按 1-10 打分"从今以后建公司会有多不同"，Christina 给 8-9 分："原则不变——一切都很复杂、人最重要；但做事方式必须完全不同。"
- **后训练（post-training）被她列为高估**：推理厂商私下说真话——继续训练的动机是成本而非质量；"为客户定制模型"更多是讲给投资人听的营销；类比 2011 年的移动互联网："没人真的想被交付一个模型，就像没人想研究下拉刷新功能。"
- **FTE（全职人力外包）模式被她列为疯狂**：本质上是人才套利的专业服务，只有 Palantir 那种八位数美元合同撑得住；五、六位数合同 + 30% 毛利的旧时代逻辑不可持续，"这套全职人力经济大概率不会长久"。
- **欧洲厂商转向中国模型的真实原因**：她在巴黎见客户得知，巴黎的法国软件公司大量改用中国模型——不是民族主义，而是某美国模型对非美国用户关闭后，企业意识到"业务连续性风险"，决定不再把生意押在美国模型必然可用上。
- **旧代码模块化**：8 年历史代码库必须拆成 agent 可完整理解的小模块，否则编码 agent"会做蠢事"，仍需高上下文工程师 babysitting；Notion 在这件事上比 Vanta 早约 9 个月。
- **广告牌战争（复盘）**：2021 年 SaaStr 期间试水 101/280 交汇处广告牌，PM Sarah 的合规梗文案走红 r/accounting；2022 年市场崩盘时才发现根本没有多年合同、只是一张投放单，位子被一家现金流为正的公司以约 150 万美元年费买走，Christina 开价 300 万美元被拒。
- **她看好/看衰的方向**：看衰 token 计费、为低毛利而低毛利、为营销而后训练；看好网络安全创业潮、AI 时代的销售技术（GTM）工具、机器人（"相对于整个软件业仍被低估"）。
- **宏观侧写**：美国联邦/州/地方政府的现代化预算因 AI 催化的 FOMO 而上桌——CISO 以"AI 与 agent 带来新风险"为由申请企业风险管理预算，搁三年前只会被敷衍。

## Key Takeaways（核心精华）

- **应用层不要按 token 报价**：只要用户能反推"你在模型成本上加价"，你就被拖进与 Claude 的裸对比；要么吞成本换部署与留存，要么锚定成果，唯独不能锚定 token。
- **部署期优先于变现期**：当一项技术处于"先把 agent 装进工作流"的阶段，留存与使用广度的复利高于过早的毛利优化——Vanta 宁可低毛利也要把 agent 流程从 25% 推到 75%。
- **AI 转型的真正瓶颈是组织对失败的容忍度**：聪明、有动力的团队会自发退回已知安全解，因为"没人告诉他们可以失败"——领导层明确"此路必成、不许回退"往往比任何技术投入都见效。
- **创始人必须亲手用模型**：每两周体验一次强弱边界，才能在"一个 agent 就能裁掉整支团队"的狂热提案面前给出真伪判断，这是 AI 时代 CEO 的最低配置。
- **安全的 AI 化正在颠覆"严重度分级"**：威胁从"找零日"变成"组合 17 个低危"，静态排期体系整体失效——能以机器速度修复的一方将获得不需要排优先级的奢侈。
- **与常见认知的差异**：好生意没有变差，变的是倍数——但估值折扣会经由人才市场（5 年 10 倍总包、半年一次要价）变成真实的经营约束；后训练与 FTE 在应用层更多是融资叙事而非价值创造。
- **待验证问题**：消化 token 成本换留存的策略在客户量放大后能否不击穿毛利结构？成果计价是否存在任何可收敛的"工作单元"定义？欧洲对中国模型的"业务连续性切换"是否会蔓延至更多地区并重塑全球模型市场格局？
