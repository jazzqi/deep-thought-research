# AI Token 的供需革命 —— Dylan Patel · 2026-04-23

> **总览**
>
> Dylan Patel（SemiAnalysis 创始人）用自家公司的亲历数据，揭示了一个正在发生的经济结构转变：AI 模型能力的跃升让「实施成本趋近于零」，从此只有「好想法」才值得花 token 去执行。SemiAnalysis 自身的 Claude 年化支出从不到 5 万美元飙升至 700 万美元，占薪资开支的 25% 以上——非技术人员用 AI 写代码、经济学家一个人复刻 200 人团队的产出、能源分析师三周建出竞品十年才有的模型，这些并非概念而是正在发生的事实。
>
> 与此同时，token 需求的增速远超基础设施的扩张能力。Anthropic 的 ARR 从 90 亿美元冲到 400 亿美元以上，毛利率从 30% 多飙升至 72% 以上；GPU 有效寿命从 5 年延伸到 7-8 年，存储芯片价格还要再翻两三倍。供给瓶颈沿着整条供应链传导——从铜箔、光纤到光刻机，层层缺货、层层涨价。
>
> Patel 最核心的判断是：最前沿模型创造的经济价值，增长速度远快于基础设施能服务的 token 数量，这个缺口会持续扩大。对个人和企业而言，"不用更多 token 就永远无法摆脱永久性底层"——不是修辞，而是他在亲身践行的生存逻辑。

## TL;DR

1. **SemiAnalysis 的 Claude 支出已达 700 万美元年化**：占薪资开支 25% 以上，按当前趋势年底将超过 100%——这不是失控，而是 AI 带来的增长远超成本。
2. **实施成本归零后，想法质量成为唯一瓶颈**：过去执行难、想法廉价；现在实施极廉价，只有值得花 token 执行的好想法才能生存。
3. **Anthropic 毛利率已超 72%，且还在扩张**：需求远超算力供给，tier 2/3 实验室也会售罄，token 的稀缺性短期内不会缓解。
4. **DRAM 价格还会再翻两三倍**：存储产能年增仅 20-30%，新增产能最早 2028 年才能到位，需求端通过涨价实现需求破坏来重新分配产能。
5. **Mythos 是两年来最大的模型能力跃升**：相当于 L6 工程师（vs Opus 4.6 的 L4），但 Anthropic 因安全顾虑选择不公开发布，仅限 select 客户使用。

## 核心论点

### 论点 1：AI 让「实施」成本趋近于零，经济结构因此倒转
- 论据：过去执行困难、想法廉价；现在想法和实施都廉价，但实施已经便宜到只有「好想法」才值得花 token 去执行。Anthropic 的发布节奏从 6 个月压缩到 2 个月，OpenAI 同步加速——模型迭代本身也受益于这一倒转。
- 理解：这意味着竞争优势的来源从「能不能做」转向「选对做什么」和「能不能卖出去」。实施能力不再是护城河，判断力和分发能力才是。

### 论点 2：非技术人员用 AI 编码正在颠覆产出结构
- 论据：SemiAnalysis 总裁 Doug O'Laughlin 带领非技术人员使用 Claude Code 编码，拉动全员 token 消耗从每月数千美元飙升。一个前 Intel 工程师用几千美元 token 建造了 GPU 加速的芯片材料分析工具（覆盖铜、钽、锗、钴等全栈有限元分析），此前需要一个完整团队。经济学家 Malcolm 独自完成原本需要 200 人团队一年的工作量，创建了「幻影 GDP」指标体系和覆盖 2000 项任务的全新基准测试。能源分析师 Jeremy 三周内抓取美国全部电厂和输电线路数据，建出的模型在部分维度优于拥有 100 人、十年积累的竞品。
- 理解：关键不在于 AI 能写代码，而在于它把「专业领域知识 + 编程实现」之间的鸿沟填平了——一个懂半导体逆向工程的人，现在可以自己把分析流程自动化，不再需要等待开发团队排期。

### 论点 3：Token 需求增速远超算力供给，实验室毛利率持续扩张
- 论据：Anthropic ARR 从年初的 90 亿美元冲至 400 亿美元以上（截至访谈时点），毛利率从泄漏文件显示的 30% 多飙升至 72% 以上。即使 Anthropic 将 Opus 翻倍定价，大多数用户仍会继续付费，且这仍不足以解决其容量问题。H100 价格持续上涨，GPU 有效使用寿命从行业假设的 5 年延伸到 7-8 年（Hopper 集群正在续约 3-4 年），进一步推高了云层和硬件层的利润率。
- 理解：这不是周期性供需失衡，而是结构性缺口——最前沿模型创造的经济价值，增长速度快于基础设施能承载的 token 供给，这个差距在扩大而非收敛。

### 论点 4：存储芯片和整个半导体供应链面临深度结构性紧缺
- 论据：DRAM 和 NAND 产能年增仅 20-30%（NAND 更低），即使需求信号在 2025 年底已经非常强烈，新增产能最早也要到 2028 年才能落地。DRAM 价格将再翻两三倍，唯一能重新分配产能的机制是通过涨价实现需求破坏。TSMC 今年资本开支 560-574 亿美元，三年后可能达 1000 亿美元——下游供应链（Lam Research、Applied Materials、ASML、MKSI 等）的尾部鞭甩效应将越来越剧烈。铜箔、光纤、激光等上游材料全面售罄，预付款大幅增加。
- 理解：半导体供应链的复杂度和交期已经拉长到「即使立刻决策也要 2-3 年才能释放增量产能」，这意味着涨价不是短期现象，而是一个持续数年的过程。

### 论点 5：机器人是 token 需求的第二条需求曲线，但尚未启动
- 论据：当前机器人模型（VLA 视觉语言动作模型）数据效率低、数据规模无法快速扩展。Patel 预计 6-18 个月内将出现few-shot学习的突破——预训练机器人模型 + 少量示例即可完成任务。软件奇点（software-only singularity）只是短暂阶段，一旦实施成本归零，物理世界的机器人开发也会加速。
- 理解：机器人的 token 消耗目前几乎为零，一旦 few-shot learning 突破，将释放一条全新的、巨大的 token 需求曲线。

## 关键细节

- **SemiAnalysis 支出轨迹**：2025 年底前年化约数万美元 → 2026 年 1 月起急剧攀升 → 签订 Anthropic 企业合同 → 访谈时点年化 700 万美元（此前一周还是 500 万）。薪资开支约 2500 万美元，Claude 占比超 25%。
- **Anthropic 里程碑**：ARR 从 90 亿 → 350-450 亿美元；毛利率从 ~30% → 72%+；Mythos 仅限 select 客户（网络安全用途），定价为普通模型的 5-10 倍；Opus 4.7 发布时明确标注「刻意在网络安全能力上做了降级」。
- **Mythos 能力定位**：2 年来最大的模型能力跃升；Anthropic 内部 2025 年目标是达到 L4 软件工程师水平（Opus 4.6 基本实现），Mythos 已达到 L6 水平。
- **TSMC 资本开支预测**：2026 年 560-574 亿美元 → 2028 年可能达 1000 亿美元。
- **Phantom GDP 概念**：AI 让某些任务的执行成本暴降，产出上升但因成本暴跌导致 GDP 反而理论上收缩——这部分隐性价值无法被现有 GDP 统计捕捉。
- **社会反弹预测**：Patel 预计 3 个月内将出现大规模反 AI 抗议；引用 Pew 调查称 AI 的受欢迎程度低于政治人物；Sam Altman 住宅两次遭燃烧瓶袭击。
- **Ken Griffin 场景**：Patel 假设 Citadel 可能与 OpenAI/Anthropic 签约，每年锁定首 100 亿 token 的使用权，从而在市场中碾压竞争对手——模型的有限供给让率先锁定算力的玩家获得不对称优势。

## Key Takeaways

- **"不用更多 token 就永远无法摆脱永久性底层"**：Patel 明确区分了三个层次——使用 token、用 token 产生价值、从价值中捕获收益。三者缺一不可，否则在模型能力持续飙升、资源向少数人集中的趋势下将被甩开。
- **想法的价值因实施成本归零而被重新定价**：过去一个好想法可能因执行难度高而被搁置；现在唯一的门槛是 token 成本，竞争焦点完全转向判断力——选对方向比做对事情更重要。
- **AI 实验室的毛利率扩张是结构性的而非周期性的**：需求增速远超算力扩张速度，即使 tier 2/3 实验室也会售罄；硬件供应链各环节（GPU、存储、光刻机、铜箔）层层缺货、层层涨价，整个栈的利润率都在扩张。
- **「幻影 GDP」是衡量 AI 真实经济影响的关键盲区**：token 创造的价值在 GDP 统计中系统性被低估——SemiAnalysis 的信息让客户做出更好的投资决策，但这些决策的收益不会被归因到 token 消耗上。
- **存储芯片是当前最被低估的瓶颈之一**：市场普遍认为存储故事已被充分定价，但 DRAM 产能年增仅 20-30%，新增产能最早 2028 年落地，价格还要再翻两三倍才能通过需求破坏重新分配产能。
- **与常见认知的差异**：① AI token 消费并非"用多了就该控制"——Patel 的策略是尽可能多用、尽可能用在最高价值场景上，而非优化成本；② 模型变便宜不会降低总支出——更便宜的模型解锁更多新用例，总 token 消耗反而暴涨；③ GPU 有效寿命远长于行业假设的 5 年，这实际上加剧了供给紧张（旧卡不退役、新卡产能有限）。
- **待验证问题**：① Anthropic 的毛利率能否在 OpenAI/Google 追赶上来后维持 70%+——如果 tier 2 实验室以更低毛利率提供同级服务，价格战是否会压缩利润；② Patel 预测的"3 个月内大规模反 AI 抗议"是否会兑现，以及它对监管和资本投入的实际影响；③ 机器人 few-shot learning 突破的时间窗口是否真在 6-18 个月内，VLA 之外的架构是否已经出现。
