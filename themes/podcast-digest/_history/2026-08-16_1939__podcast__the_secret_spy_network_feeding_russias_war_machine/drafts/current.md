# The Secret Spy Network Feeding Russia’s War Machine —— The Daily · 2026-08-14

> **俄罗斯得以持续发动高技术导弹与无人机袭击，关键不只是绕过贸易禁令，而是把情报机构、第三国转运与日本物流企业编织成了一条可替换的采购网络。**《纽约时报》援引5个西方情报机构的说法称，俄军情局（GRU）设有专门负责规避制裁的“第20局”；其行动人员以俄航等国有机构为掩护，在日本寻找能够购买、报关和转运敏感零部件的商业伙伴。
>
> **日本既拥有俄罗斯急需的高端制造能力，也因反间谍体系分散而成为网络的薄弱环节。**乌克兰调查人员从袭击平民区的导弹和无人机残骸中发现日本部件，并估计俄方武器、无人机和导弹中90%含有日本组件。这是乌方估计而非独立审计结果，但它揭示了制裁有效性取决于出口国执法，而不仅是禁令文本。
>
> **曝光一名间谍能够造成短期扰动，却无法切断供应链。**Maxim Filchenkov在报道发表后离开日本，但第20局可用其他人员接替他；若日本不同时强化反间谍能力、核查物流链及追究企业责任，单点驱逐不会改变网络的经济激励与组织结构。

## TL;DR

1. **制裁规避已被组织化**：GRU“第20局”据称专门负责取得俄罗斯无法自行生产、又受西方限制的高技术部件。  
2. **日本是关键技术节点**：日本的机床、切削和钻孔设备等能力，对俄罗斯制造高技术武器尤为重要。  
3. **第三国转运掩盖最终目的地**：货物可先从日本运往越南或斯里兰卡，再由俄航包机转入俄罗斯。  
4. **物流企业是最脆弱也最关键的一环**：采购者、货运代理、报关文件与最终收货人之间的信息断层，为“我不知道最终去向”提供了操作空间。  
5. **曝光个人不等于瓦解网络**：Filchenkov离境说明公开调查能提高行动成本，但只有系统性执法才能实质压缩俄罗斯补给能力。  

## 核心论点

### 论点 1：俄罗斯高技术武器的持续供给，依赖跨境零部件网络而非本土技术自给。
- 论据：俄乌战争已从近距离堑壕战，转向大量使用自杀式无人机、弹道导弹和远程打击；这些武器需要作为“脑部”的半导体、微芯片及精密制造设备。节目称，俄罗斯自身无法充分制造所需技术。
- 论据：乌克兰军事情报人员会从导弹、无人机残骸中人工搜寻芯片等组件；2024年开始，他们发现相当多的部件来自日本。
- 理解：出口禁令限制的是直接、合法交易；只要俄罗斯仍能获得关键零件和制造设备，其武器生产能力就不会随禁令自动归零。

### 论点 2：GRU通过“第20局”把情报工作嵌入商业供应链，以规避制裁。
- 论据：《纽约时报》调查始于情报线索，随后采访5个西方情报机构；这些机构称，GRU的第20局专职规避西方制裁、走私战争所需技术。
- 论据：Maxim Filchenkov据称是该网络在日本的重要人员，2024年以俄航员工身份开始第二次驻日任期；他掌握日语、俄语和英语。
- 理解：间谍的任务不是亲自把零件带出境，而是识别、联络并维系能够完成采购、运输和文件处理的商业节点。

### 论点 3：第三国中转将受制裁的直运交易拆解为看似普通的多段物流。
- 论据：日本禁止向俄罗斯或俄罗斯企业销售相关敏感组件，俄航也因制裁无法正常飞往日本；网络因而需要日本中间商购买货物，并安排运输。
- 论据：货物可由日本发往越南、斯里兰卡等第三国，再由俄航从当地包机送往俄罗斯。
- 理解：每一段运输都可能拥有表面上合法的目的地与文件，但将各段连起来，才会显露俄罗斯才是最终受益方。

### 论点 4：日本的高端制造优势与反间谍能力缺口，使其成为俄罗斯特别有价值的目标。
- 论据：节目指出，日本不仅生产芯片，也擅长制造机床及切割、钻孔等精密设备；这些设备关系到俄罗斯能否加工和生产武器部件。
- 论据：日本二战后的情报能力曾被战胜国拆解，目前没有统一的对外情报机构，情报职能分散在约5至6个不同政府部门；消息人士称，在欧洲驱逐数百名俄方人员后，数十名俄罗斯间谍转往日本。
- 理解：技术供给能力和低执法风险同时存在时，目标国就不只是零部件来源地，更会成为网络的前沿组织中心。

### 论点 5：企业“疏忽”与明知参与之间，必须通过终端收货人和文件链条加以区分。
- 论据：日本物流企业Proko Air负责人Takehiko Miki承认与俄航、Filchenkov合作，但称仅运输医疗设备和化妆品，并否认运输受制裁物品。
- 论据：他提供的一张经黑色记号笔涂改的发票，在透光后仍可辨认出收货方为俄罗斯制药公司ArPharm；节目称，该公司创始人因与普京关系密切而受到英国、加拿大和澳大利亚制裁。
- 论据：另有两名人士称，Miki曾要求协助运输他承认被禁止出口至俄罗斯的物品；这是对其说法的直接挑战。
- 理解：货运代理并非制造商，确实可能依赖客户文件；但若最终收货人、货物性质和规避路径已出现明显风险信号，“未做尽调”与有意规避之间的界线会迅速变窄。

## 关键细节

- **平民袭击残骸中的日本组件**：2026年5月，基辅一栋住宅楼遭袭，造成24人死亡、其中包括儿童；乌克兰调查人员在毁楼导弹残骸中发现日本部件。节目强调，这些发现来自针对平民目标的袭击，而非通常意义上的前线战场。
- **“90%”的边界**：乌克兰政府估计，俄罗斯武器、无人机和导弹中90%含有日本组件。该数字说明乌方对日本供应链的高度担忧，但节目未提供独立样本、统计口径或第三方核验，应视为乌方判断而非已审计结论。
- **德国的对照案例**：一名乌克兰官员称，战争初期俄方武器中的德国部件占比一度高达20%；乌方向德国预警后，德国很快切断相关供应。该案例支撑的不是“制裁天然有效”，而是执法与政治意愿可迅速改变供应链。
- **俄航的双重角色**：俄航是合法商业航空公司，同时长期被情报界视为俄方人员的掩护渠道；其国有属性使俄罗斯情报机构更容易安置具备商业身份的行动人员。
- **追访与后果**：记者在东京俄航办公室连续3天试图接触Filchenkov，未获回应。报道发表后，日本政府据消息人士称开始调查Filchenkov与Proko Air；Filchenkov则在报道次日离开日本。
- **个人出局后的组织韧性**：Filchenkov的海外行动身份已暴露，难以再从事驻外间谍工作；但节目指出，他可能回俄获得表彰或转入培训岗位，而日本仍有其他俄方人员能够接手原有关系网。

## Key Takeaways（核心精华）

- **制裁的真正战场是终端用途核查，而不是宣布禁令的那一刻。**
- **高技术战争的生产瓶颈往往隐藏在机床、芯片和物流服务等看似普通的民用环节。**
- **把货物转运至第三国并不必然违法，但当货物、收货人和路线共同指向受制裁终端时，风险判断必须穿透形式文件。**
- **情报网络最有效的形态不是秘密仓库，而是利用合法企业的采购、运输与报关能力。**
- **公开调查能让行动人员“烧毁”身份、提高网络成本，却不能替代制度性的反间谍与出口管制执行。**
- **出口管制的效果取决于盟友间执法能力是否存在短板；一个薄弱节点即可削弱整套制裁体系。**
- **对俄罗斯战争能力的评估不能只看武器库存，还要看其持续获得外国零件、设备与商业服务的能力。**

- **与常见认知的差异**：俄罗斯并非必须通过公开采购或直接走私获得技术；其更具韧性的方式是把受制裁采购拆成多个合法商业步骤，并以第三国作为物流缓冲层。
- **待验证问题**：日本对涉事企业和相关人员的调查是否会带来起诉、出口管制升级或制度改革；乌方“90%含日本组件”的统计样本与具体组件类别为何；Filchenkov离境后相关物流路线是否仍持续运作。
