# Global Macro：通胀降温预期尚不足以打开全面宽松交易

## Big Picture

全球宏观交易的核心标的不是单一公司，而是一组由美元、美国国债、实际利率、黄金、工业品和区域风险资产组成的资产体系。其“商业模型”可以理解为货币与财政信用定价：央行通过政策利率和资产负债表影响资金成本，政府通过债券发行把财政支出转化为市场久期供给，企业和居民部门再决定流动性能否转化为信贷、投资与消费。当前主线已从“全球是否同步软着陆”转向“通胀能否持续回落、财政供给是否推高期限溢价、宽货币能否传导至私人部门需求”。美国面临通胀高于目标与财政融资压力并存，中国面临货币总量与信用需求背离，地缘冲突则提供能源与通胀路径上的尾部风险。未来资产表现更可能分化，而不是由“全球同步降息”这一单一叙事驱动。

本主题没有单一公司的营收、利润、估值倍数或分析师一致预期，因此不能虚构公司财务数据。对宏观资产而言，基本面替代变量是通胀、增长、财政融资、信用传导、实际利率和风险溢价；估值则应围绕现金流久期、无风险利率和风险溢价变化展开。当前可验证的核心矛盾是：短端政策利率可能存在下行空间，但长端利率未必同步下降。

## 共识：降温预期是宽松交易的必要条件，但不是充分条件

我们判断，7月CPI公布前，市场对通胀降温的预期不足以单独证明美联储即将转向全面宽松。数据库显示，美国最新可用CPI同比为3.5%，数据日期为2026年6月1日，已经滞后于当前；它只能作为背景，不能替代7月数据。日历显示，美国7月CPI的主要预测为总体同比3.4%、核心同比2.5%、核心环比0.2%，但同一日历中还存在总体同比3.5%的重复预测条目，因此预测本身存在口径不一致，不能把预测值当作已实现数据。

美国7月CPI将通过三条路径影响市场：

1. **高于预期：**若核心CPI环比高于0.2%，或核心同比高于2.5%，且住房、服务等黏性分项重新加速，市场将下调近期降息预期。美元和实际利率倾向上行，长久期国债、成长股、高估值资产及新兴市场承压。若总体CPI上行主要由能源推动、核心通胀未变，冲击可能较短暂，但通胀风险溢价仍会抬升。
2. **符合预期：**总体同比约3.4%、核心同比约2.5%、核心环比约0.2%，只能说明通胀没有明显恶化，不能自动构成强烈宽松信号。若市场此前已经交易通胀降温，符合预期可能出现“买预期、卖事实”；后续方向将由核心服务、就业、财政供给和国债拍卖决定。
3. **低于预期：**若核心环比低于0.2%，且服务通胀同步回落，美元和实际利率下行，长久期债券、成长股和新兴市场资产通常受益。但若低通胀伴随就业和消费快速恶化，市场可能从“宽松利好”切换为“衰退担忧”，不能机械地把低CPI等同于全面风险偏好上升。

纽约联储7月调查计划于8月10日公布，日历中的前值为1年通胀预期3.7%、3年通胀预期3.3%。日历另列出1年黄金涨幅预期前值5.2%，不能与通胀预期混用。通胀预期尚未处于无风险下行环境。真正足以支持美联储明确转鸽的组合，应是核心通胀持续回落、通胀预期稳定、就业和薪资同步降温，而非单月总体CPI下降。

**共识1：**美国CPI低于预期并不等于所有风险资产同步上涨，必须同时观察核心服务、就业、实际利率与通胀预期。

**buffett 视角：**宏观交易最容易犯的错误，是把一个有利数据直接外推成完整的资产上涨链条。CPI低于预期只改变通胀路径的一个变量，资产价格最终还取决于实际利率、财政融资和未来现金流。只有当低通胀降低实际利率、而非由需求坍塌造成，长久期资产才更可能获得持续支持；否则“降息交易”可能只是衰退交易的另一种表述。

## 美国：短端可以交易降息，长端仍受财政供给约束

美国财政部计划于8月11日至13日标售逾千亿美元国债，8月12日将拍卖390亿美元10年期国债，前次高收益率为4.58%。这构成期限溢价上升和全球流动性收紧的潜在催化剂，但在拍卖结果公布前，不能直接认定为系统性风险。

美国最新可用的美联储资产负债表数据为6,748,567.0，数据日期为2026年8月5日；数据库未明确单位和口径，因此只能作为流动性背景，不能据此推导“流动性宽松”或“流动性收紧”的单一结论。

判断供给压力是否转化为市场冲击，应观察三组信号：

- **拍卖定价：**中标收益率相对于拍卖前市场收益率的尾部是否扩大；
- **需求结构：**投标倍数和间接投标者占比是否明显恶化；
- **拍卖后反应：**10年期收益率是否继续上行，并传导至30年期、实际利率、美元融资成本及信用利差。

若CPI高于预期、实际利率走高且国债拍卖需求疲弱，市场可能形成“通胀—实际利率—财政供给”共振，美元融资成本上升，压制全球股票、信用债和新兴市场货币。若CPI低于预期且拍卖需求稳健，说明供给仍可被市场吸收，风险资产可能获得阶段性喘息，但财政赤字和长期期限溢价问题并未解决。

**共识2：**政策利率预期与长端国债走势不能视为同一交易，财政融资供给可能造成短端下行、长端高位甚至上行的曲线背离。

**kahneman 视角：**全球宏观的核心矛盾已从“增长是否软着陆”转向“通胀黏性与财政供给如何重塑利率曲线”。合理的基准情景是政策利率存在下行空间，但长端利率受财政融资、通胀风险和期限溢价约束。若通胀预期下降而长端收益率仍不降，市场应将其解读为财政供给正在取代货币政策，成为利率曲线的主导变量。

**tech_generalist 视角：**市场不应把“降息预期”和“长债上涨”视为同一交易。政策利率下降通常利好短端和高久期资产，但财政持续融资会增加长端久期供给；当财政供给、通胀风险和期限溢价同时上升时，可能出现短端利率下行、长端利率高位甚至上行的曲线背离。对风险资产而言，实际利率比名义降息更关键。

**soros 视角：**长端市场的关键不是财政部“发行了多少债”，而是供给是否改变了投资者对未来通胀、债务可持续性与期限补偿的叙事。一旦拍卖弱、实际利率升、美元融资条件同步收紧，市场反馈会从线性定价转为反身性过程：收益率上升压低资产价格，资产价格走弱又提高融资压力，进一步要求更高期限溢价。因此，CPI与拍卖应作为同一条反馈链观察，而不能分开交易。

## 中国：M2与新增贷款实际值缺失，不能把宽货币当成增长修复

中国7月M2和新增人民币贷款计划于8月10日公布，当前实际值为空。因此，报告不能提前写入具体数值，也不能把市场预测当作已经实现的数据。数据库中最新可用的中国出口和进口数据均为2026年4月1日，且已被工具标记为超过90天过时，不能据此对当前外需趋势下强结论。

交易上应区分货币总量与信用传导：

1. **M2和新增贷款同时改善：**若社融、房地产销售、财政支出和企业融资同步修复，才意味着信用脉冲可能企稳，工业品、亚洲风险资产和人民币资产获得更可靠的增长支持。
2. **M2保持稳定但新增贷款偏弱：**说明银行体系流动性仍在，但居民和企业融资意愿不足。此时中国债券可能受益于宽松预期，商品、周期股和消费资产却未必同步上涨。
3. **信贷弱于预期、美国需求仍强：**中美增长差异扩大，美元相对优势增强，人民币、工业金属及部分新兴市场资产承压。
4. **信贷改善主要来自政府融资：**若居民和民营企业贷款没有同步恢复，则政策支持对私人部门需求和企业盈利的传导应打折扣。

**共识3：**中国货币总量改善只有在私人部门信贷需求、财政支出和企业盈利同步修复时，才能转化为可持续的增长交易。

**dalio 视角：**中国的关键问题不是银行体系有没有流动性，而是流动性能否穿过资产负债表修复、收入预期和投资回报率这几个环节，转化为私人部门信用需求。如果M2稳定而贷款持续疲弱，市场交易的将是“利率下行、增长不足”，而非典型的宽松复苏。

**soros 视角：**中国数据最重要的不是M2绝对增速，而是政策资金是否突破“金融体系—政府部门”的闭环并进入居民与民营企业资产负债表。若政府融资改善而私人贷款不动，债券上涨与股票、商品疲弱可以同时发生；这种背离不是数据矛盾，而是信用传导尚未完成的信号。

## 地缘政治：仍是低概率尾部风险，但验证成本必须降低

截至2026年8月9日，Al Jazeera报道伊朗正寻求走出与美国“既非战争也非和平”的僵局，说明双方仍处于谈判、威慑与局部对抗并存的状态。新闻流同时显示，俄罗斯方面称其边境州遭乌克兰大规模无人机袭击，造成13人受伤。

现有信息尚不足以确认新的能源—通胀冲击已经形成。伊朗局势对油价和通胀的影响，取决于是否出现霍尔木兹航运中断、能源设施受损、保险费率急升或实际出口下降；俄乌无人机袭击则只有在持续打击能源基础设施、港口或运输线路时，才更可能转化为可交易的能源供给冲击。

我们将地缘风险分为三档：

- **基准情景：**外交僵局和局部袭击持续，但能源运输未出现实质中断，油价和通胀风险溢价短期波动后回归宏观数据主导。
- **升级情景：**霍尔木兹通行受限、油轮遭袭、能源设施受损或制裁明显加码，油价、航运费率和通胀预期同步上行，市场转向美元、能源和黄金，长久期债券及高估值风险资产承压。
- **缓和情景：**伊朗与美国谈判取得实质进展，航运恢复，能源风险溢价回落，美元和黄金的地缘避险溢价下降，风险资产重新关注CPI、就业和财政供给。

**共识4：**地缘事件只有穿透至能源运输、保险成本、油价曲线和通胀预期，才应从尾部风险升级为核心宏观变量。

**tech_generalist 视角：**地缘新闻不应只按标题交易，而应采用“事件—运输—价格”的验证链。只有当政治事件改变能源运输或保险成本，并进一步反映到原油期货曲线、汽油价格、通胀预期和实际利率时，才足以从尾部风险升级为宏观主线。在此之前，直接追高能源或黄金的风险收益比并不稳定，但对冲仓位仍有必要，因为关键航运节点的损失函数具有非线性。

**soros 视角：**地缘风险的市场影响具有明显的非对称性：多数新闻不会改变能源供给，但少数事件可能迅速改变航运、保险和库存行为。基准仓位不应建立在“冲突必然升级”上，也不应因当前没有运输中断而忽略尾部风险。更有效的做法是提前定义验证条件，在价格与物流数据确认前控制追涨，在关键节点失守后迅速调整风险预算。

## 近期重大事件与交易含义

当前新闻与日历显示，未来一周的宏观叙事还受到能源、科技和区域政策事件交叉影响，但它们的重要性不同。

第一，8月12日美国CPI和10年期国债拍卖几乎形成同日验证窗口。CPI决定市场对政策路径的重新定价，拍卖决定财政供给是否被吸收；若两者方向一致，利率市场的趋势信号更可靠。若CPI偏弱但拍卖疲弱，则可能出现“短端利率下行、长端收益率不降”的背离。

第二，能源库存数据将为地缘风险提供价格验证。日历显示，8月12日公布截至8月7日当周EIA原油库存变动，前值为增加247.9万桶；汽油库存前值减少164.3万桶。由于这些是前值而非新公布数据，不能据此直接判断当前供需方向，但可作为观察能源市场是否出现供给收紧的背景变量。

第三，日本央行7月会议意见摘要和澳洲联储8月11日利率决议将检验非美央行的政策分化。澳洲现金利率前值和预测均为4.35%，若政策表述继续偏紧，可能支持澳元和区域利率；若明显转鸽，则会强化全球降息交易，但仍需与美国长端供给压力区分。

第四，近期新闻还出现AI产业与半导体事件，包括DeepSeek拟上调API服务定价、DeepSeek-V4-Flash正式版公测，以及黄仁勋相关市场消息。它们可能影响科技板块的盈利预期与估值分化，但目前没有足够的已实现财务数据证明其已经改变全球宏观主线。该类事件应作为成长股内部的结构性变量，而不是直接替代通胀、利率和财政供给分析。

## 观点分歧地图

- **kahneman：**通胀降温预期不足以单独支持美联储宽松；核心服务和就业必须同步走弱。财政供给可能使短端降息与长端高收益率并存。
- **dalio：**全球处于政策与周期不同步的再平衡阶段。美国面对通胀黏性和财政融资压力，中国面对宽货币未充分传导至信贷需求，资产配置应关注利率、美元、黄金与区域增长的分化。
- **tech_generalist：**应优先识别宏观变量之间的背离：CPI回落但长端收益率不降、中国M2稳定但贷款收缩、地缘升级但能源运输未中断。背离比单一数据的方向更能决定交易持续性。
- **buffett：**资产配置应先区分“价格便宜”和“现金流风险下降”。在通胀、实际利率和财政供给尚未形成稳定方向前，不宜因为一次CPI低于预期就扩大所有长久期资产敞口。更稳健的做法是等待数据验证资产价格是否真正获得基本面支持。
- **soros：**宏观市场存在反身性反馈，尤其应重视长端收益率、美元融资条件和风险资产价格之间的相互强化。冲突新闻和单点数据不应机械交易，但一旦验证条件满足，仓位调整速度应快于线性基准情景。

目前没有明确记录显示其他agent不同意上述核心判断，因此不列单独少数派条目。

## 综合结论

我们判断，未来两周的主导链条是：

**美国通胀预期与7月CPI → 美债拍卖需求 → 长端期限溢价与实际利率 → 美元及全球风险资产估值。**

基准情景不是“通胀下降后所有资产同步上涨”，而是政策利率预期可能边际走低、长端利率受财政供给约束、风险资产表现分化。中国信贷数据若显示货币总量稳定但贷款需求偏弱，将进一步证明全球宽松并不等于同步增长修复。伊朗与美国僵局、俄乌无人机袭击目前仍属于低置信度尾部风险；只有当其穿透至能源运输、油价曲线和通胀预期，才应提升为核心交易变量。

宏观资产不存在单一公司的财务报表、估值倍数或分析师一致预期，因此当前不能用公司层面的盈利增长替代宏观验证。对股票和信用资产，应以实际利率、信用利差、盈利预期和融资成本作为基本面替代变量；对债券，应以通胀、财政供给和期限溢价作为估值锚；对黄金和美元，则应同时观察实际利率、地缘风险和全球流动性。

**soros 视角：**当前最值得交易的不是“CPI会不会低于预测”这一孤立问题，而是市场叙事能否自我强化。若核心通胀下降、实际利率回落、国债拍卖稳健，宽松交易具有正向反馈基础；若CPI下降但长端收益率因财政供给上升，或中国M2改善却没有私人信贷修复，则资产背离将暴露叙事的脆弱性。策略上应先等待关键数据确认，再根据价格反馈调整仓位，而不是把单月数据外推成全面牛市或全面衰退。

**buffett 视角：**当前最重要的不是预测某一个数据点，而是坚持“价格—现金流—融资条件”的核验顺序。通胀数据若改善，先观察实际利率是否下降；实际利率若下降，再观察信用和企业盈利是否改善；只有这条链条闭合，风险资产上涨才具有更强的持续性。在数据滞后、部分中国指标缺失、长端财政供给仍待拍卖验证的情况下，我们更适合维持情景化判断，而不是把单月数据外推成全面牛市或全面衰退。
