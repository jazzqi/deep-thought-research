# 全球宏观（global-macro）

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建，其中的数据、事件和核心问题可能已过时。**
> **Agent 在持续接触现实世界的最新数据源，应根据最新信息不断修改更新本文档，**
> **使其及时准确贴合现实世界。不要将本文档当作静态的 ground truth。**

> 以美国、中国为主轴，兼具全球视野。流动性、通胀、就业是核心跟踪变量，同时覆盖情绪面、突发事件、地缘政治和风险厌恶。注重从预期与预期差、产业与信用周期、政府与央行主导经济理念的角度进行分析。

## 范围

**核心覆盖：** 美国和中国宏观经济。这是全球资产定价的两大锚点。
**延伸覆盖：** 欧洲、日本及其他主要市场的溢出效应。
**不覆盖：** 单一资产的微观交易策略（归属对应 theme）。

## 核心跟踪变量

- **流动性** — 央行资产负债表、银行信贷条件、货币市场利率、跨境资本流动
- **通胀** — CPI/PCE 分项驱动力、薪资-通胀螺旋、通胀预期（盈亏平衡、调查）
- **就业** — 非农、失业率、劳动参与率、薪资增速、职位空缺/失业率比率

## 分析角度

- **预期与预期差** — 市场定价 vs 现实数据 vs 央行指引，三者的偏离是最大的 alpha 来源
- **产业与信用周期** — 企业盈利周期、信贷扩张/收缩、违约率、资本开支周期
- **政府与央行主导经济理念** — 财政纪律 vs 财政扩张、通胀目标制的信守 vs 灵活化、产业政策介入程度。经济理念的范式转换比单一数据点更重要
- **情绪与风险厌恶** — 恐慌/贪婪指标、资金流向、波动率结构、尾部风险定价
- **突发事件与地缘** — 战争、制裁、技术封锁、选举/政策突变对宏观路径的冲击

## 数据源

- **央行** — Fed（FOMC声明/SEP/纪要）、PBoC（LPR/MLF/降准）、ECB、BOJ
- **通胀与就业** — BLS（CPI/非农/JOLTS）、BEA（PCE）、中国NBS、PMI分项
- **流动性** — Fed 资产负债表（H.4.1）、RRP、SOFR、TGA余额、中美利差
- **预期** — Bloomberg/调查通胀预期、联邦基金期货定价、互换利率
- **信用** — 投资级/高收益利差、贷款官调查（SLOOS）、违约率
- **情绪** — VIX、MOVE（债市波动）、信用利差、资金流 EPFR、CNN Fear & Greed
