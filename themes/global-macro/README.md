# 全球宏观（global-macro）

> 增长-通胀-政策三元体制的跨国比较与演化。全球宏观是所有资产定价的大背景——经济周期定位、央行体制切换、贸易与资本流动的重构，最终都在这里汇聚为单一系统性判断。

## 范围

覆盖全球四大经济体（美国、中国、欧洲、日本）的周期定位与世界其他主要市场的溢出效应。框架围绕三个维度展开：增长周期（GDP/PMI/就业）、通胀体制（需求拉动 vs 成本推动 vs 结构性）、货币政策周期（宽松/紧缩的异步性）。**不覆盖**：单一资产层面的微观交易策略（这些由具体 theme agent 处理），以及短期高频预测（<2周的交易 noise）。

## 核心问题

- **当前处于什么幅度的全球周期阶段？** ——全球增长是同步放缓还是异步分化？最关键的 regime 特征往往是"分化"而非"共振"，这正是当前的核心主题：中国类滞胀 vs 美国软着陆 vs 欧洲衰退，这种三速世界（three-speed world）的收敛条件是什么？
- **中美宏观大分化（Great Divergence）将持续多久？** ——中国面临通缩性衰退与资产负债表收缩；美国面临粘性通胀与 late-cycle 扩张。这种分化的根源（人口 vs 技术 vs 债务周期阶段）是中期的还是结构性的？对全球资本流出的含义是什么？
- **通胀是暂时性 spike 还是体制性迁移？** ——去全球化、绿色转型、AI 投资结构性地推高了成本，"长期通缩"的叙事是否已经过时？供应链重排（reshoring/friend-shoring）是否永久提升全球价格的尾部风险？
- **央行政策分割（policy divergence）何时收敛？** ——Fed 鹰派观望 vs  中国央行持续宽松 vs 欧洲央行按兵不动。不同步的降息周期将如何塑造全球利差、汇率与资本流动格局？
- **全球债务周期的位置**：Dalio 框架来看，我们现在处于长期债务周期的哪个阶段（积累/去杠杆/正常化）？以 Kondratiev 长波视角，AI 能否带来足以扭转生产率增长下行的"第六波康波"大创新？
- **尾部风险**：中国房地产系统性风险蔓延？欧洲边缘国家主权风险重燃？AI 驱动的私人信贷违约连锁？哪个才是真正的黑天鹅？
- **贸易流的持续重构**：关税与供应链去风险化是否已经永久改变了出口依赖型经济的增长模式？东南亚/墨西哥的"近岸外包"获益能否扛住全球需求放缓？

## 数据源

- **GDP 季调数据（美国 BEA、中国 NBS、欧盟统计局、日本内阁府）** — 增长趋势与产出缺口
- **CPI / PCE / PPI / CGPI 跨国对比** — 通胀驱动力分解（需求 vs 成本 vs 结构性）
- **PMI 全球矩阵（标普/JPMorgan 全球 PMI、ISM、财新）** — 周期拐点的领先指标
- **央行政策声明 & SEP** — Fed/ECB/PBoC/BOJ 的政策路径前瞻
- **国际金融协会（IIF）资本流动数据** — 跨资产资本流的方向与 density
- **全球贸易流量（CPB 世界贸易监测）** — 贸易量的实时 proxy
- **UNCTAD 全球 FDI 数据** — 供应链重组的资本支出映射
- **IMF WEO/Global Financial Stability Report** — 官方预测基线 vs 尾部风险
- **OECD CLI（综合领先指标）** — 跨国周期拐点的标准化比较
- **主权 CDS 利差 & 信用评级** — 主权风险定价及脆弱性筛查

## 关联主题

- **fed** — 美国利率路径是全球宏观的核心变量；Fed 的体制判断（soft landing vs hard landing）决定所有跨资产的 beta
- **energy** — 能源价格是通胀传导链的第一环；OPEC+ 供给对冲与全球增长预期互动形成跨市场反馈
- **us-iran** — 中东地缘风险溢价通过能源成本影响全球通胀与政策空间
- **qqq / semiconductor** — AI 投资驱动的增长分化（中国 vs 美国）是当前最突出的宏观主题之一
- **btc** — 全球流动性的"溢出"传感，美元强弱周期是加密市场的宏观底色
- **china-internet** — 中国宏观体制转变（通缩/监管/CAPE 压缩）直接塑造其可投资性 (investability)
