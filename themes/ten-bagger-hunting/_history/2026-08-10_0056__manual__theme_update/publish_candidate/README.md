# 十倍/百倍投资机会扫描

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

寻找具有不对称回报潜力的投资机会。关注处于早期阶段、困境反转或范式变迁中的低关注度标的。

## 分析框架

- **不对称回报筛选** — 上行空间（10x+）vs 下行风险（归零可能性）的评估
- **拐点识别** — 技术/监管/竞争环境的结构性变化何时发生
- **护城河判断** — 即使小公司也要有某种形式的竞争优势
- **容错空间** — 组合层面管理：即使多个赔率不兑现，幸存者也能覆盖损失
