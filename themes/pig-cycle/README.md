# 猪周期

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

中国生猪/猪肉市场的周期跟踪：存栏量、猪价、养殖利润、行业集中度变化、以及 WH Group 等上市公司的投资逻辑。

## 分析框架

- **周期定位** — 当前处于猪周期的什么位置（补库/去库/底部/顶部），持续时间预期
- **行业集中度** — 规模化养殖的渗透率提升是否在减弱周期波动幅度
- **成本结构** — 饲料成本、养殖效率差异（散户 vs 规模场）、非洲猪瘟等疫病风险
- **WH Group 视角** — 全球一体化猪肉生产商的竞争优势 vs 纯 commodity 属性对投资吸引力的限制
