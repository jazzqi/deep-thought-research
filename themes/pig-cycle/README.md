# 猪周期（Hog / Pork Cycle）

> 跟踪中国生猪养殖与猪肉产业链的库存周期、产能出清节奏、以及行业整合为低成本生产者创造的结构性优势。

## 范围

**覆盖：**
- 中国生猪养殖的供需周期——能繁母猪存栏、生猪存栏、出栏节奏、猪粮比价
- 产业链利润分配——养殖（自繁自养 vs 公司+农户）→ 屠宰加工 → 终端零售
- WH Group（万洲国际/双汇/Smithfield）——全球最大的猪肉加工商，作为行业结构性赢家的分析
- 周期性底部信号——产能出清速度、行业亏损深度与持续时间、现金流消耗
- 政策干预——中央储备肉收储/投放机制、环保限产政策、规模化养殖补贴
- 饲料成本——玉米/豆粕价格对养殖利润的影响

**不覆盖：**
- 猪瘟/非洲猪瘟等疫病的流行病学分析（但关注其对供给冲击的定价）
- 猪肉期货的短期限交易策略
- 其他肉类蛋白（鸡/牛/羊）的全面供需分析——除非与猪肉产生重大替代效应
- 下游食品加工企业（如火腿肠/预制菜）的个股估值

## 核心问题

1. **周期位置判断**：当前处于猪周期的哪个阶段？产能去化进度到了 40% 还是 80%？从历史模式看，猪肉价格的底部通常领先产能出清底部多久？
2. **低成本生产者的结构优势**：在周期底部全行业亏损时，牧原/温氏等龙头企业的成本曲线优势是否在扩大？它们的单位成本与散户的差距是扩大还是缩小？这个差距能否构成可持续的护城河？
3. **WH Group 的资本配置价值**：作为全球布局的猪肉加工商，WH Group 是否具备跨越中国生猪周期的结构性优势——中国低成本养殖 + 美国/欧洲高附加值加工的套利模型？其分红政策和资本配置纪律如何？
4. **行业整合速度**：散户退出的长期趋势是否在加速？规模化率从当前 ~65% 向 80%+ 迈进的过程中，最大的受益者是谁？市场集中度的提升是否改变了过去"猪周期是 commodity 周期"的本质？
5. **周期投资的尾部风险**：在行业深度亏损期，是否存在资产负债表崩盘的风险——高杠杆养殖企业的债务违约、银行的养殖业坏账集中爆发？这些尾部风险如何影响周期性底部的最低点？
6. **政策干预的扭曲效应**：中央储备肉和地方政府补贴是否延长了周期磨底时间？人为的供给管理是否使猪周期变得"更钝但更长"？
