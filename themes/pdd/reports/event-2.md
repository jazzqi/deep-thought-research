# Temu 物流模式转型：关国内仓、建欧洲仓（2026-07-31）

**事件**：Temu 近期关闭了广东等地区的多个国内仓库，导致部分卖家反映配送效率下降。与此同时，Temu 正在德国、波兰等地建设和运营自有仓库。这一"内关外建"的动作被视为战略转型信号——从依赖全托管和直邮模式，转向更复杂的本地化物流布局。

**影响评估**：转型方向正确，但时机不佳。在美国取消小包免税政策、欧盟加强监管的背景下，本地化仓储是长期生存的必要条件，但短期内资本支出和运营成本将大幅上升。

**lynch 视角**：Temu 的"全托管模式"和低价策略面临物流成本上升、合规风险等挑战。
