# 孙宇晨（Justin Sun）信号雷达 — 二阶机会发现 报告结构模板 v2

> 本文件是 `themes/justin-sun/index.md` 的结构蓝本（v2，2026-08-09 重构）。
> **核心定位：孙宇晨是信号雷达，不是分析对象。本报告寻找的核心答案是二阶投资机会——**
> 通过他的每个动作，**抢先发现他即将布局/注资/站台/上币/收购的标的，在注意力涌入前上车**。
>
> **读者定位**：专业投资人（加密资产为重心）。每轮回答三个问题——
> ① 孙宇晨最近做了什么（信号捕捉：链上/投资/上币/言论/监管/政治）？
> ② 每个动作揭示了什么机会（机会推导：谁受益、为什么、市场还没定价什么）？
> ③ 怎么上车（触发条件/时间窗/置信度/上车方式/规避项）？
>
> **结构 = SEED 顶层节（publish 识别）+ 二阶机会核心输出节**。
> 顶层节标题必须精确匹配 publish 提取契约；维度子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：正文一律用文字，禁止装饰性 emoji；
> ③ **数字带单位与时间**（`TRX 现价 $0.33（2026-08-09）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← 本轮最重要发现（结论先行：发现了什么机会/什么信号）
## 共识                 ← 3-6 条共识 + 少数派（relay 最后一人维护）
## 各维度分析            ← 信号捕捉：按维度记录孙宇晨的最新动作（下挂 ### 子节）
## 二阶机会扫描          ← ★ 本主题核心答案：机会清单（下挂机会条目或表格）
## 预测时间线            ← 6 列表格（可证伪预测，只追加不修改）
## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
## 更新日志              ← publish 自动维护，无需写
```

> **重要**：`## 二阶机会扫描` 是**本主题的核心答案节**，必须存在且内容饱满——
> 每轮至少要给出 2-5 个具体机会（含受益标的、触发条件、时间窗、置信度、上车方式）。
> 宁可写"本轮无新增机会"也不能缺失。`## 各维度分析` 是信号捕捉的原始素材。
> **不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。

## 二、各维度分析 — 信号捕捉（孙宇晨做了什么）

> 每个维度子节回答：**当前状态**（最新证据，带来源日期）→ **信号性质**（实质 vs 叙事）
> → **机会线索**（这个信号指向哪个方向的机会，供核心节汇总）。
>
> **信号捕捉纪律**：链上为真、言论为虚；区分"他控制的资产动作"（一阶，可信度打折）
> 与"他投向外部标的的动作"（二阶，核心价值）；无数据写「暂无有效信号」。

### ### 链上资金动向

**覆盖范围**：TRX/ETH/BTC 大额转账、交易所关联地址（HTX/Poloniex）进出、稳定币（USDD/USDT）铸造与储备变动、质押变化。**主导视角**：crypto_trader。

```
**当前状态：** 一句话（含最新链上事件与日期）
**信号性质：** 实质行动（真买/真卖/真投）vs 中性调度（流动性管理）vs 纯言论
**机会线索：** 资金去向揭示了什么方向（他看好/回避什么，外部标的 or 自有生态）
```

### ### 投资/注资动向（★ 二阶机会富矿）

**覆盖范围**：他投资的项目、参与的融资轮、收购的标的、上币的标的。**主导视角**：crypto_trader + tech_scout。

```
**当前状态：** 一句话（最新投资/上币/收购事件与日期）
**机会推导：** 被投项目=早期布局窗口；被收购标的=低估重估窗口；上币标的=新流动性
**上车方式：** 一级跟随 / 二级埋伏 / 等确认信号（带时间窗与置信度）
```

### ### 生态与业务动作

**覆盖范围**：TRON 生态（USDD 储备、TRX 销毁、新协议）、HTX/Poloniex 运营（上币、储备、安全）、BitTorrent/BTT。**主导视角**：crypto_trader + munger。

```
**当前状态：** 一句话
**机会推导：** 上币标的（新流动性）、生态溢出受益方、业务实质 vs 发币操作
**上车方式：** 上币效应交易 / 生态关联标的 / 规避纯叙事
```

### ### 言论与叙事操作

**覆盖范围**：社交媒体表态、蹭热点/碰瓷、危机公关、宏大承诺。**主导视角**：kahneman + soros。

```
**当前状态：** 一句话（最新高调言论与日期）
**机会推导：** 他蹭的热点=注意力即将涌入的方向；承诺-交付缺口（交付的部分=真机会）
**上车方式：** 注意力脉冲短线 vs 实质交付中线，识别兑现路径
```

### ### 监管与法律风险

**覆盖范围**：SEC 状态、全球监管、交易所合规、政治关系。**主导视角**：taleb + geopolitics_agent。

```
**当前状态：** 一句话
**机会推导：** 监管松动的受益方向（稳定币合规、牌照、加密友好政策）
**风险边界：** 尾部分险（规避清单），不把背景叙事当已证实事实
```

### ### 政治关系投资

**覆盖范围**：WLFI / $TRUMP / 特朗普家族关联。**主导视角**：geopolitics_agent + soros。

```
**当前状态：** 一句话
**机会推导：** 政策受益赛道（加密友好政策、合规通道）、政治风向变化的时间窗
**反噬风险：** 依附关系脆弱性（WLFI 冻结=样本）
```

## 三、二阶机会扫描（★ 本主题核心答案，必须存在）

> **这是本报告的价值所在。** 把各维度信号汇总成机会清单，按优先级排序。
> 每个机会必须回答 5 要素：**机会是什么 / 受益标的 / 触发条件 / 时间窗 / 置信度**。
> 用表格或条目均可，但必须落在 `## 二阶机会扫描` 之下。
>
> **机会分类框架**：
> - **抢先型**（孙宇晨动作先于市场认知 → 他投的项目、他收购的标的、他上币的标的）
> - **注意力型**（他蹭的热点 → 赛道注意力涌入，短线流动性机会）
> - **政策型**（政治投资 → 监管受益方向，中线布局）
> - **规避型**（纯叙事/风险事件 → 明确规避清单，防踩坑）

```
### 本轮机会清单（按优先级排序）

| # | 机会（机会是什么） | 受益标的 | 触发条件 | 时间窗 | 置信度 | 类型 |
|---|------------------|---------|---------|--------|--------|------|
| 1 | ... | ... | ... | ... | x/10 | 抢先/注意力/政策 |
| 2 | ... | ... | ... | ... | x/10 | ... |

### 机会详解（每个机会 2-3 句逻辑链）

1. **机会 1 逻辑链：** 孙宇晨做了什么（信号）→ 意味着什么（推导）→ 谁受益（标的）→ 何时确认（触发条件）→ 怎么上车（方式）
2. ...

### 规避清单（防踩坑）

- **纯叙事**：宏大承诺无交付（FTX「数十亿救援」式）→ 不追涨
- **自有资产拉盘**：他控制标的的叙事脉冲（TRX 热度）→ 短线波动，非长期估值
- **风险事件**：监管翻案、交易所提现受限、稳定币脱锚 → 明确规避
```

### 行为模式库（机会时间窗判断工具）

| 模式 | 特征 | 典型历史案例 | 机会含义 |
|------|------|-------------|---------|
| 先否认后承认 | 否认参与/控制，证据确凿后承认 | Poloniex、HTX、格林纳达大使 | 否认期=市场低估期，承认时=机会确认 |
| 收购+发币闭环 | 收购有用户基数产品 → 发币 → 自控交易所维持流动性 | BitTorrent→BTT、Steemit→失败 | 被收购标的=低估重估窗口 |
| 危机抢叙事 | 行业危机时高调承诺救援，部分交付 | FTX「数十亿救援」→1:1 通道 | 承诺=PR；交付的部分=真机会 |
| 注意力经济 | 高价购买注意力 → 转化为币价支撑 | 巴菲特午餐、香蕉、Blue Origin | 热度峰值=短线卖点；热度源头=受益标的 |
| 政治投资对冲 | 投资政治关系对冲法律风险 | 格林纳达、WLFI/$TRUMP→SEC 撤诉 | 政策受益方向=中线布局 |
| 说而不做 | 宏大承诺无交付 | 「数十亿救助」未兑现 | 链上/落地证据>言论，无证据不动作 |

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / binance_get_price /
  binance_get_klines / QueryLongbridgeByRouteTool / query_indicators），
  禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- 链上断言（大额转账/持仓变化）必须有链上数据或权威报道来源支撑。
- **机会推导是概率判断，不是事实陈述**：每个机会标注置信度与触发条件；
  无触发条件的"机会"不写（那是猜测不是情报）。
- 涉及代币价格/市值的数字必须标注来源工具 + 关键参数 + 日期。
- **一阶 vs 二阶纪律**：他控制的资产动作（TRX/HTX 等）是信号源，不是核心机会；
  核心机会 = 他投向/揭示的外部标的与方向。
- **立场中立**：本主题做情报分析，不粉饰也不污名化孙宇晨；分析只服务于
  投资决策，不输出立场或评价其人格。
- 服务资本市场投资决策，不输出政治立场。
