# 孙宇晨（Justin Sun）信号雷达 — 二阶机会发现 报告结构模板 v2

> 本文件是 `themes/justin-sun/index.md` 的结构蓝本（v2，2026-08-09 重构）。
> **核心定位：孙宇晨是信号雷达，不是分析对象。本报告寻找的核心答案是二阶投资机会——**
> 通过他的每个动作，**抢先发现他即将布局/注资/站台/上币/收购的标的，在注意力涌入前上车**。
>
> **读者定位**：专业投资人（加密资产为重心）。每轮回答三个问题——
> ① 孙宇晨最近做了什么（信号捕捉：链上/投资/上币/言论/监管/政治）？
> ② 每个动作揭示了什么机会（机会推导：谁受益、为什么、市场还没定价什么）？
> ③ 怎么上车（触发条件/时间窗/置信度/上车方式/规避项）？
>
> **结构 = SEED 顶层节（publish 识别）+ 二阶机会核心输出节**。
> 顶层节标题必须精确匹配 publish 提取契约；维度子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：正文一律用文字，禁止装饰性 emoji；
> ③ **数字带单位与时间**（`TRX 现价 $0.33（2026-08-09）`），所有判断给置信度或概率。

## 二、各维度分析 — 机会提炼（行为→想法，非剖析人）

> 每个维度子节不写“孙宇晨做了什么”流水账，只写 **从该行为/言论中提炼出的投资想法**：
> **提炼的想法**（一句话投资假设，带置信度）→ **推导**（为什么成立/不成立）→ **验证/证伪**（触发条件/时间窗）。
> 无可提炼想法写「暂无有效想法」。

### ### 赛道与标的发现（行为→新赛道/新标的想法）

**提炼对象**：从 链上异动/投资/收购/上币 行为中，发现 “他提前看到的赛道/标的”。**主导视角**：crypto_trader + tech_scout。

```
**提炼的想法：** 一句投资假设（如“GRVT 类永续 DEX 的多平台流动性窗口” + 置信度 x/10）
**推导：** 行为证据（日期/来源）→ 为什么是赛道/标的级机会（非 TRX 本身）
**验证/证伪：** 触发条件 / 时间窗 / 证伪条件（未触发则不追）
```

### ### 流动性与上车窗口（行为→怎么上车的想法）

**提炼对象**：从 生态上币/交易所动作/资金调度 中，提炼 “流动性何时来、怎么上车”。**主导视角**：crypto_trader + munger。

```
**提炼的想法：** 一句上车假设（如“HTX 上币后 72h 现货深度窗口” + 置信度）
**推导：** 生态/上币证据 → 流动性路径（现货/永续/跨所）
**验证/证伪：** 上车触发条件 / 时间窗 / 止损条件
```

### ### 叙事与政策套利（言论→套利/风险的想法）

**提炼对象**：从 高调言论/蹭热点/政治投资 中，提炼 “叙事/政策套利或需规避的想法”。**主导视角**：kahneman + soros / geopolitics_agent + taleb 轮动。

```
**提炼的想法：** 一句套利/规避假设（如“WLFI 政策通道期权溢价过高，宜规避” + 置信度）
**推导：** 言论/政治证据 → 套利逻辑（注意力脉冲/政策通道）或风险逻辑
**验证/证伪：** 兑现路径 / 风险边界 / 证伪条件
```

## 三、二阶机会扫描（★ 本主题核心答案，必须存在）

> **这是本报告的价值所在。** 把各维度信号汇总成机会清单，按优先级排序。
> 每个机会必须回答 5 要素：**机会是什么 / 受益标的 / 触发条件 / 时间窗 / 置信度**。
> 用表格或条目均可，但必须落在 `## 二阶机会扫描` 之下。
>
> **机会分类框架**：
> - **抢先型**（孙宇晨动作先于市场认知 → 他投的项目、他收购的标的、他上币的标的）
> - **注意力型**（他蹭的热点 → 赛道注意力涌入，短线流动性机会）
> - **政策型**（政治投资 → 监管受益方向，中线布局）
> - **规避型**（纯叙事/风险事件 → 明确规避清单，防踩坑）

```
### 本轮机会清单（按优先级排序）

| # | 机会（机会是什么） | 受益标的 | 触发条件 | 时间窗 | 置信度 | 类型 |
|---|------------------|---------|---------|--------|--------|------|
| 1 | ... | ... | ... | ... | x/10 | 抢先/注意力/政策 |
| 2 | ... | ... | ... | ... | x/10 | ... |

### 机会详解（每个机会 2-3 句逻辑链）

1. **机会 1 逻辑链：** 孙宇晨做了什么（信号）→ 意味着什么（推导）→ 谁受益（标的）→ 何时确认（触发条件）→ 怎么上车（方式）
2. ...

### 规避清单（防踩坑）

- **纯叙事**：宏大承诺无交付（FTX「数十亿救援」式）→ 不追涨
- **自有资产拉盘**：他控制标的的叙事脉冲（TRX 热度）→ 短线波动，非长期估值
- **风险事件**：监管翻案、交易所提现受限、稳定币脱锚 → 明确规避
```

### 行为模式库（机会时间窗判断工具）

| 模式 | 特征 | 典型历史案例 | 机会含义 |
|------|------|-------------|---------|
| 先否认后承认 | 否认参与/控制，证据确凿后承认 | Poloniex、HTX、格林纳达大使 | 否认期=市场低估期，承认时=机会确认 |
| 收购+发币闭环 | 收购有用户基数产品 → 发币 → 自控交易所维持流动性 | BitTorrent→BTT、Steemit→失败 | 被收购标的=低估重估窗口 |
| 危机抢叙事 | 行业危机时高调承诺救援，部分交付 | FTX「数十亿救援」→1:1 通道 | 承诺=PR；交付的部分=真机会 |
| 注意力经济 | 高价购买注意力 → 转化为币价支撑 | 巴菲特午餐、香蕉、Blue Origin | 热度峰值=短线卖点；热度源头=受益标的 |
| 政治投资对冲 | 投资政治关系对冲法律风险 | 格林纳达、WLFI/$TRUMP→SEC 撤诉 | 政策受益方向=中线布局 |
| 说而不做 | 宏大承诺无交付 | 「数十亿救助」未兑现 | 链上/落地证据>言论，无证据不动作 |

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / binance_get_price /
  binance_get_klines / QueryLongbridgeByRouteTool / query_indicators），
  禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- 链上断言（大额转账/持仓变化）必须有链上数据或权威报道来源支撑。
- **机会推导是概率判断，不是事实陈述**：每个机会标注置信度与触发条件；
  无触发条件的"机会"不写（那是猜测不是情报）。
- 涉及代币价格/市值的数字必须标注来源工具 + 关键参数 + 日期。
- **一阶 vs 二阶纪律**：他控制的资产动作（TRX/HTX 等）是信号源，不是核心机会；
  核心机会 = 他投向/揭示的外部标的与方向。
- **立场中立**：本主题做情报分析，不粉饰也不污名化孙宇晨；分析只服务于
  投资决策，不输出立场或评价其人格。
- 服务资本市场投资决策，不输出政治立场。
