# 全球生物医药

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

全球生物医药行业全景跟踪（创新药/Big Pharma/生物科技/仿制药/器械诊断）：从创新药研发管线、审评监管、商业化、并购与 license 到政策与地缘，覆盖行业景气、资本周期、竞争格局与监管环境，**持续监测行业重大的潜在投资机会**。**与上游主题的关系**：宏观背景与流动性见 global-macro，颠覆式技术范式（ADC/GLP-1/CGT）见 disruptive-innovation，不重复宏观/技术细节，聚焦医药行业自身的发展脉络与投资主线。

## 分析框架

- **研发管线** — 临床阶段（Phase 1/2/3）、适应症拓展、关键数据读出（readout）日历、管线价值折现
- **审评监管** — FDA/EMA 审评、NDA/BLA 批准、加速批准、黑框警告、撤市
- **商业化与支付** — 上市销售爬坡、重磅药峰值销售、专利悬崖、仿制/生物类似药侵蚀、定价与报销
- **并购与 license** — M&A、BD/license 交易、管线交易估值、中小 biotech 被收购溢价
- **政策与地缘** — IRA 药价谈判、医保改革、中美医药脱钩、贸易关税
- **重大投资机会扫描** — **管线成败 × 商业化兑现 × 政策冲击** 三者的交集 = 重大潜在投资机会（含上行尾部与下行尾部）
