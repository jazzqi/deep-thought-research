# 全球生物医药 — 报告结构模板 v1

> 本文件是 `themes/biopharma/index.md` 的结构蓝本（v1，2026-08-08 冷启动创建）。
> **读者定位**：专业投资人。回答三个问题——
> ① 全球生物医药行业当前处于什么阶段（管线景气/审评节奏/商业化周期/并购热度），市场定价了多少？
> ② 哪些驱动因素（临床 readout、审评决策、专利悬崖、并购、政策）正在改变行业斜率，上行/下行尾部被低估多少？
> ③ 我该怎么参与（Big Pharma / 中型 biotech / 早期管线），什么信号会推翻我的判断？
>
> **结构 = SEED 顶层节（publish 识别）+ 五维分析子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；维度子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许「产业景气速览表」首列用 emoji，正文一律用文字；
> ③ **数字带单位与时间**（`LLY Q2 2026 营收 $XXX亿（2026-08 财报季）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← 行业总判断（200-400 字，结论先行）
## 共识                 ← 3-6 条共识 + 少数派（relay 最后一人维护）
## 各维度分析            ← ★ 唯一大容量节：按五维组织（下挂 ### 子节）
## 预测时间线            ← 6 列表格（可证伪预测，只追加不修改）
## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
## 更新日志              ← publish 自动维护，无需写
```

> **重要**：`## 各维度分析` 是唯一大容量内容节。所有行业分析写在这里的
> `### 子节` 中。**不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。

## 二、各维度分析 — 五维子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的维度就写哪些，可合并可增删。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。
>
> **每个维度子节必须回答三件事**：
> 1. **当前状态** — 该维度最值得注意的新证据（带来源与日期，工具查询，不注入数值）
> 2. **行业定位** — 景气度（管线密度、审评节奏、销售爬坡、交易热度）
> 3. **投资信号** — 方向判断 + 跟踪指标 + 时间窗口 + 置信度

### ### 研发管线

**覆盖范围**：临床阶段（Phase 1/2/3）、适应症拓展、关键数据读出（readout）日历、管线价值折现。**主导视角**：pharma_specialist。

```
**当前状态：** 一句话（含最新 readout/临床新闻证据与日期）
**管线热度：** 各治疗领域（肿瘤/代谢/免疫/神经/CGT）管线密度、资本开支方向
**投资信号：** 关键 readout 日历、管线价值 vs 市值落差、候选标的
```

### ### 审评监管

**覆盖范围**：FDA/EMA 审评、NDA/BLA 批准、加速批准、黑框警告、撤市。**主导视角**：pharma_specialist + taleb。

```
**当前状态：** 一句话（含最新审评新闻证据与日期）
**审评动态：** FDA/EMA 批准/否决/延迟、加速批准、黑框警告
**投资信号：** 获批时间窗标的、审评风险尾部
```

### ### 商业化与支付

**覆盖范围**：上市销售爬坡、重磅药峰值销售、专利悬崖、仿制/生物类似药侵蚀、定价与报销。**主导视角**：buffett。

```
**当前状态：** 一句话
**销售爬坡：** 重磅药峰值销售、渗透率、生物类似药/仿制侵蚀
**专利悬崖：** 未来 2-5 年专利到期图谱、lost exclusivity 影响
**投资信号：** 已兑现收入标的 vs 纯叙事标的的区分
```

### ### 并购与 license

**覆盖范围**：M&A、BD/license 交易、管线交易估值、中小 biotech 被收购溢价。**主导视角**：buffett + soros。

```
**当前状态：** 一句话
**交易动态：** M&A/BD 交易、溢价率、管线交易估值
**投资信号：** 潜在被收购标的（小而美管线）、并购驱动重估
```

### ### 政策与地缘

**覆盖范围**：IRA 药价谈判、医保改革、中美医药脱钩、贸易关税。**主导视角**：soros + munger。

```
**当前状态：** 一句话
**政策动态：** IRA 药价谈判、医保改革、中美医药脱钩、关税
**投资信号：** 政策受益/受损标的、地缘尾部
```

### ### 重大投资机会扫描（★ 本主题特色节）

**覆盖范围**：**管线成败 × 商业化兑现 × 政策冲击** 三者的交集 = 重大潜在投资机会
（含上行尾部与下行尾部）。**主导视角**：pharma_specialist 统筹 + 全员。

```
| 机会类型 | 标的/方向 | 触发条件 | 置信度 | 提出者 |
|---------|----------|---------|--------|--------|
| 上行（管线） | ... | 关键 readout 成功 | x/10 | agent |
| 下行（尾部） | ... | 临床失败/政策冲击 | x/10 | agent |
```

### ### 其他子节（按需）

**覆盖范围**：中国创新药出海、CXO 产业链、医药 ETF/指数联动（XBI/IBB）、GLP-1 产能等。
**主导视角**：按实际涉及选择。

```

| 审评监管 | ... | ... | 双向 | FDA/EMA 批准节奏 | 6/10 |
| 商业化与支付 | ... | ... | 上行 | 重磅药销售爬坡、专利悬崖 | 6/10 |
| 并购与 license | ... | ... | 上行 | M&A 交易额、溢价率 | 5/10 |
| 政策与地缘 | ... | ... | 下行 | IRA 谈判进展、关税 | 6/10 |
```

> **数据获取（全部工具查询，不注入数值）**：新闻/进展用 `query_raw_items`
> （关键词覆盖 biopharma/biotech/pharmaceutical/FDA/EMA/clinical trial/drug approval/
> patent cliff/GLP-1/ADC/immuno-oncology/CGT/并购/license/IRA drug pricing 等，
> source 首选 'telegram:Financial_Express' 实时快讯，次选 longbridge/reuters）；
> 上市公司基本面/估值/一致预期/新闻用 `QueryLongbridgeByRouteTool`
> （LLY/NVO/PFE/MRK/ABBV/AMGN/SNY/JNJ/MRNA 等，先 search_routes 探索路由再 query）；
> 行业政策/宏观背景用 `query_indicators`（利率/流动性/风险偏好）+ `query_raw_items`
> （IRA/药价谈判/医保政策关键词）。
> **核心方法**：所有数字必须来自工具查询，禁止 prompt 注入/凭空编造；无数据写
> 「（数据缺失）」（G-04 诚实标注）。**主题特有纪律**：区分「管线叙事/预期」与
> 「实际销售/获批」；临床成功率给参考基准（Phase 1→2 ~50%、2→3 ~40%、3→获批 ~60%）；
> 不把临床前/早期数据当已验证产品（readout≠获批=blocker）。

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / QueryLongbridgeByRouteTool /
  query_indicators），禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- 管线/审评状态断言必须有新闻来源支撑（禁止无来源的批准/readout 断言）。
- 区分「管线叙事/预期」与「实际销售/获批」；临床成功率给参考基准
  （Phase 1→2 ~50%、2→3 ~40%、3→获批 ~60%）；readout≠获批，不把临床前/早期
  数据当已验证产品。
- 涉及公司财务的数字必须标注来源工具 + 关键参数 + 日期，记入 reference.md 溯源
  （`- {数据点}: {来源工具}({关键参数}) = {值}`）。
- 判断给置信度或概率；预测给可证伪的触发条件或数值区间。
- 服务资本市场投资决策，不输出政治立场。
