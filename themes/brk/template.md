# 伯克希尔哈撒韦（BRK / 巴菲特投资动向）— 报告结构模板 v1

> 本文件是 `themes/brk/index.md` 的结构蓝本（v1，2026-08-09 冷启动创建）。
> **读者定位**：专业投资人。回答三个问题——
> ① 伯克希尔/巴菲特近期发生了什么（持仓变动/言论/资本配置），市场定价了多少？
> ② 这些动作与言论释放了什么投资信号（跟风机会/反向信号/防御配置），上行/下行尾部如何？
> ③ 我该怎么参与（BRK 本身 / 巴菲特持仓个股 / 反指），什么信号会推翻我的判断？
>
> **结构 = SEED 顶层节（publish 识别）+ 五维分析子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；维度子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许「信号速览表」首列用 emoji，正文一律用文字；
> ③ **数字带单位与时间**（`苹果持仓 6.5 亿股（2026-08-09 估算）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← 伯克希尔/巴菲特总判断（200-400 字，结论先行）
## 共识                 ← 3-6 条共识 + 少数派（relay 最后一人维护）
## 各维度分析            ← ★ 唯一大容量节：按五维组织（下挂 ### 子节）
## 预测时间线            ← 6 列表格（可证伪预测，只追加不修改）
## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
## 更新日志              ← publish 自动维护，无需写
```

> **重要**：`## 各维度分析` 是唯一大容量内容节。所有分析写在这里的
> `### 子节` 中。**不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。

## 二、各维度分析 — 五维子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的维度就写哪些，可合并可增删。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。
>
> **每个维度子节必须回答三件事**：
> 1. **当前状态** — 该维度最值得注意的新证据（带来源与日期，工具查询，不注入数值）
> 2. **行业定位** — 该维度当前处于什么阶段/位置
> 3. **投资信号** — 方向判断 + 跟踪指标 + 时间窗口 + 置信度

### ### 持仓动向（13F + 公告）

**覆盖范围**：季度 13F 持仓变动（新建仓/加仓/减仓/清仓）、关键持仓变动（苹果、美国银行、西方石油、日本五大商社、可口可乐、美国运通、雪佛龙等）、大宗交易公告、13F 披露的时点与滞后。**主导视角**：buffett + lynch。

```
**当前状态：** 一句话（含最新 13F/公告证据与日期）
**持仓变动：** 新建/加/减/清仓明细（带数量/比例/方向）
**信号解读：** 变动背后的逻辑（估值/行业/宏观驱动）+ 跟风交易时点价值
```

### ### 管理层言论与股东信

**覆盖范围**：股东大会（AGM）问答、年度股东信、访谈与公开声明；对市场估值、利率、经济周期、具体行业/公司的观点；**言行一致度**（说了什么 vs 实际买/卖了什么）。**主导视角**：buffett + munger。

```
**当前状态：** 一句话（含最新言论证据与日期）
**核心观点：** 对市场/利率/周期/行业的判断（带原话摘要与日期）
**言行一致度：** 言论 vs 持仓行为是否一致（一致=信号增强，背离=警示）
```

### ### 伯克希尔基本面与估值

**覆盖范围**：保险浮存金与承保盈亏、铁路（BNSF）/能源/制造业分部、现金储备规模、回购节奏与价格区间、B 股估值（PB/市值 vs 内在价值估算）。**主导视角**：buffett + soros。

```
**当前状态：** 一句话
**分部表现：** 保险/铁路/能源/制造各自的最新经营数据
**资本配置：** 现金储备、回购/分红、收购动向（带金额与日期）
**估值定位：** BRK 的 PB/PE/市值 vs 内在价值估算，当前溢价/折价
```

### ### 投资信号转化（★ 本主题特色节）

**覆盖范围**：巴菲特动作/言论 → 可跟踪信号的转化：哪些标的出现"巴菲特效应"（跟风买盘）、哪些出现反向定价（他卖出但基本面未变）、哪些是他言论看多但未持仓的方向。**主导视角**：buffett + lynch + soros。

```
| 信号类型 | 标的/方向 | 触发条件 | 置信度 | 提出者 |
|---------|----------|---------|--------|--------|
| 跟风（持仓） | ... | 13F 披露/公告确认 | x/10 | agent |
| 反向（减仓） | ... | 基本面未变但遭减持 | x/10 | agent |
| 言论（未持仓） | ... | 表态看多/看空 | x/10 | agent |
```

### ### 风险与反指

**覆盖范围**：跟风 13F 的滞后风险（披露延迟 45 天）、大宗持仓变动的时点陷阱、把价值投资言论当短期交易信号的误用、伯克希尔自身风险（管理层交接、集中持仓、浮存金利率敏感）。**主导视角**：taleb + munger。

```
**当前状态：** 一句话
**跟风风险：** 披露滞后/时点陷阱/言行不一致的案例与量化
**反指信号：** 什么情况下"巴菲特买入"不是买入信号
```

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / QueryLongbridgeByRouteTool /
  query_indicators），禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- 持仓/言论状态断言必须有新闻来源支撑（禁止无来源的持仓变动断言）。
- **13F 滞后纪律**：13F 按季度披露、滞后约 45 天，写持仓变动时必须标注
  「数据截止季度」（如 `（13F 2026Q2 数据，2026-08 披露）`），禁止把披露的
  历史持仓当当前持仓。
- 涉及公司财务的数字必须标注来源工具 + 关键参数 + 日期，记入 reference.md 溯源
  （`- {数据点}: {来源工具}({关键参数}) = {值}`）。
- 判断给置信度或概率；预测给可证伪的触发条件或数值区间。
- 服务资本市场投资决策，不输出政治立场。
