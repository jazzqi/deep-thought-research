# 伯克希尔哈撒韦（BRK / 巴菲特投资动向 → 机会发现）— 报告结构模板 v2

> 本文件是 `themes/brk/index.md` 的结构蓝本（v2，2026-08-09 重定位：核心从「BRK 公司投资价值」转为「通过 BRK/巴菲特动向发现可投资标的」）。
> **读者定位**：专业投资人。回答三个问题——
> ① 巴菲特/伯克希尔近期持仓变动和言论指向哪些**具体可投资的标的**？
> ② 这些标的的信号类型是什么（跟随新建仓/加仓确认/反向减持/前瞻未建仓）？触发条件和置信度如何？
> ③ 我该怎么参与（直接买标的 vs 买 BRK 载体），什么信号会推翻我的判断？
>
> **结构 = SEED 顶层节（publish 识别）+ 机会发现维度子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；维度子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许「投资机会清单」表首列用 emoji，正文一律用文字；
> ③ **数字带单位与时间**（`苹果持仓 6.5 亿股（13F 2026Q2，2026-08 披露）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← 本轮巴菲特动向总判断（200-400 字，结论先行，聚焦机会方向）

## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
```

> `### 子节` 中。**不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。
>
> **★ 主题灵魂**：本主题产出的是**可投资的标的清单**，不是"BRK 公司研究报告"。
> 每一节都要回答"**这个机会我能投什么、什么时候投、凭什么投**"。

## 二、各维度分析 — 机会发现维度子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的维度就写哪些，可合并可增删。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。
>
> **每个维度子节必须回答三件事**：
> 1. **当前状态** — 该维度最值得注意的新证据（带来源与日期，工具查询，不注入数值）
> 2. **机会定位** — 该维度指向哪些具体投资机会（标的/方向）
> 3. **投资信号** — 信号类型（跟随/反向/前瞻）+ 触发条件 + 时间窗口 + 置信度

### ### 持仓动向 → 可跟随标的（★ 核心维度）

**覆盖范围**：13F 季度持仓变动翻译为**具体标的信号**——新建仓（跟随机会）、加仓（确认信号）、减仓/清仓（反向或风险信号）。每个标的三要素：当前状态、巴菲特逻辑推断、我们如何参与。**主导视角**：buffett + lynch。

```
**当前状态：** 一句话（含最新 13F/公告证据与日期，标注数据截止季度）
**可跟随标的一览：**
| 标的 | 变动 | 巴菲特逻辑推断 | 参与方式 | 触发条件 | 置信度 | 提出者 |
|------|------|--------------|---------|---------|--------|--------|
| AAPL | 加仓/减仓/新建 | ... | 直接买入/等待 | 13F确认+估值合理 | x/10 | agent |
| OXY  | ... | ... | ... | ... | x/10 | agent |
**信号解读：** 变动背后的投资逻辑 + 跟风交易时点价值 + 反指风险
```

### ### 管理层言论 → 前瞻线索（机会雷达）

**覆盖范围**：巴菲特/Abel 股东信、股东大会、访谈中**指向具体方向**的观点——识别"已表态未建仓"的前瞻机会（如看好能源、日本、AI、公用事业）。**言行一致度**仍是关键：言论 + 行为都指向的方向 = 高置信机会；只有言论 = 前瞻观察。**主导视角**：buffett + soros。

```
**当前状态：** 一句话（含最新言论证据与日期）
**前瞻线索：**
| 方向/标的 | 言论要点 | 是否已建仓 | 言行一致度 | 机会类型 | 置信度 |
|----------|---------|-----------|-----------|---------|--------|
| 日本商社 | ... | 已重仓 | 一致 | 确认/加码 | x/10 |
| 能源 | ... | 未确认 | 待验证 | 前瞻观察 | x/10 |
```

### ### 投资机会清单（★ 本主题核心产出节）

**覆盖范围**：**全维度汇总的一张可执行机会表**——把持仓动向 + 言论线索 + 反向信号汇总成下游可直接消费的清单。每行必须含：标的 + 信号类型 + 逻辑 + 触发条件 + 置信度 + 验证数据 + 提出者。**主导视角**：buffett 统筹 + 全员。

```
| 信号类型 | 标的/方向 | 逻辑 | 触发条件 | 置信度 | 验证数据 | 提出者 |
|---------|----------|------|---------|--------|---------|--------|
| 跟随（新建仓） | GOOGL | 巴菲特亲导 $31B 投资 | 13F确认+回撤到估值区间 | 3/10 | 13F 2026Q2 | lynch |
| 跟随（加仓确认） | BRK.B | 回购持续+现金部署 | 回购价格<内在价值 | 5/10 | 10-Q回购明细 | buffett |
| 反向（减持） | AMZN | 减持但基本面未变 | 13F确认+基本面验证 | 2/10 | 13F+季报 | munger |
| 前瞻（言论） | 日本商社 | 巴菲特持续看好日本 | 日股回调+商社财报 | 4/10 | 股东信+持仓 | soros |
```

> **★ 本节是发布后供 CIO/组合决策直接消费的核心资产**。宁可每行保守（低置信度+明确触发条件），不可堆砌无执行性的泛泛方向。

### ### BRK 自身：信号源可靠性（次要维度）

**覆盖范围**：伯克希尔基本面只用于**评估信号源的可靠性**——现金储备（防御/进攻倾向）、回购节奏（管理层是否认可自身价值）、浮存金（资本成本）、分部经营（判断资本配置能力）。**不是主分析对象**，除非 BRK.B 作为"资本配置载体"优于直接买其持仓。**主导视角**：buffett + soros。

```
**当前状态：** 一句话
**信号源可靠性：** 现金/回购/浮存金反映的管理层姿态（进攻/防御/中性）
**载体 vs 标的：** BRK.B 作为载体 vs 直接买其持仓的取舍
```

### ### 风险与反指

**覆盖范围**：跟风 13F 的滞后风险（披露延迟 45 天）、大宗持仓变动的时点陷阱、"巴菲特卖出"不等于"看空"（可能是税/集中度管理）、"巴菲特买入"不等于"必涨"（披露时可能已涨完）、把价值言论当短期交易信号的误用。**主导视角**：taleb + munger。

```
**当前状态：** 一句话
**跟风风险：** 滞后/时点/口径冲突/言行背离的案例与量化
**反指条件：** 什么情况下"巴菲特买入"不是买入信号（反向过滤清单）
```

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / QueryLongbridgeByRouteTool /
  query_indicators），禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- 持仓/言论状态断言必须有新闻来源支撑（禁止无来源的持仓变动断言）。
- **13F 滞后纪律**：13F 按季度披露、滞后约 45 天，写持仓变动时必须标注
  「数据截止季度」（如 `（13F 2026Q2 数据，2026-08 披露）`），禁止把披露的
  历史持仓当当前持仓。
- **标的落地纪律**：每个投资信号必须落到具体标的（代码/方向）+ 触发条件 +
  置信度 + 验证数据，禁止泛泛的方向描述。
- 涉及公司财务的数字必须标注来源工具 + 关键参数 + 日期，记入 reference.md 溯源
  （`- {数据点}: {来源工具}({关键参数}) = {值}`）。
- 判断给置信度或概率；预测给可证伪的触发条件或数值区间。
- 服务资本市场投资决策，不输出政治立场。
