# 伯克希尔哈撒韦（Berkshire Hathaway / 巴菲特投资动向 → 第一时间发现投资机会）

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围（★ 核心定位）

**本主题的核心不是分析伯克希尔这家公司的投资价值，而是通过跟踪伯克希尔的投资组合变动与巴菲特/管理层言行，第一时间发现有价值的投资机会。** 通过巴菲特发现投资机会是**二阶收益**——真正的收益来自被他买入/看好的**标的本身**，而不是 BRK 这家公司。

**两条核心原则：**

1. **第一时间（领先性）** — 13F 季度披露滞后约 45 天，是**最后确认信号**，不是机会起点。真正的领先信号按时效排序：
   - **T0（即时，分钟-小时级）**：13D/13G 文件（持股≥5% 须 10 天内披露）、大宗交易公告、收购要约、SEC 突发申报
   - **T1（日级）**：巴菲特/Abel 公开言论、股东信、股东大会问答、权威财经媒体披露的交易细节
   - **T2（周-月级）**：13F 季度披露（滞后 45 天）、10-Q/10-K 持仓明细（滞后一个季度）
   
   报告必须**按信号时效分层**，明确每个机会当前处于哪个信号层级、领先市场多少——领先性本身就是 alpha。

2. **二阶收益（标的导向）** — 每个信号必须落到**具体可投资的标的**（代码/方向），并回答"为什么这个标的机会被低估/未定价"。我们赚的是**被投公司**的价值重估，不是 BRK 的估值变化。BRK 自身只作为"信号源可靠性"评估（如回购说明管理层认可价值、现金高企说明防御倾向），不作为主分析对象。

**产出物** = **可执行的机会清单**：每个机会包含「标的 → 信号时点（T0/T1/T2）→ 信号类型（跟随/反向/前瞻）→ 触发条件 → 置信度 → 验证数据」六要素。

**与上游主题的关系**：宏观背景与流动性见 global-macro，市场全景见 market-daily，市场情绪/叙事热度见 market-sentiment（用于判断"巴菲特效应"的跟风热度与反转风险）。本主题聚焦"伯克希尔动向 → 具体标的信号"的转化，不重复宏观/大盘分析。

**主题定位（独特价值）**：
- **巴菲特 = 领先信号源**：他的每一次建仓/加仓/减持/表态，都是被投标的的潜在机会信号；13D/13G 与公告是最快的正式信号，13F 是确认信号
- **持仓个股 = 二阶收益载体**：伯克希尔重仓/新建仓的每一个标的，都是潜在的投资标的（跟随或反向），收益在被投公司
- **言论 = 前瞻雷达**：股东信/股东大会观点指向的行业方向（能源、日本、AI），可能是尚未建仓的前瞻机会
- **时机 = alpha 来源**：同一信号，T0 发现 vs T2 确认的收益差异巨大；报告必须明确每个机会的时效窗口

## 分析框架

- **领先信号扫描（T0/T1 优先）** — 实时监控 13D/13G、大宗交易公告、收购要约、巴菲特/Abel 言论、权威媒体披露；**13F 是最后的确认环节，不是起点**。每个标的标注当前信号层级（T0/T1/T2）与领先市场的时窗
- **持仓动向 → 可跟随标的（核心）** — 持仓变动翻译为标的信号：新建仓（跟随机会）、加仓（确认信号）、减仓/清仓（反向或风险信号）；每个标的三要素：当前状态、巴菲特逻辑推断、我们如何参与（含时效窗口）
- **管理层言论 → 前瞻线索** — 识别"已表态未建仓"的前瞻方向；区分"言论"与"行为"（言行一致度）——言行一致的信号置信度最高
- **投资机会清单（★ 本主题核心产出）** — 每轮输出一张可执行的机会表：标的 × 信号时点 × 信号类型（跟随/反向/前瞻） × 触发条件 × 置信度 × 验证数据，直接供下游组合决策使用
- **BRK 自身 = 信号源可靠性** — 现金储备/回购/浮存金用于评估"信号源是否可靠"，不作为主分析对象
- **风险与反指** — 跟风滞后风险（T2 信号已充分定价）、时点陷阱、"巴菲特卖出"不等于"看空"（可能是税/集中度管理）、"巴菲特买入"不等于"必涨"
