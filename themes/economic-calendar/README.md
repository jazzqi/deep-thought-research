# 周度财经日历预读

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

周度全球财经日历预读与回顾。

覆盖：各国宏观经济数据（CPI/PPI/PMI/非农/利率决议等）、央行会议、重要财经事件；全球视角，不限于单一国家。

## 分析框架

- **下周重要事件识别与影响评估** — 从财经日历中筛选高影响事件，评估其对各类资产的可能影响
- **数据指标预测 + 场景路径** — 对关键指标给出预测，并推演 miss/达标/超预期三种场景下的路径（每档必须含触发阈值 + 分项确认条件 + 市场反应）
- **国别区分** — 所有事件/指标必须标注国家，避免混淆不同经济体之间的数据差异
- **事件→市场反应预判** — 预判事件落地后各市场（股/债/汇/商品）的潜在反应方向与幅度
- **行情坐标** — 报告必须含关键资产快照（10Y/2Y UST、DXY、SPX、Brent、Gold、CNH），让事件分析与市场当前位置挂钩

## 报告结构（v2）

每周产出两份文档（周日晚发布，落盘周文件夹）：

| 文档 | 位置 | 核心内容 |
|------|------|---------|
| forecast.md（预读） | `themes/economic-calendar/{下周一}__{下周日}/` | TL;DR、行情快照、日历一览、事件时间线、场景路径（阈值+分项）、对组合的含义、日历外已知未知、预测总表、共识/分歧、数据可用性声明 |
| recap.md（回顾） | `themes/economic-calendar/{本周一}__{本周日}/` | TL;DR、行情快照（周涨跌）、**日历事件意外矩阵**（actual vs consensus）、非日历事件（归属主题）、预测验证（逐条）、**跨周预测成绩单**、观察清单、经验教训 + agent 复盘 |

结构蓝本：`template.md`。**结构固定，内容自由发挥**。

## 跨周闭环（重要）

```
forecast（周日晚）
  ├─ 承接：读取上期 recap 的「未来需持续观测清单」→ 逐条放入「日历外的已知未知」
  ├─ 引用：读取上期 recap 的「跨周预测成绩单」→ 校准置信度
  └─ 输出：预测总表（含置信度 + 提出者）
recap（周日晚）
  ├─ 验证：逐条对照本周 forecast 场景路径 → 落点/场景/市场反应/命中
  ├─ 成绩单：追加本周预测验证结果 + 累计命中率（不修改历史）
  └─ 输出：观察清单 → 供下周 forecast 承接
```

## 数据质量准则

- **数据缺失不掩盖**：缺失项集中写入「数据可用性声明」节，正文不逐段重复；禁止占位符/默认值（P-03/R-06）
- **前值/共识字段**：日历事件（akshare/openbb）携带 previous/forecast 字段，agent 必须优先使用真实字段，不得写"数据缺失"代替查询
- **数据质量分级**：frontmatter `data_quality: full|partial|poor` 由发布流程注入，读者一眼可见

## 跨周预测成绩单（v2 新增）

- **维护位置**：每周 recap.md 的「跨周预测成绩单」节（追加不修改）
- **用途**：追踪各 agent 预测命中率，校准置信度；forecast 的 roundtable 时 lead 必读
- **数据来源**：本周 forecast.md 的预测总表（置信度 + 提出者）+ 本周实际结果
