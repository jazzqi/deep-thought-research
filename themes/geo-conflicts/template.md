### 0. 执行摘要（TL;DR）— 3~5 行

```
- 第一触发器：霍尔木兹通航状态 / 中东新一轮打击（给出具体观察对象与时间窗）
- 基准情景：冲突受控于代理人层面，油价风险溢价 8-12 美元/桶（概率 ~60%）
- 上行尾部：海峡受阻 → Brent 110+，通胀二次冲击（概率 ~15%）
- 下行尾部：停火/谈判实质进展 → 溢价回吐 5-8 美元/桶（概率 ~25%）
- 一句话组合含义：黄金/能源多头期权维持，风险资产减久期（若 X 触发则推翻）
```

> 30 秒抓取核心；正文可展开，此处只给结论。
> **格式**：加粗标签后必须留空格再接内容；emoji 最多 0-1 个（仅第一触发器可带国家 emoji，可省）。

### 1. 冲突态势速览（conflict map）

| 冲突线/热点 | 当前状态 | 升级/缓和方向 | 关键观察信号 | 对资产的主要传导 |

| 中东（以伊/红海/霍尔木兹） | 代理人战升级 | ↑ | 打击范围、通航、战争险保费 | 油价、航运、黄金 |

### 2. 情景树（★核心 — 概率 + 触发 + 传导 + 资产影响）

```
| 情景 | 概率 | 触发阈值/确认条件 | 传导路径 | 资产影响预判 |
|------|------|------------------|---------|-------------|
| 基准（受控升级） | ~60% | 代理人战，无海峡实质受阻 | 能源溢价温和 | Brent 75-85，黄金稳，风险资产震荡 |
| 升级（能源受袭） | ~20% | 打击炼油/出口设施，通航下降 | 能源→通胀→央行路径 | Brent 95-110，美债上行，风险资产 -5~10% |
| 失控（海峡受阻） | ~5% | 霍尔木兹实际关闭 >2 周 | 全球供给冲击 | Brent 110+，股债双杀，黄金/美元飙升 |
| 缓和（停火/谈判） | ~15% | 停火协议/制裁松绑 | 溢价回吐 | Brent -5~8，风险资产反弹，黄金回落 |
```

> **概率约束（硬要求）**：① 各情景概率合计必须 100%；② 概率必须给**参考基准**
> （reference class：历史类似情景的发生频率，如"1990/2022 式海峡受阻平均持续 X 周"），
> 禁止凭空给概率（Convex schema base-rate 要求）；③ 每档必须有可观察的触发阈值，
> 无阈值的档位不许写（G-22：信号必须带 examples）。
> ④ 情景档位可增减（合并/细分），但至少保留 基准 + 一个尾部。

### 3. 风险溢价分解（★核心 — 当前定价已含多少地缘溢价）

```
| 资产 | 当前水平 | 公允价值锚 | 地缘溢价估算 | 溢价回吐触发 |
|------|---------|-----------|-------------|-------------|
| Brent | 78.5 美元/桶 | 68-70（供需锚） | +8-10 美元/桶 | 停火协议、OPEC+ 增产确认 |
| 黄金 | 3,270 美元/盎司 | —（避险+央行购金） | 含避险溢价，难拆分 | 风险偏好修复、实际利率上行 |
| VIX | 17.2 | 14-15（无冲突常态） | +2-3 | 冲突降级、股指企稳 |
| BTC | 61,000 美元 | — | 数字黄金叙事强度待验证 | ETF 资金流、与黄金背离信号 |
```

> **核心方法**：JPM/GS 式"公允锚 vs 市价 = 溢价"。每个溢价估算给推导依据
> （期权偏斜 / 战争险保费 / 期限结构 / 历史分位），无锚的资产写「难拆分」并给代理信号
> （G-04 诚实标注）。**溢价回吐触发**必须具体可观察。

### 4. 传导链分析（event → channel → asset → magnitude → timing）

```
| 事件 | 传导通道 | 受影响资产 | 幅度估算 | 时滞 |
|------|---------|-----------|---------|------|
| 霍尔木兹受阻 | 能源供给 → 油价 → 通胀 → 央行路径 | Brent/美债/美元/风险资产 | +20~40 美元/桶 → 10Y +20-40bp | 即时~2 周 |
| 出口管制升级 | 供给链 → 半导体板块盈利 → 估值 | SOX/AI 股/CNH | -5~15% | 1-4 周 |
| 红海袭船 | 航运 → 运价/保险 → 通胀 | 航运股/油价/欧洲 | 温和 | 数周 |
```

> 链条必须写到**终端资产**（不止第一层）；幅度给区间而非单点；时滞给范围。
> 每条链可引历史类比（1973/2022/2024 中东冲突）作为幅度锚（reference class）。

### 5. 市场定价 vs 我们的判断（market-implied probability）

- 期权隐含：VIX 结构 / 原油期权偏斜隐含的升级概率 ≈ X%（给出计算依据）
- 我们的评估：情景树基准概率 ≈ Y%，与市场定价的差距 = 潜在错配方向
- 历史类比：本次冲突与 1973/2022 RU-UA/2024 以伊的异同（供给敞口/闲置产能/央行响应）

> **本节的目的是找错配**——市场定价 vs 我们概率树的差异才是 Alpha（G-24 可交易性判据）。

### 6. 避险资产联动（haven sequencing）

- 黄金 vs BTC：同涨 = 避险真需求；BTC 独跌 = 流动性挤压（数字黄金叙事失效信号）
- 抢跑/滞后：通常 黄金/美债 > 美元/日元 > 风险资产，但每次冲突结构不同，需标注本次节奏
- ETF 资金流 / 期货净多头佐证（有数据才写，无则标注缺失）

### 7. 对组合的含义 + Falsifiable trigger

```
- 黄金：超配/标配（基准情景下对冲尾部）
- 能源：低配转中性 + 看涨期权（若海峡风险抬头）
- 美债：中久期（通胀二次冲击对冲）
- 美元：中性偏多（避险 + 利差）
- 风险资产：减久期、降 beta（升级情景）
- **Falsifiable trigger**：若 X 事件发生（具体可观察），基准情景被推翻，切换至升级/失控交易
```

## 二、写作硬规则（行文格式）

### 1. 服务投资决策，不输出政治立场

- 冲突分析只评估**对资产定价的传导**（能源/航运/避险/风险偏好/通胀预期），不站队、不评判战争正义性
- 禁止出现政治宣传性表述（"侵略/正义/解放"等价值判断词）；用中性事实陈述（"X 方对 Y 目标实施打击"）

### 2. 归属与署名（WRITING_GUIDE 约束）

- 共识/综合判断用「我们」；个人观点必须 `**{agent_id} 视角：**` 开头
- 禁止无署名第一人称（`我的判断`/`我认为`）；引用他人观点保留原归属

### 3. 概率与数字纪律

- 概率给区间或精确值 + 参考基准（reference class），禁止裸给概率
- 数字带单位与时间；幅度给区间；无锚不编（写「难拆分」+ 代理信号）
- 预测必须可证伪（带触发条件或数值区间）

### 4. 信息结构（金字塔原理）

- 每节首句给结论 → 分层论据 → 数据来源
- 关键判断/分歧处充分展开讲透因果（2-4 段），不因求简牺牲关键信息
- 观点段 200-400 字；单节不超 1500 字

### 5. 禁止项

- 禁止 session 目录名/manual/miss 等内部元数据出现在正文（G-08）
- 禁止无溯源的具体数字断言（G-04）
- 禁止把"不知道"写成模糊判断——写"数据缺失"或给出代理信号
