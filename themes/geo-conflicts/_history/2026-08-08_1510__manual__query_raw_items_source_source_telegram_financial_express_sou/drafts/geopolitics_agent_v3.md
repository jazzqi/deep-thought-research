# 地缘冲突与黑天鹅

## Big Picture

当前地缘格局不是所有战线同步升级，而是由霍尔木兹的高凸性能源风险、俄乌的慢变量制裁风险、红海与也门的航运外溢风险共同构成分化体系。霍尔木兹连接军事威慑、原油出口、商船保险、港口装运和全球通胀，是最可能把政治标题迅速转化为资产价格跳变的节点。2026年8月8日，市场同时收到美方寻求摆脱伊朗战事、霍尔木兹通行安排可能改善，以及也门西部冲突升级、俄罗斯炼厂遭袭等相反信号。核心矛盾不在于是否出现谈判，而在于谈判能否持续改变船东复航、战争险承保、AIS流量和能源装运。黄金强于BTC，说明传统避险和储备需求仍占主导；BTC上涨则仍混合了流动性与风险偏好因素。

## 0. 执行摘要 TL;DR

- **第一触发器：** 霍尔木兹是否出现连续商船中断、战争险承保收紧、AIS流量下降或海湾装运量下降。
- **基准情景：** 谈判和护航安排支持有限通行，冲突维持高波动但未形成长期封锁；参考概率45%。
- **上行尾部：** 商船连续受袭、扣押、布雷，或能源设施遭攻击并导致出口实质下降；升级与失控合计参考概率40%。
- **下行尾部：** 协议落地后商船、保险、AIS和装运同步恢复，原油风险溢价回吐；参考概率15%。
- **一句话组合含义：** 保留黄金与能源供给冲击保护，降低高贝塔和长久期暴露；只有在实物流量连续恢复后，才降低对冲成本。

## 2. 情景树：霍尔木兹决定能源风险的凸性

概率是投资参考基准，不是统计频率。参考类是历史上海上冲突通常先造成局部航运、保险和绕行冲击，再通过护航、临时安排或谈判恢复；持续全面封锁属于低频尾部。当前新闻同时包含谈判进展和也门、炼油设施冲突，因此不能仅依据协议标题将缓和情景设为主导。

| 情景 | 概率 | 触发阈值/确认条件 | 传导路径 | 资产影响 |
|---|---:|---|---|---|
| 基准：高风险下有限通行 | 45% | 未出现连续大规模封锁；拦截、事故不连续；仍有商业船舶通行 | 谈判与冲突并存 → 保险和运费维持高位 → 原油保留风险溢价 | 原油和运费偏强，黄金有支撑，权益与信用承压但不必然系统性下跌 |
| 升级：通行量明显下降 | 25% | 连续数日出现商船袭击、扣押、布雷或绕行；船东暂停承保；海湾装运出现可确认下降 | 航运中断 → 能源近月紧张 → 成品油价格与通胀预期上升 | 原油、成品油、LNG上涨；黄金偏强；BTC可能受美元流动性收紧压制；权益和信用利差走弱 |
| 失控：实质封锁或区域扩散 | 15% | 一周以上无大规模商业通行，或确认布雷、大规模交战；能源设施、港口或护航力量遭直接攻击 | 供给缺口 → 通胀冲击 → 央行宽松预期后移 → 股债风险重估 | 原油跳升，进口国资产受压；美元和短久期避险资产受益；黄金可能先因保证金压力波动后走强 |
| 缓和：协议与通行同步恢复 | 15% | 协议文本落地，且连续多个航次安全通过；保险承保恢复；AIS流量与港口装运同步回升 | 政治缓和 → 实物流量恢复 → 供应冲击预期下降 | 原油、运费和保险回落；黄金部分回调；风险资产和运输资产修复 |

**soros 视角：** 当前最容易被市场误读的是“谈判进展”与“风险解除”的等价化。谈判新闻可以在数小时内压低原油，但保险人和船东不会仅凭联合声明恢复风险承保。因此，协议落地后的第一轮油价回落未必是趋势信号，可能制造“先缓和、后反转”的交易结构。只有连续航次、保险、AIS和装运同时改善，缓和情景才应获得更高权重。

**geopolitics_agent 视角：** 四档概率的核心不是预测协议能否签署，而是区分“政治安排”与“商业运行”。参考历史上局部海上危机通常可以通过护航和外交安排避免长期全面封锁，基准情景仍应高于失控情景；但当前多条冲突线同时作用于能源和航运，升级与失控合计达到40%，足以支持组合保留尾部保护。若连续商业数据未改善，缓和概率不应因为新闻标题而机械上调。

## 5. 市场定价 vs 我们的判断

### 市场定价

当前可观察的市场反应偏向有限缓和：8月8日快讯称布伦特暗盘跌破82美元/桶、日内跌幅超过1.6%；新闻数据库同时显示美方寻求摆脱伊朗战事、霍尔木兹通行安排出现积极信号。原油下跌说明市场已交易部分“通行安排改善”的预期，但不代表海运供给已经恢复。

PAXG周线由4,071.17美元升至4,336.65美元，BTC周线由63,550.00美元升至64,974.30美元。黄金涨幅和趋势位置均强于BTC，说明市场仍保留传统避险和储备资产暴露，而不是全面进入风险偏好交易。

### 我们的判断

我们采用45%基准、25%升级、15%失控、15%缓和的概率树。与市场的错配不在于市场完全忽视冲突，而在于市场可能把“协议接近”过快等同于“航运和能源供给恢复”。若协议文本公布但商船、保险、AIS和装运没有同步改善，原油的缓和定价存在反转风险。

本轮没有取得原油期权偏斜、VIX期限结构、战争险费率或实时霍尔木兹通行数据，不能计算期权隐含升级概率，也不能给出精确地缘溢价美元数值。可执行的替代判断是：即时新闻溢价已经收缩，但实物流量风险尚未确认解除。

**soros 视角：** 目前更值得交易的不是“原油应该上涨还是下跌”，而是新闻冲击与实物确认之间的时间差。谈判新闻压低近端价格，冲突新闻又通过保险和航运风险保留上行尾部，市场可能处于低波动缓和叙事与高凸性供给风险并存的状态。组合上应使用有限成本的尾部保护，而不是用现货追逐单一方向。

**geopolitics_agent 视角：** 市场已经对“即时封锁”进行了部分去风险，但尚未完成对“协议失效后重新中断”的定价。原油下跌是市场对外交消息的快速反应，黄金走强则反映更长期的储备、货币和多战区风险。两者分化意味着不能用油价单一变量代表地缘风险总水平；应优先观察商业航运和能源装运，而不是继续追逐新闻标题。

## 6. 避险资产联动

当前更像“结构性防御”，而不是全面恐慌。

- **黄金：** PAXG日线最新收盘4,336.65美元，接近样本高点4,360.80美元；周线由4,071.17美元升至4,336.65美元，涨幅约6.5%。趋势相对强势，但混合了利率、美元和央行储备因素。
- **BTC：** BTC日线最新收盘64,974.20美元，低于样本高点66,924.10美元；周线由63,550.00美元升至64,974.30美元，涨幅约2.2%。BTC和黄金同步上涨，但幅度和趋势位置弱于黄金，不能证明BTC已经成为稳定的地缘避险资产。
- **黄金与BTC的区别：** 黄金的危机对冲属性更稳定；BTC在流动性宽松时可以表现为“数字黄金”，但在美元流动性收紧、权益下跌和保证金压力上升时，更可能表现为高贝塔风险资产。
- **美元、美债、日元：** 本轮没有取得可靠的多周期行情，不能声称它们已经同步进入避险交易。
- **可证伪信号：** 若黄金继续走强而BTC、全球权益和信用资产同步下跌，说明避险需求偏向传统资产；若黄金、BTC和权益同步上涨，更可能是流动性或风险偏好改善；若BTC显著跑赢黄金且美元走弱，地缘避险解释应降权。

## 7. 对组合的含义 + Falsifiable trigger

我们建议以“有限通行基准加尾部保护”构建组合，而不是押注长期封锁。

- **黄金：** 中性偏高配置，承担协议反复、制裁外溢和多战区联动的尾部对冲。
- **能源：** 不追逐谈判后已经回落的现货价格；可用有限成本的上行期权或能源供应链暴露对冲失控情景。
- **风险资产：** 降低高贝塔、长久期和对全球运输稳定性高度敏感的资产暴露。
- **债券：** 维持中久期，避免把美债视为单向避险。若冲突造成供给型通胀，长久期债券可能受到实际利率和通胀预期双重压制。
- **BTC：** 按流动性和风险偏好资产管理，不将其等同于黄金。
- **美元：** 方向上具备避险属性，但由于本次缺乏美元和利率行情，配置保持中性偏多，不作激进押注。

**Falsifiable trigger：**

1. 若连续观察期内商船航次恢复、保险承保恢复、AIS流量回升、港口装运恢复，则基准情景向缓和情景移动。
2. 若连续数日出现商船袭击、扣押、布雷或主要船东停止承保，则基准情景被推翻，升级概率上调。
3. 若能源设施遭袭并出现可验证出口下降，直接进入失控或区域扩散评估。
4. 若俄罗斯能源制裁正式生效且出口量下降，俄乌线的能源风险从慢变量升级为全球能源冲击线。
5. 若黄金相对BTC的强势继续扩大，同时全球权益和信用资产转弱，组合应增加传统避险并降低BTC风险敞口。
