## 🚫 blocker

- **情景树的“触发阈值”仍未达到可执行标准。** 虽然四档情景均列出概率、传导路径和资产影响，但多个关键条件只有定性描述，没有数值区间或明确统计口径。例如“连续数日”“明显下降”“一周以上无大规模商业通行”“连续多个航次”“港口装运同步回升”均未定义具体天数、船舶数量、AIS流量降幅、保险费率变化或出口量降幅。根据审查规则，情景树缺少可操作阈值属于 blocker。至少应补充类似“连续3日商业船舶通行量较协议前7日均值下降50%以上”“主要战争险报价较基准周上升X%”“海湾原油装运量连续7日下降20%以上”等可验证条件；若无法取得数据，应明确写为“无法量化，暂不作为硬触发器”。

- **第7节 Falsifiable trigger 仍不可证伪。** “连续观察期内”“连续数日”“能源设施遭袭并出现可验证出口下降”等表述没有给出观察期长度和数值阈值。预测时间线也主要使用“维持高波动”“风险仍在”“黄金相对BTC保持强势”等方向性判断，缺少价格区间、波动率、通行量或时间点。应明确验证窗口，例如未来1—4周内、连续5个交易日、AIS流量恢复至协议前均值的80%以上等。

- **最新相关制裁事件没有纳入主体分析。** 本次交叉查询得到：2026年8月8日有“美国制裁两家伊朗加密交易平台，指控其协助规避制裁”的新闻。现稿只讨论霍尔木兹谈判、战争和能源设施，没有评估该制裁对伊朗制裁外溢、加密资产流动性、合规风险或谈判执行机制的影响，也未在“已知未知/观察清单”中列出。该事件未必改变霍尔木兹主情景，但属于与伊朗冲突和BTC分析直接相关的最新制裁信号，应至少补充为次级传导线，并说明其对能源通道情景的影响有限或尚未可量化。

- **部分新闻事实的来源和覆盖范围不一致，削弱了“完整世界模型”的可靠性。** 现稿第13节称数据来源包括 `telegram:Financial_Express`、行情数据和多源新闻，但本次重新查询显示 Financial Express 可核验的条目主要包括：美军高层寻找摆脱伊朗战事途径、也门西部冲突升级、伊尔斯基炼油厂起火、扎维耶炼厂罐体受击、布伦特跌破82美元和南海军事训练。霍尔木兹谈判进展主要由 BlockBeats 条目返回，而不是 Financial Express。正文应逐条标注实际来源，不能将不同来源合并为单一“新闻数据库”证据。

- **行情数字存在源记录冲突，不能继续作为精确事实使用。** 工作区 `reference.md` 中同一批历史记录出现多组不同值：PAXG最新收盘分别记为4,336.24、4,337.46、4,337.48、4,337.82和4,336.65美元；BTC最新收盘分别记为64,967.60、64,969.60、64,974.20和64,980.60美元；样本高低点也存在差异。现稿使用4,336.65、64,974.20等数值，但没有说明最终采用哪一次查询、交易所、时间戳和K线是否已收盘。应统一为一次可复核查询的结果，或改写成近似值并删除“最新精确收盘”措辞。否则第3、6节的涨幅和趋势结论存在数据基础不稳的问题。

- **“黄金强于BTC”这一结论有方向依据，但被写成过强的地缘因果解释。** 现稿用PAXG和BTC周涨幅比较支持“传统避险优先”，同时承认实际利率、美元、央行购金、流动性和加密资金流数据缺失。但在 Big Picture 中直接写“黄金强于BTC，说明传统避险和储备需求仍占主导”，证据不足，因为没有资金流、实际利率、美元或全球权益同步数据。应改为“与传统避险相对占优的解释一致，但无法排除利率、储备需求或加密流动性因素”。

## ⚠️ concern

- **概率合计正确，但参考基准仍过于裸化。** 45%+25%+15%+15%=100%，形式上合格；文档也说明概率是投资参考基准而非统计频率，并提到“历史上海上冲突通常先造成局部航运、保险和绕行冲击”。但没有给出参考样本、样本时期、相似事件数量或基准如何映射到45%/25%/15%/15%。这仍属于较弱的概率依据。建议补充“基于何类事件、观察窗口及为何调整当前基准”，或将精确点估计改为区间，例如基准40%—50%、升级20%—30%、失控5%—15%、缓和10%—20%，并说明区间不确定性。

- **“基准情景”与“缓和情景”的边界有重叠。** 基准情景写“仍有商业船舶通行”，缓和情景写“连续多个航次安全通过、保险承保恢复、AIS流量和港口装运同步回升”。但“仍有商业船舶通行”没有最低规模，可能与“连续多个航次安全通过”重叠。应将基准定义为低于恢复阈值的零散通行，缓和定义为达到明确的通行量、AIS和装运恢复阈值。

- **“升级”与“失控”的触发条件仍存在重叠。** 升级包括连续数日袭击、扣押、布雷和装运下降；失控包括一周以上无大规模商业通行、确认布雷、大规模交战或能源设施遭攻击。已确认布雷同时出现在两个情景中，应明确分层：例如单点布雷但仍有有限通行为升级；多点布雷并导致连续7日通行量低于基准50%为失控。

- **风险溢价表列出了“公允锚”，但没有公允锚的可计算形式。** 原油一栏的供需、库存、OPEC+和需求增长，PAXG一栏的实际利率、美元、央行购金，BTC一栏的流动性、风险偏好、资金流和网络使用，均只是因素列表，不是公允锚。文档已诚实说明无法拆分，也没有硬编精确地缘溢价，因此不构成“无锚硬编”的 blocker；但应改成“公允锚变量清单，当前缺少数据无法估计”，避免表格形式让读者误以为已完成锚定。

- **原油“跌破82美元/桶”不能单独证明战争溢价收缩。** 该价格来自 Financial Express 快讯，且是“暗盘”价格、日内跌超1.6%。没有现货结算价、期限结构、库存、OPEC+消息或期权偏斜，油价下跌可能包含需求、美元、供给预期和流动性因素。正文部分已作限制声明，但“市场已交易部分缓和预期”“即时战争溢价收缩”的表述仍应降级为“与缓和预期一致”。

- **俄乌部分遗漏了可交叉核验的制裁政策信号。** 查询结果显示2026年8月8日有“美国参议院通过俄罗斯能源制裁法案”的新闻，而现稿仅写“制裁是否正式生效”“制裁从议案转为正式执行”。这不是直接事实错误，但应在市场定价部分明确区分“参议院通过法案”与“正式生效、执行细则公布、出口实际下降”，否则读者无法判断政策距离实际供给冲击还有多远。

- **红海/也门信息覆盖不足。** 现稿写“也门西部军事冲突升级”，但没有给出袭船数量、航线绕行比例、运价、战争险或港口数据，因此只能支持“事件风险上升”，不能支持“航运外溢风险未解除”的强度判断。此前查询未返回可用红海条目，文档应明确该线的最新证据仅为地区冲突升级，商业航运影响尚未核实。

- **南海军事训练与系统性航运风险之间的距离解释不足。** 本次查询确认的是“南海部分海域进行军事训练、禁止驶入航行警告”，现稿已写“尚无商船受阻或系统性冲突确认”，这一限制是合理的；但“亚洲航运、半导体供应链、CNH”资产传导仍较宽泛，建议明确这些只是条件性尾部传导，而非当前市场已经发生的影响。

- **台海章节信息基础最弱。** 文档承认“本轮未取得足够可靠的新升级信号”，但仍保留“对资产传导”一整行。可保留作为监测框架，但应标注为“机制性情景，非当前事实判断”，并避免与有实际新闻证据的霍尔木兹、俄乌、南海并列为当前态势。

- **“美元方向上具备避险属性”“维持中性偏多”缺乏市场数据支撑。** 文档同时声明没有美元、美债、日元行情序列，因此配置建议只能是机制推断，不能形成方向性配置结论。建议改为“若美元指数和实际利率未反向验证，则不作激进美元多头押注”。

- **组合建议缺少仓位、期限和退出规则。** “黄金中性偏高”“降低高贝塔”“能源保留上行保护”“维持中久期”属于方向建议，不是可执行配置。若报告定位为投资 world model，至少应给出相对基准、适用期限和触发后的调整规则；若不提供仓位数据，应明确这是风险方向而非投资组合比例建议。

- **“公司财务、估值和一致预期不适用”的处理基本合理，但未覆盖受冲突影响的上市公司或行业代表。** 本主题不要求建立单一公司的完整估值模型，因此不构成 blocker；不过报告提及航运股、能源股、军工、炼化股、欧洲权益和半导体供应链，却没有对应公司财务、估值或分析师预期。应二选一：删除个股/板块投资含义，或补充明确的行业/公司标的分析与最新公司新闻核验。

- **“美军高层寻找摆脱伊朗战事”是消息人士说法，正文应持续保留信源不确定性。** 现稿在部分位置简化为“美方寻求摆脱伊朗战事”，容易从匿名消息变成官方政策事实。建议统一写成“据消息人士称”，并与正式协议、官方文本、通航数据分开。

- **概率总和通过形式校验：** 45%、25%、15%、15%合计100%，没有出现概率缺项或加总错误。

- **情景树结构完整：** 四档情景均包含概率、触发条件、传导路径和资产影响，框架层面符合审查要求；主要问题是阈值尚未数值化，而不是结构缺失。

- **文档没有明显政治立场表述。** “失控”“升级”“缓和”等是风险情景标签；对美、伊、俄、乌等各方的描述基本采用新闻归因和资产传导语言，没有出现支持或谴责某一方的立场性表达。匿名消息也基本被写成消息来源，而非作者事实断言。
