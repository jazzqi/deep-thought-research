# 地缘冲突与黑天鹅

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新，不要将其当作静态 ground truth。**

> 本主题跟踪全球主要地缘冲突局势的发展与各类黑天鹅事件，评估其演进路径与对资产定价的影响。
> **服务对象是资本市场投资决策，而非政治分析**——只评估冲突/事件对资产的传导，不输出政治立场。

## 范围

**覆盖**：
- **主要地缘冲突** — 正在进行的战争/冲突与主要地缘关系线的紧张态势：
  - 热战/军事冲突（美伊、俄乌、台海潜在风险、中东其他热点：红海/胡塞、以伊等）
  - 大国关系线（中美科技封锁/贸易/资本流动、中日、欧美关税/能源/监管、美俄对抗）——即使未到热战，关系恶化本身也是资产定价变量
  - 制裁与贸易摩擦（出口管制、关税升级、金融制裁：SWIFT/资产冻结）
  - 关键地缘节点（霍尔木兹、马六甲、红海/苏伊士、巴拿马）的紧张态势
- **黑天鹅/尾部事件** — 低概率高影响：主权违约/机构暴雷、供应链冲击、政策突变、恐怖袭击/网络攻击
- **避险资产定价** — 冲突/黑天鹅下的避险资金流向：黄金、比特币（数字黄金叙事）、美元、美债、日元的相对表现与抢跑/滞后节奏
- **对资本市场的传导分析** — 每个事件评估其对能源/避险资产/风险资产/相关板块的定价影响与时间窗口

**不覆盖**：
- 与资本市场定价无关的纯政治/外交分析
- 单一资产的微观交易策略（归属对应 theme）
- 与资产定价无关的孤立区域事件

## 分析框架

- **情景树（Scenario Tree）** — 每个热点建立 基准/升级/失控/缓和 四档情景，每档带概率（参考基准）+ 触发阈值 + 传导路径 + 资产影响（JPM/GS 范式）
- **风险溢价分解（Risk Premium Decomposition）** — 拆解当前资产价格中已含多少地缘溢价（公允锚 vs 市价），评估市场定价充分性
- **传导链分析** — 事件 → 通道（能源/航运/避险/通胀/政策）→ 资产 → 幅度 → 时滞，写到终端资产
- **避险资产联动** — 黄金/BTC/美元/美债/日元的抢跑与滞后节奏，数字黄金（BTC）与实物黄金的分化信号
- **市场定价 vs 现实** — 期权隐含概率/波动率结构 vs 我们概率树的错配 = Alpha 方向
- **黑天鹅概率评估** — 尾部事件发生概率、升级路径、影响幅度，用历史类比（reference class）校准，不凭空给概率
