# 颠覆式创新扫描 — 报告结构模板 v1

> 本文件是 `themes/disruptive-innovation/index.md` 的结构蓝本（v1，2026-08-08 冷启动创建）。
> **读者定位**：专业投资人。本主题不是单一标的，而是**跨领域早期信号雷达**——
> 回答三个问题：
> ① 哪些技术/商业模式正在穿越颠覆式创新的关键拐点（从 Demo 到 Product、从利基到主流）？
> ② 这些创新的当前证据强度如何——是演示、是早期产品、还是正在渗透主流？市场定价了多少？
> ③ 我该关注哪些信号来提前确认/推翻判断，哪些领域存在被低估的范式迁移？
>
> **结构 = SEED 顶层节（publish 识别）+ 领域雷达子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；领域子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许「信号强度评估表」首列用 emoji，正文一律文字；
> ③ **数字带单位与时间**（`Grok 月活 3.2 亿（2026-08）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← 宏大叙事（200-400 字，跨领域综合判断，结论先行）
## 共识                 ← 3-6 条共识 + 少数派（relay 最后一人维护）
## 各维度分析            ← ★ 唯一大容量节：按创新领域组织（下挂 ### 子节）
## 预测时间线            ← 6 列表格（可证伪预测，只追加不修改）
## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
## 更新日志              ← publish 自动维护，无需写
```

> **重要**：`## 各维度分析` 是唯一大容量内容节。所有领域分析写在这里的
> `### 子节` 中。**不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。

## 二、各维度分析 — 领域雷达子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的领域就写哪些。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。
>
> **每个领域子节必须回答三件事**：
> 1. **当前状态** — 该领域最值得注意的新证据（带来源与日期）
> 2. **成熟度定位** — 技术成熟度 S-curve 位置（研究/原型/Demo/早期产品/主流渗透）
>    + **Demo vs Product 检验**：是演示还是可量产产品？离真实采用还有多远？
> 3. **投资信号** — 范式迁移信号强度 + 跟踪指标 + 时间窗口

### ### AI / 前沿技术（模型能力 / 推理成本 / 智能体落地）

**覆盖范围**：前沿模型能力跃迁、推理成本曲线、Agentic AI 落地、具身智能、
AI 基础设施瓶颈转移。**主导视角**：ai_specialist（能力评估）+ karpathy（工程现实性）。

```
**当前状态：** 一句话（含最新模型/产品/数据证据与日期）
**成熟度定位：** S-curve 位置 + Demo vs Product 检验（karpathy 视角）
**能力视角（ai_specialist）：** 能力跃迁与可验证证据
**投资信号：** 范式迁移方向 + 跟踪指标 + 时间窗口 + 置信度
```

### ### 生物科技 / 医疗（基因编辑 / 新药 / 疗法突破）

**覆盖范围**：基因编辑（CRISPR 等）、GLP-1 类疗法、AI 药物发现、
细胞疗法、诊断技术突破。**主导视角**：ai_specialist（AI 制药）+ buffett（商业化验证）。

```
**当前状态：** 一句话（含最新临床/审批/销售证据与日期）
**成熟度定位：** S-curve 位置 + 临床→商业化的关键门槛
**商业化视角（buffett）：** 从科学验证到商业模式跑通的现实检验
**投资信号：** 监管/临床里程碑 + 市场空间 + 置信度
```

### ### 能源 / 材料（核聚变 / 固态电池 / 新材料）

**覆盖范围**：核聚变商业化进展、固态电池量产、氢能、光伏/储能技术迭代、
关键材料替代。**主导视角**：karpathy（工程可实现性）+ tech_generalist（产业进度）。

```
**当前状态：** 一句话（含最新工程/量产/成本证据与日期）
**成熟度定位：** S-curve 位置 + 成本曲线下降证据
**工程视角（karpathy）：** 物理可行性 → 工程可实现性 → 经济可行性的阶梯
**投资信号：** 量产里程碑 + 成本突破点 + 置信度
```

### ### 消费 / 商业模式（平台变革 / 新零售 / 支付重构）

**覆盖范围**：新商业模式颠覆传统行业（平台化、订阅化、AI 原生体验）、
中国/全球消费降级与升级并存、支付与金融科技重构。**主导视角**：soros（叙事）+ buffett（商业模式质量）。

```

**成熟度定位：** 渗透率位置（早期 adopt / 主流渗透）
**商业模式视角（buffett）：** 单位经济性与护城河是否成立
**投资信号：** 渗透率/份额/单位经济性拐点 + 置信度
```

### ### 其他前沿（太空 / 机器人 / 量子 / 脑机）

**覆盖范围**：太空商业化、人形机器人量产、量子计算、脑机接口、

## 七、写作硬规则（行文格式）

### 1. 归属与署名（WRITING_GUIDE 约束）
- 共识/综合判断用「我们」；个人观点必须 `**{agent_id} 视角：**` 开头；禁止无署名第一人称

### 2. 概率与数字纪律
- 概率给区间或精确值 + 参考基准；数字带单位与时间；幅度给区间；无锚不编（写「数据缺失」+ 代理信号）
- 预测必须可证伪（带触发条件或数值区间）

### 3. 数据纪律（全部工具查询，不注入数值）
- 新闻：`query_raw_items`（关键词覆盖领域+公司+技术词，如
  `grok`/`agentic ai`/`crispr`/`glp-1`/`核聚变`/`solid state battery`/`人形机器人`；
  source 首选 `telegram:Financial_Express` 实时快讯，次选 hackernews/solidot/36kr）
- 可交易标的：`QueryLongbridgeByRouteTool` 查询受影响上市公司（如 AI 产业链、
  减肥药相关、机器人标的）的基本面/一致预期/最新新闻
- 宏观背景：`query_indicators`（利率/流动性/风险偏好）
- **判断必须来自查询到的事实**（新闻/数据），无数据写「数据缺失」+ 代理信号（G-04 诚实标注），禁止编造

### 4. 信息结构（金字塔原理）
- 每节首句给结论 → 分层论据 → 数据来源；关键判断/分歧处充分展开讲透因果

### 5. 主题特有纪律（颠覆式创新雷达）
- **区分「演示」与「产品」**：凡涉及新技术里程碑，先做 Demo vs Product 检验——
  是实验室演示、试点、还是真实用户/真实收入？没有产品化证据一律按早期信号处理
- **避免线性外推炒作**：技术进展 ≠ 商业成功；引用里程碑时标注成熟度阶段
- **交叉融合敏感度**：AI+生物、AI+能源、AI+机器人的交叉点常孕育最大机会，注意跨领域信号
- **长期视角**：本主题多为 1-5 年视角，避免把短期价格波动当作范式迁移证据

### 6. 禁止项
- 禁止 session 目录名/manual/miss 等内部元数据出现在正文（G-08）
- 禁止无溯源的具体数字断言（G-04）
- 禁止把"不知道"写成模糊判断——写「数据缺失」或给出代理信号
