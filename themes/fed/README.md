# 美联储（fed）

> 利率路径、资产负债表周期与流动性体制的转换节点。Fed 是宏观资产定价的核心坐标——所有跨资产定价都以此为锚。

## 范围

覆盖美联储货币政策全谱系：FOMC 利率决议与点阵图演化、资产负债表扩张/收缩（QE/QT）、流动性条件（储备金余额、RRP、SOFR 压力）、前瞻指引与预期管理、通胀/就业双 mandate 的动态权衡。**不覆盖**：具体财政政策的设计细节（但跟踪财政-货币协同效应）、信用风险定价的微观结构。

## 核心问题

- **利率路径偏差**：市场定价 vs Fed 点阵图之间的 gap 有多大？反身性机制会驱动 gap 向哪一侧修复？——当前 Fed 维持鹰派观望，市场定价了额外 25-50bp 降息，这一认知偏差究竟是市场自我实现还是市场误判？
- **中性利率（R\*）是否已结构性上移？** ——AI 投资浪潮、财政赤字持续化、绿色转型资本支出是否正在永久性抬高均衡利率，使"higher for longer"从周期口号变为体制现实？
- **QT 终点在哪里？** ——储备金稀缺何时出现？SRP（准备金稀缺溢价）何时重新定价 repo 市场？ON RRP 余额的下降路径提供了什么关于流动性环境的领先信号？
- **收益率曲线的宏观含义**：曲线正常化（不再倒挂）意味着什么——经济软着陆 confirmation 还是衰退前最后的 inversion unwind？曲线的"陡峭化"交易隐含的周期定位是什么？
- **Fed 独立性处于什么状态？** ——中期选举年政治压力、财政主导风险（fiscal dominance）对货币政策的渗透边界在哪里？
- **长期债务周期的位置**：如果以 50-75 年的 Kondratiev 长波来看，当前全球信用扩张的哪个阶段？利率的正常化是技术性回调还是长波从通胀到通缩的结构切换？

## 数据源

- **FOMC 会议日历 & 声明** — 利率决策、经济预测摘要（SEP）、点阵图
- **CME FedWatch / OIS 曲线** — 市场隐含利率路径，用于 gap 量化分析
- **美联储 H.4.1（储备金余额）** — 银行系统准备金总量、RRP 余额、TGA 余额
- **SOFR / EFFR 利率** — 短端流动性压力信号
- **鲍威尔/其他 FOMC 成员讲话全文** — 通过 NLP 量化鹰鸽倾向迁移
- **TIPS 市场（盈亏平衡通胀率）** — 通胀预期、实际利率、通胀风险溢价
- **美国一级交易商调查** — 华尔街对利率路径的共识 vs 分歧
- **财政预算 & 债务发行计划** — treasury issuance 对期限溢价的挤出效应
- **全球央行储备数据（IMF COFER）** — 美元储备占比变化，去美元化趋势的量化
- **商业地产抵押贷款/区域银行信用风险指标** — 金融稳定视角下的 Fed"应激条件"

## 关联主题

- **global-macro** — Fed 政策是全球宏观分体制（divergent regime）的核心驱动力；中国的政策空间也受 Fed 制约
- **qqq** — 利率路径直接决定科技股 DCF 估值中的分母端；QT 进度影响成长股流动性溢价
- **btc / cryptocurrency** — 全球美元流动性的"溢出效应"；利率预期转向是加密资产反转的关键催化剂
- **energy** — 油价冲击→通胀预期上升→Fed 更鹰派；反向：Fed 降息→经济软着陆→能源需求韧性
- **us-iran** — 中东地缘冲突→油价地缘溢价→二次通胀风险→Fed 政策空间收窄
