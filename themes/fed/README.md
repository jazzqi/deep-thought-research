# 美联储

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

美联储货币政策路径：利率决议、点阵图/SEP、资产负债表政策（QT）、流动性条件、通胀/就业双 mandate 动态权衡，以及政策传导（二阶效应）与多路径概率评估。

## 报告结构（六大模块，详见 template.md）

> **动笔前必须用 ReadThemeDocsTool 读取 `themes/fed/template.md` 作为结构蓝本。**

1. **政策基准与会议时间表** — 当前联邦基金区间/上次决议/投票分歧 + 未来 12 个月 FOMC/发布会/纪要/Jackson Hole 时间表，提前准备
2. **关键经济指标监测表** — CPI/PCE/非农/失业率/JOLTS/零售/ISM 等表格统计（前值/预测/实际/权重）
3. **FOMC 成员立场矩阵** — 主席（Warsh）与现任成员表格管理，近期言论（带来源层级），鹰/鸽倾向与投票预测
4. **点阵图推算（Dot Plot Projection）** — 成员立场矩阵的合成输出：把 18 位参与者的鹰/鸽立场映射为年末利率预测点，汇总分布 + 推算中位数，与上次官方 SEP 和市场定价对比
4. **市场定价与业界看法** — 市场定价（期货/互换/收益率）vs 卖方共识 vs 我们判断，识别偏差
5. **政策二阶效应** — 政策利率 → 短端 → 长端/美元/信贷 → 风险资产的传导链
6. **政策路径与概率评估** — 降息/按兵不动/加息等多路径，各给概率 + 触发条件 + 证伪条件

## 分析框架

- **政策基准优先** — 每轮先立当前政策基准（利率区间、上次决议、投票分歧、QT 进度），无基准不写政策判断
- **会议时间表** — FOMC 决议/发布会/纪要/Jackson Hole/听证会/褐皮书全量跟踪，提前识别下一个政策拐点窗口
- **数据仪表盘** — 通胀（CPI/PCE，注意 CPI≠PCE 口径）/就业（非农/失业率/JOLTS）/增长/流动性四组指标，标清前值与数据日期
- **成员立场矩阵** — 逐人追踪主席与票委近期言论，预测投票；来源分级（官方稿 > 一手采访 > 新闻转引）
- **点阵图推算** — 立场 → 年末利率预测点 → 18 人分布 + 中位数，与上次 SEP/市场定价对比（推算非官方，必须标注）
- **市场 vs 业界 vs 我们** — 市场定价与卖方共识的偏差是最大 alpha 来源；无市场数据不做「市场押注」强度判断
- **二阶效应** — 政策决策的传导链分析，区分已验证价格数据与机制假设
- **多路径概率** — 至少三档路径（降息/按兵不动/加息），主观概率 + 触发条件 + 可证伪条件
- **体制判断** — soft landing vs hard landing vs no landing，每次 FOMC 的后验验证
- **独立性风险** — 政治施压/人事变动（如理事解雇事件）对政策可信度的影响，纳入尾部风险
