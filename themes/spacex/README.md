# SpaceX

> SpaceX 在航天发射、卫星互联网和深空运输市场的生态版图扩展——从可复用火箭的经济性到空间经济基础设施的构建。

## 范围

**覆盖：**
- 猎鹰 9 号 / 猎鹰重型发射节奏：年度发射次数、复用比例、单次发射成本趋势
- Starship 研发进展：飞行测试里程碑、完全复用目标、载荷容量、火星任务时间表
- Starlink 卫星互联网：用户增长、收入规模 ARPU 趋势、D2C（Direct-to-Cell）服务
- Starlink 融资与估值：私募市场估值变化、二级市场交易、IPO 窗口预期
- 空间经济基础设施：全球宽带覆盖、低轨卫星通信竞争（OneWeb、Project Kuiper）
- NASA 合同与政府收入：Artemis 登月计划、货运/载人任务、军事发射合同
- 发射市场格局：SpaceX vs ULA vs 蓝色起源 vs Rocket Lab vs 中国民营航天
- 星链对传统电信行业的颠覆潜力：全球 5G 补盲、回传网络、应急通信
- 火星任务与 Elon Musk 长期愿景对 SpaceX 战略方向的驱动

**不覆盖：**
- SpaceX 企业治理、劳工关系、企业文化等内部议题
- 深空科学探测（行星际科学 payload）的详细任务规划
- 中国航天（CNSA）和俄罗斯航天（Roscosmos）的详细竞争分析
- 航天保险、发射保险等金融衍生品
- 载人航天的乘客体验和太空旅游细节
- 不属于 SpaceX 的直接竞争范畴（如卫星制造、地面终端销售）

## 核心问题

- **Starship 经济性测算** — Starship 完全复用后单次发射成本能否降到 $10M 以下？这对当前发射市场格局有多大的颠覆力？
- **Starlink 何时 cash flow self-sustaining** — 星链从需要外部输血到正向自由现金流的转折点在哪里？用户饱和点何时到来？
- **IPO 估值框架** — 如果 SpaceX 上市，合理的估值区间？应该按发射业务（工业制造），还是按星链宽带（电信/TMT）估值？
- **发射频率 vs 需求匹配** — SpaceX 年发射 150-200 次的产能是否超过了全球有效需求？还是需求由 Starship 创造？
- **Kuiper 竞争的实际威胁** — Amazon Project Kuiper 的卫星制造和部署节奏能否真正挑战 Starlink 的 first-mover 优势？
- **政府收入依赖度** — NASA/DOD 合同在 SpaceX 总收入的占比变化？如果 Starship 成功，政府合同占比是增长还是下降？
- **二级市场估值隐含了什么预期** — 当前二级市场估值来自公开市场和私募，是否存在估值溢价（Elon premium）？
