# SpaceX — 报告结构模板 v1

> 本文件是 `themes/spacex/index.md` 的结构蓝本（v1，2026-08-08 冷启动创建）。
> **读者定位**：专业投资人。SpaceX 是未上市公司——二级市场/一级市场信息是估值锚，
> 公开财务数据稀缺。报告要回答三个问题：
> ① 发射/Starlink/Starship 三大业务线当前处于什么阶段，市场如何定价？
> ② 哪些里程碑/信号是下一步股价（估值）的驱动因子，现在被低估还是高估？
> ③ 我该用什么方式参与（二级股权、概念股暴露、等待上市），什么信号会推翻我的判断？
>
> **结构 = SEED 顶层节（publish 识别）+ 业务线子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；业务线子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**第一触发器：** 星舰发射`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许表格首列用 emoji，正文一律文字；
> ③ **数字带单位与时间**（`Falcon 9 复用报价 ~$6,700 万（2026-08）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← 宏大叙事（200-400 字，三大业务线综合判断，结论先行）
## 共识                 ← 3-6 条共识 + 少数派（relay 最后一人维护）
## 各维度分析            ← ★ 唯一大容量节：按业务线组织（下挂 ### 子节）
## 预测时间线            ← 6 列表格（可证伪预测，只追加不修改）
## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
## 更新日志              ← publish 自动维护，无需写
```

> **重要**：`## 各维度分析` 是唯一大容量内容节。所有业务线分析写在这里的
> `### 子节` 中。**不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。

## 二、各维度分析 — 业务线子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的维度就写哪些。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。

### ### 发射经济性（发射次数 / 复用率 / Starship 成本颠覆）

**覆盖范围**：Falcon 9 复用报价与毛利、发射节奏（次/月）、Starship 全复用对
发射成本的颠覆潜力、全球发射市场份额。

```
**当前状态：** 一句话（含最新发射/报价证据与日期）
**主导视角（tech_generalist）：** 发射经济性判断——复用率/成本曲线/份额
**财务视角（buffett）：** 发射业务现金流质量与资本开支回报
**宏观视角（soros）：** 政府订单/星盾等非市场收入的安全垫作用

| 情景 | 概率 | 触发阈值/确认条件 | 传导路径 | 估值影响预判 |
|------|------|------------------|---------|-------------|
| 基准（复用扩张） | ~60% | 发射节奏维持/提速，复用报价维持 | 收入稳增，估值靠倍数 | 二级估值跟随业绩上修 |
| 颠覆（Starship 复用成熟） | ~25% | Starship 高频复用 + 有效载荷入轨 | 发射成本数量级下降 | 二级估值大幅上修 |
| 停滞（发射节奏放缓） | ~15% | 发射推迟/事故停飞 | 收入预期下修 | 二级估值回调 |
```

> 概率合计必须 100% + 给参考基准（历史类比频率）；无阈值不写档位。

### ### Starlink 商业化（用户增长 / ARPU / 企业客户 / 现金流拐点）

**覆盖范围**：订阅用户数、ARPU、企业客户（海事/航空/政府）、现金流拐点、
与电信运营商的竞争与反垄断风险。

```
**当前状态：** 一句话（含最新用户/新闻证据与日期）
**主导视角（tech_generalist）：** 用户/ARPU/现金流拐点判断
**财务视角（buffett）：** Starlink 是否已过盈亏平衡、自由现金流质量
**宏观视角（soros）：** 地缘/监管对 Starlink 全球扩张的约束（如乌克兰事件）
```

### ### Starship 开发里程碑（进度 / 发射 / 有效载荷入轨）

**覆盖范围**：Starship 发射频次、轨道试飞、有效载荷入轨、助推器回收、
对 NASA/HLS 及后续任务的里程碑意义。

```
**当前状态：** 一句话（含最新试飞/新闻证据与日期）
**主导视角（tech_generalist）：** 里程碑进度 vs 计划表
**前瞻视角（karpathy）：** 技术跨越对发射成本结构的长期影响
```

### ### 空间经济与竞争格局（LEO 商业化 / 竞对）

**覆盖范围**：近地轨道商业化（通信/遥感/制造）S-curve、竞对
（Blue Origin、Rocket Lab RKLB.US、中国商业航天等）、SpaceX 生态位。

```
**当前状态：** 一句话
**主导视角（tech_generalist）：** 空间经济拐点与竞对相对位置
```

### ### 二级市场估值信号（未上市公司估值锚）

**覆盖范围**：SpaceX 未上市——二级市场股权交易价/估值、一级融资轮、
概念股（RKLB/ASTS 等）相对暴露。**估值信号必须来自查询到的事实**
（如新闻提及"SpaceX 现报 127.96 美元/贝莱德持股 5100 万股"），无数据写"数据缺失"。

```
**估值锚：** 二级/一级市场可得估值信号（带来源与日期；无则写"数据缺失"）
**概念股暴露：** 公开市场可交易标的与 SpaceX 的相关性
**估值判断：** 当前市场定价隐含的增长预期 vs 基本面证据（G-24：找错配方向）
```

## 六、写作硬规则（行文格式）

### 1. 归属与署名（WRITING_GUIDE 约束）
- 共识/综合判断用「我们」；个人观点必须 `**{agent_id} 视角：**` 开头；禁止无署名第一人称

### 2. 概率与数字纪律
- 概率给区间或精确值 + 参考基准；数字带单位与时间；幅度给区间；无锚不编（写「数据缺失」+ 代理信号）
- 预测必须可证伪（带触发条件或数值区间）

### 3. 数据纪律（全部工具查询，不注入数值）
- 新闻：`query_raw_items`（keyword: spacex/starlink/starship/星链/星舰；source 优先
  `telegram:Financial_Express` 实时快讯，次选 hackernews/solidot/36kr）
- 概念股：`QueryLongbridgeByRouteTool` 查询 RKLB.US 等公开标的
- 估值信号必须来自查询到的事实（新闻/数据），禁止凭空写估值数字
- 禁止无来源的财务断言；SpaceX 未上市，无公开财报 → 数字要标注"新闻披露/推断"

### 4. 信息结构（金字塔原理）
- 每节首句给结论 → 分层论据 → 数据来源；关键判断/分歧处充分展开讲透因果

### 5. 禁止项
- 禁止 session 目录名/manual/miss 等内部元数据出现在正文（G-08）
- 禁止无溯源的具体数字断言（G-04）
- 禁止把"不知道"写成模糊判断——写"数据缺失"或给出代理信号
