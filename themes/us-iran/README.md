# 美伊冲突（us-iran）

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建，其中的数据、事件和核心问题可能已过时。**

> **使其及时准确贴合现实世界。不要将本文档当作静态的 ground truth。**

> 美伊已处于实际战争冲突状态，在谈判与交火之间不断拉扯。本主题跟踪冲突的实时动态、军事/外交的交替节奏、以及对能源市场、全球通胀和风险偏好的传导。

## 范围

美伊战争的动态跟踪——交火烈度、战线变化、关键基础设施攻击（能源设施/航运/军事基地）、谈判窗口的开闭、第三方介入（海湾国家、以色列、俄罗斯、中国）。**不覆盖**：泛中东地区的其他非关联冲突。

## 核心问题

- **当前处于交火周期还是谈判窗口？** ——冲突在"打"和"谈"之间切换的节奏和触发点是什么？每次切换的驱动因素是军事进展还是外交压力？
- **关键基础设施的状态**：霍尔木兹海峡通行是否受影响？伊朗/海湾国家的石油出口设施是否被攻击？全球航运保险市场信号？
- **冲突的经济承受力**：双方还能打多久？伊朗的经济韧性（石油收入、制裁规避、中国支持）vs 美国/以色列的国内政治承受力
- **谈判的实质性进展**：停火/休战谈判的红线是什么？每次谈判破裂的直接原因是什么？第三方的调解角色（中国、俄罗斯、海湾国家、联合国）
- **对资产定价的传导**：油价的地缘溢价如何随战斗/谈判节奏波动？风险资产在冲突升级阶段的定价是否充分？避险资产（黄金、美元、美债）的反应模式
