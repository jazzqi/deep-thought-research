# AI 二阶效应与衍生投资机会 — 报告结构模板 v1

> 本文件是 `themes/ai-second-order/index.md` 的结构蓝本（v1，2026-08-09 冷启动创建）。
> **读者定位**：专业宏观/跨资产投资人。回答三个问题——
> ① AI 溢出到各领域（AI for Science / Agentic / AI 视频 / 工作流自动化 / 具身智能 / AI+能源）当前落地到哪一步，市场定价了多少？
> ② 哪个方向正在从「Demo」跨入「Product + 收入兑现」，产生范式升级与二阶赢家？上行/下行尾部被低估多少？
> ③ 我该怎么参与（直接标的 / 衍生链条 / 成本重构受益者），什么信号会推翻我的判断？
>
> **结构 = SEED 顶层节（publish 识别）+ 各维度方向子节（自由发挥）**。
> 顶层节标题必须精确匹配 publish 提取契约；方向子节标题可自由命名/增删。
>
> **格式三铁律**：
> ① **加粗后必须留空格**：`**当前状态：** 一句话`（禁止无空格——加粗解析失效）；
> ② **emoji 极度克制**：只允许「方向成熟度速览表」首列用 emoji，正文一律用文字；
> ③ **数字带单位与时间**（`某 AI 制药管线进入 II 期（2026-08）`），所有判断给置信度或概率。

## 一、顶层结构（SEED FORMAT，必须精确匹配）

```
## Big Picture          ← AI 二阶效应总判断（宏大叙事，200-400 字，结论先行）
## 共识                 ← 3-6 条共识 + 少数派（relay 最后一人维护）
## 各维度分析            ← ★ 唯一大容量节：按方向组织（下挂 ### 子节）
## 预测时间线            ← 6 列表格（可证伪预测，只追加不修改）
## 分歧地图              ← 4 列表格（观点带 agent_id 前缀）
## 更新日志              ← publish 自动维护，无需写
```

> **重要**：`## 各维度分析` 是唯一大容量内容节。所有方向分析写在这里的
> `### 子节` 中。**不要**创建 `## 0. 执行摘要` 这类编号顶层节——publish 无法识别会丢失。

## 二、各维度分析 — 方向子节（推荐框架，可自由增删）

> 下列 `###` 子节是**推荐框架**。本轮实际涉及的方向就写哪些，可合并可增删。
> 硬约束：内容必须落在 `## 各维度分析` 之下，否则不进定版。
>
> **每个方向子节必须回答三件事**：
> 1. **当前状态** — 该方向最值得注意的新证据（带来源与日期，工具查询，不注入数值）
> 2. **成熟度定位** — Demo vs Product vs 收入兑现；S-curve 渗透率阶段；单位经济性
> 3. **投资信号** — 方向判断 + 跟踪指标 + 时间窗口 + 置信度（含二阶赢家画像）

### ### AI for Science（生物医药/材料/化学/物理）

**覆盖范围**：AI 驱动的药物发现/临床设计、AI 材料发现、AI 物理/化学模拟、AI 科学基础设施（数据/算力/实验自动化）。**主导视角**：pharma_specialist + ai_specialist + karpathy。**上游**：biopharma 的 `index.md` 结论，不重复管线细节。

```
**当前状态：** 一句话（含最新证据与日期）
**成熟度定位：** 哪个环节已跨过 Demo（如 AI 设计分子进入临床）、收入模式是否成型
**单位经济性：** 研发周期/成本压缩幅度、CRO/平台收费模式验证
**投资信号：** 方向 + 标的（平台/管线/上游设施）+ 跟踪指标 + 置信度
```

### ### Agentic AI / 数字员工（FDE）

**覆盖范围**：编程 Agent、通用数字员工/自动化平台、多 Agent 协作、企业流程自动化、劳动力替代链条。**主导视角**：karpathy + ai_specialist。

```
**当前状态：** 一句话
**成熟度定位：** 从 Demo 到可交付产品的跨越、可靠性/成本/评估闭环、企业采购证据
**渗透信号：** 企业采用率、API 调用量、开发者生态的可观察指标
**投资信号：** 平台型 vs 垂直型；被替代劳动力的成本重构受益者
```

### ### AI 视频与内容生成

**覆盖范围**：视频生成（文生视频/图生视频/数字人）、内容生产成本曲线重构、广告/影视/游戏/短剧产业链影响。**主导视角**：ai_specialist + tech_generalist。

```
**当前状态：** 一句话
**成熟度定位：** 生成质量与成本曲线、商用门槛（影视级 vs 短视频级）
**渗透信号：** 内容平台采用量、广告素材生产迁移率、IP 变现
**投资信号：** 工具/分发/素材库/被重构产业的赢家与受损方
```

### ### 企业工作流自动化

**覆盖范围**：AI 原生 SaaS、Copilot 落地、垂直行业工作流（金融/法律/医疗/客服）、知识管理。**主导视角**：tech_generalist + munger。

```
**当前状态：** 一句话
**成熟度定位：** 付费留存、AI 收入占比、从工具到工作流重构的跨越
**投资信号：** 已兑现收入标的 vs 纯叙事标的（叙事≠订单）
```

### ### 具身智能 / 机器人

**覆盖范围**：人形机器人、具身大模型、工业/服务机器人、硬件+AI 融合。**主导视角**：ai_specialist + tech_generalist + karpathy。

```
**当前状态：** 一句话
**成熟度定位：** 量产时间表、BOM 成本下降、场景落地证据
**投资信号：** 整机/核心零部件/数据采集；警惕 Demo 型叙事
```

### ### AI + 能源

**覆盖范围**：AI 电力需求对能源的衍生拉动（数据中心电力）、AI 优化能源调度、核能/AI 融合。**主导视角**：dalio + tech_generalist。**上游**：energy 的 `index.md` 结论。

```
**当前状态：** 一句话
**成熟度定位：** 电力供需缺口量化、AI 节能优化落地
**投资信号：** 电力链受益标的 + 跟踪指标
```

## 五、数据纪律（硬性要求）

- 所有数字必须来自工具查询（query_raw_items / QueryLongbridgeByRouteTool /
  query_indicators），禁止 prompt 注入、禁止凭空编造（G-01 教训）。
- 无法从工具获取的数字写「（数据缺失）」并说明尝试了什么（G-04 诚实标注）。
- 方向进展断言必须有新闻来源支撑（禁止无来源的管线/商用/采用断言）。
- 区分「叙事/预期」与「实际收入/订单」：AI 叙事强但必须落到渗透率、收入占比、
  留存、单位经济性等可验证数据。
- 涉及公司财务的数字必须标注来源工具 + 关键参数 + 日期，记入 reference.md 溯源
  （`- {数据点}: {来源工具}({关键参数}) = {值}`）。
- 判断给置信度或概率；预测给可证伪的触发条件或数值区间。
- 服务资本市场投资决策，不输出政治立场。
