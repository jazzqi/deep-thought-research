# NVIDIA（AI 芯片龙头）

> NVIDIA 在 AI GPU 和数据中心加速计算领域的统治地位——从架构迭代、供应链约束到竞争格局的完整追踪。

## 范围

**覆盖：**
- NVIDIA AI GPU 产品线：Hopper → Blackwell → Rubin 架构路线图与量产节奏
- Datacenter 计算与网络业务收入趋势，DC 部门占总收入比重变化
- CoWoS 先进封装产能分配与供给瓶颈跟踪
- 数据中心 capex 周期与云厂商（AWS/Azure/GCP）GPU 采购节奏
- AMD MI 系列、自研芯片（TPU、Trainium、Gaudi）竞争压力评估
- 出口管制对中国市场收入的影响及合规应对
- GPU 定价能力与毛利率趋势
- NVLink、InfiniBand 等互连技术在 AI 集群中的渗透

**不覆盖：**
- Gaming GPU 细分市场（GeForce 消费级 GPU）的详细分析
- Automotive 和 Embedded 等非数据中心业务
- NVIDIA 公司治理、管理层变动等企业层面议题
- 日内或短期股价技术面分析
- 加密货币挖矿对 GPU 需求的周期性影响

## 核心问题

- **Blackwell 需求可持续性** — B200 需求确定性高，但订单能见度到几个季度？云厂商 GPU 采购是否存在重复下单（double-ordering）？
- **Rubin 架构节奏** — 2026 年 Rubin 是否能如期接棒 Blackwell？架构代际提升幅度是否足以维持溢价定价？
- **CoWoS 产能瓶颈** — 台积电 CoWoS 产能扩产节奏能否匹配 NVIDIA 出货目标？2026 年瓶颈是否从 CoWoS 转移到 HBM？
- **竞争侵蚀** — AMD MI400 和自研 ASIC（Google TPU v6、AWS Trainium 3）在特定工作负载上的性价比能否削弱 NVIDIA 的 >90% 市占率？
- **需求 vs 预期 gap** — 资本市场已充分定价 AI 叙事，如果 capex 增速放缓或企业推理部署不及预期，估值修正风险有多大？
- **出口管制风险升级** — 对华出口限制进一步收紧可能影响多少营收？替代合规芯片（H20 等）的利润率和需求如何？
- **AI 推理需求爆发 vs 训练需求** — Inference 工作负载增长能否接替训练成为下一波 GPU 需求驱动力？

## 数据源

- **财报/业绩会** — NVIDIA 季度 earnings（收入拆分、DC 部门毛利率、指引），重点关注数据中心收入和网络收入
- **台积电营收月报** — CoWoS 产能、先进制程（N4/N3）利用率，间接验证 NVIDIA 出货量
- **云厂商 capex 指引** — AWS、Azure、GCP 季度资本支出计划与 AI 服务器占比
- **SemiAnalysis / 供应链调研** — GPU 出货量估算、CoWoS 分配比例、BOM 成本拆解
- **SCA 出口管制追踪** — BIS 规则更新、实体清单变化对中国市场收入的影响测算
- **AMD/INTC 数据中心收入** — 竞品份额变化作为 NVIDIA 护城河的交叉验证
- **HBM 供应链** — SK 海力士、三星、美光的 HBM3E/HBM4 认证与产能分配
