# 中国互联网（Tencent / Alibaba / Meituan / Bilibili）

> 跟踪中国互联网平台的竞争再平衡、监管框架的稳态形成、以及头部企业从"增长优先"向"资本回报优先"的转型。

## 范围

**覆盖：**
- 腾讯——社交护城河（微信/QQ）的耐久性、游戏业务的版号与出海节奏、资本配置纪律（回购/分红），以及投资组合（美团/拼多多/快手等）的变现策略
- 阿里巴巴——云智能的利润爬坡、国内电商市场份额稳定化、国际业务（Lazada/AliExpress/Trendyol）的资本效率、管理层更替后的文化重塑
- 美团——本地服务（外卖/到店/闪购）的壁垒强度、骑手成本与 regulatory 合规成本、社区团购的效率改进、盈利能力拐点
- 哔哩哔哩（Bilibili）——用户增长与商业化的平衡、游戏 vs 广告 vs 直播的收入结构优化、盈亏平衡时间表
- 监管周期——从"强监管"到"常态化管理"的过渡、数据合规成本、反垄断对竞争格局的影响
- 消费复苏预期——中国内需恢复的速度和结构对平台商业化的驱动力

**不覆盖：**
- 个股的短期交易策略、技术分析或动量交易信号
- 非上市的创业公司（如字节跳动/Shein），除非作为竞争参照
- 全面的行业指数回顾——聚焦特定头部公司的个体分析
- 美股中概股的法律/退市风险（已在 global-macro 覆盖）

## 核心问题

1. **护城河再评估**：腾讯的微信生态是否仍然是无可替代的基础设施？阿里巴巴的电商护城河在拼多多和抖音的侵蚀下还能守住多少？当竞争加剧而增长放缓时，什么才是真正的持续竞争优势？
2. **监管稳态是什么**：中国互联网监管进入了一个可预测的新常态，还是仍存在政策反复的可能性？监管成本——从数据合规到反垄断到游戏版号——对所有者盈余的长期折损是多少？
3. **资本配置纪律的转折点**：Tencent 已开始大规模回购（2025 年至今累计 >1000 亿港元），阿里巴巴也加大了回购力度。这些公司是否完成了从"增长再投资"到"股东回报"的转向？这种转向是可持续的，还是竞争压力会迫使它们重新加大投资？
4. **消费复苏的真实斜率**：中国 GDP 4.7%、社零 1%、消费者信心 89.9——在这种宏观背景下，互联网平台的广告和佣金收入能有多大弹性？是 V 型反弹还是 L 型低迷？
5. **AI 投入的 ROI**：中国互联网巨头正在大举投资 AI（大模型、云计算）。这些投入的资本回报率如何？是必需的防御性支出（不做就会落后），还是能创造新的增量现金流？
6. **估值的安全边际**：经过三年调整，中国互联网的估值（Tencent ~15x PE, Alibaba ~10x PE）相比全球科技股是否提供了足够的安全边际？这些估值中包含了多少"中国折扣"（地缘政治、监管、治理），这个折扣是合理的还是夸大的？
