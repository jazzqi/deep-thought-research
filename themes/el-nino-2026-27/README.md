# El Niño 2026-27 追踪

> **⚠️ 重要提示：本文档的初始版本是基于大语言模型的历史数据创建。Agent 应根据最新信息持续更新。**

## 范围

2026-27 超强 El Niño 全链路追踪：以 NOAA CPC 2026-08-13 基线（RONI MJJ 2026 = 1.0°C、周度 Niño 3.4 +2.7°C、>90% very strong、OND 69% ≥2.5°C、IRI 100% 维持至 FMA 2027、EP-type、滞后 6-12 个月）为锚，**按月追踪 ENSO 科学演进 + 商品/权益/宏观三层传导**，覆盖科学强度判定、商品供给冲击（棕榈/糖/可可/渔业）、权益映射（A 股/港股/美股 + ETF + Panama/水电/保险渠道）、宏观二阶（通胀/利率/汇率/财政）及政策响应，**持续监测超强事件的商品与权益定价错配与尾部风险**。**与上游主题的关系**：宏观 regime 与利率路径见 global-macro，日度市场情绪与交易信号见 market-daily，能源供需与水电/航运见 energy，地缘与产区出口管制见 geo-conflicts，不重复上游细节，聚焦 ENSO 自身的跨层传导链与投资主线。

## 分析框架

- **科学层** — ONI/RONI/周度 Niño 3.4/SOI、预报一致性（NOAA/CPC/IRI/BOM/JMA 四源）、EP-type 形态判定、峰值窗口 OND 与滞后 6-12mo 定时
- **商品层** — bg_db821d28 4 矩阵（棕榈 -20% / 糖 India/Thailand -30% / 可可 every strong cut / 渔业 Peru -36%）+ 逻辑链（ENSO 强度 → 天气异常 → 产量/物流 → 价格 → 库存去化）
- **权益层** — A 股/港股/美股映射表 + ETF（DBA/CORN/WEAT/JO/COCO）+ Panama/水电/保险三渠道 Watchlist，区分产区股 vs 消费股 vs 航运 vs 保险
- **宏观层** — 通胀路径（CPI 滞后 2-3 季度）、利率与汇率（美联储/产区央行二次定价）、财政与政策响应（出口管制/灾害救助/航运补贴）、水电/航运/保险渠道量化
