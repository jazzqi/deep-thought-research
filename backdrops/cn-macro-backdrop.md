# 中国宏观背景文档 (CN Macro Backdrop)

> 最后更新：2026-10-27 | 维护者：zhou_jintao  
> 用途：团队共享参考文档，为所有涉及中国宏观分析的 Agent 提供最新背景基准（偏重市场体感与周期穿透，剔除修饰性表述）

---

## 1. 总体态势：名义底部震荡，"输入性通胀 + 内需通缩"并存（2026-10 下旬复核）

2026年中国宏观经济在"内需长周期筑底"与"外需高位抵抗"的拉锯中运行。官方大盘实际GDP增速（上半年4.7%）虽在目标区间内，但微观体感（名义增速与利润率）明显弱于实际增速。三季度GDP及10月中旬"数据大礼包"（社融、PMI、工业、消费、投资）已于10月中旬公布，本环境暂未接入具体数值——**涉及三季度增速的判断需先核数，勿沿用旧值**。

* **物价结构（2026年4月起质变，10-27复核仍成立）**：PPI同比连续6个月转正——4月+2.8%、5月+3.9%、6月+4.1%、7月+3.5%、8月+3.8%、9月+3.8%；而CPI仅+0.8%。这是**成本推动的输入性通胀**（布油100美元上下、EIA对2026年Brent均价预估91.01美元/桶、全球商品超级周期脉冲），而非需求拉动。PPI-CPI剪刀差约+3pp且为正向——上游资源品利润修复，中下游制造毛利受挤压。旧叙事"中国深陷通缩"需修正为"**内需通缩 + 上游输入性通胀的结构性分化**"。
* **名义与实际GDP的平减指数**：核心矛盾仍是GDI（国内总收入）和企业真实利润回吐。除上游资源品外，大部分行业仍呈"量增价跌"、微观高度"内卷"的特征。
* **就业与内需物价**：城镇调查失业率失真度较高，16-24岁青年就业压力、白领降薪及中年危机向消费端传导。CPI在0-1%低位徘徊——上游涨价尚未传导至终端，说明终端需求疲弱、提价能力缺失。
* **全球康波周期定位**：全球处于第五波康波的衰退末期至萧条初期。按经典长波节奏，萧条期前后常伴随商品超级周期的脉冲（资源约束+货币体系重估）——本轮布油100美元与PPI转正即此类脉冲的体现。旧的万物互联红利见顶；中国作为全球最大制造国，正承受全球总需求放缓、跨国供应链"去风险化"以及资本回报率下降的系统性压力。**外部货币环境**：美联储处于加息周期（主席沃什，2026年9月加息25bp），10月FOMC（10-27/28召开）决议在即——会前市场预期按兵不动约8成；12月再加息预期约6-7成。中美政策周期背离，人民币与资本流动压力构成国内宽松空间的外部约束。

## 2. 新旧动能转换：新动能"赚量不赚钱"，旧动能仍在"失血"，但政策在加速押注新动能

"新质生产力"在顶层设计上是核心，但从资本市场和企业生存角度看，仍处于"青黄不接"的残酷阵痛期；不过10月以来政策对新兴赛道的扶持密度明显上升。

* **战略新兴产业的"产能过剩"与陷阱**：AI、新能源汽车、光伏及锂电等高技术制造业增加值增速虽快，但由于资本过度涌入和地方政府补贴扭曲，全行业陷入价格战和利润率恶化。新动能创造了产值和就业，但"尚未形成全社会可持续的微观利润"。反内卷/供给侧限产政策仍是修复利润率的主要政策工具。
* **10月政策新脉冲（信号面，注意这是主题炒作与产业政策的混合体，勿直接等同于基本面改善）**：① 机器人行动方案落地，概念股大涨；② 国家数据管理局提出探索 Token 交易等数据要素新型交易模式；③ 核电核准加速——核能/核电概念集体涨停，多地核能项目迎建设运营"双峰"；④ 两部门政策利好消费电子，A/H 联动上涨。产业政策方向明确指向"AI+机器人+数据要素+核能"的新型capital开支叙事，属于朱格拉中周期换代投资的政策催化。
* **AI产业的S曲线尴尬**：算力投资（大模型、服务器、数据中心）在政府和巨头合力下录得高增长，但商业化落地依然处于S曲线的中下部，尚未引发全行业的生产率革命。
* **旧动能（房地产/传统基建）：核心城市出现企稳行为样本，但全局底部未确认**。政策端"现房销售新政"正在重塑开发商拿地行为；核心城市土地联合拿地成为主流，部分地方国企积极补位拿地；"银十"冲刺下开发商抢旧规窗口期。这些是**核心一二线城市边际企稳的领先行为信号**，但房企信用链条断裂的后遗症仍向城投、地方中小金融机构蔓延，全局新稳态未至。

## 3. 结构性不平衡：供需错配，资产负债表防御；外需出现"抢出口"扰动

市场最核心的撕裂点在于"生产端的强韧性"与"需求端的防御性"严重失衡。

【强韧端】出口景气度 + 政府基建投资 + 上游涨价利润修复 ──► 维持基本面"量"的下限
                                           ▲
                                           │ (严重供需错配)
                                           ▼
【偏弱端】居民缩表 + 民间投资资本退潮 + 中下游毛利挤压 ──► 维持微观体感"价"的流失

* **外需**："夹缝出海" + **新增"抢出口"扰动**。花旗指出特朗普新关税预期促使亚洲提前发货（front-loading）——这会在关税落地前人为抬高中国出口读数，形成"虚高的外需韧性"，分析出口数据时务必剥离抢出口效应，否则会误判内需真实温度。欧美全面高关税和地缘壁垒下，利润正向海外本土化工厂转移，国内总部仅留存微薄供应链溢价。
* **内需**：居民部门"预防性储蓄"演变为"主动缩表"。房价下跌的负财富效应叠加收入预期恶化，导致居民减少杠杆、提前还贷。消费呈现"下沉消费"与"情绪消费"并存，传统大宗消费全面疲软。CPI仅+0.8%即是终端需求疲弱的直接证据。
* **投资**：民间投资意愿处于历史低位。缺乏明确暴利赛道，民营企业家以"保现金流、防踩坑"为主，固定资产投资靠国央企和专项债托底；但注意上文产业政策脉冲（机器人/核能/数据要素）可能在局部制造新的国资+龙头联合资本开支热点。
* **新增维度：输入性成本冲击**。上游PPI+3.8%而中下游CPI+0.8%，中下游制造与消费板块承受"成本上行、提价不能"的双重挤压；只有资源品、煤炭、油气、部分化工上游直接受益于涨价。
* **金融监管补丁**：民营银行异地存款收紧（存量产品限制新增、属地化整改倒计时）——压降高息负债成本，客观上是稳银行净息差、但进一步抑制中小银行揽储竞争的信号。

## 4. 政策框架：在"稳债务"与"刺激经济"的既要又要中走钢丝

宏观调控已彻底告别大开大合的"强刺激"迷恋，政策出台具有极强的阶段性、补丁式和克制性。

* **财政政策**：以"化债"为主旋律，防范系统性风险。中央对地方债务约束严格，地方核心精力在化解隐性债务、应付"三保"。基建投资边际效果大打折扣。地方财政发力呈"碎片化产业补贴"特征：如重庆等地对低空经济给予真金白银支持、山东十五五规划改造老旧小区加装电梯等——是"补产业、补存量"而非"大基建重启"。
* **货币政策**：陷入"流动性陷阱"与传导受阻。尽管多次降准、下调LPR和存量房贷利率，但资金滞留金融体系内部（M2高企但M1低迷，社融结构中企业中长期贷款意愿弱）。**新增约束**：美联储加息周期 + 布油100美元输入性通胀，压缩央行大幅宽松空间——"宽松无力"与"不敢宽松"并存。
* **反内卷政策落地**：通过环保、能耗、价格反垄断等刚性手段强行限制恶性价格战，通过供给侧被动出清修复行业利润率。PPI转正部分受益于此供给侧逻辑。
* **资本市场态度**：政策利好密集催化下A/H风险偏好明显回暖（消费电子、AI、核能、创新药轮动上涨，甚至出现"利好出尽卖—反转—涨停"的高波动博弈），"政策牛/主题牛"特征压过基本面驱动——分析A股时需区分"政策叙事驱动的估值扩张"与"盈利驱动"。

## 5. 更新触发条件与动态观察指标

所有 Agent 在执行分析时，若发现以下高频或结构性指标发生突变，必须触发逻辑重估：

### 5.1 信用与物价（核心领先指标）：
* **M1 增速是否拐点向上？**（判断企业活跃度和内生动力复苏的最关键指标）
* **PPI-CPI剪刀差的方向反转**：当前PPI约+3.8%、CPI约+0.8%，正剪刀差约+3pp。需观察：(a) PPI涨价向CPI的传导是否启动（需求终于跟上）；(b) 还是PPI因全球商品回落而重新转负（输入性通胀脉冲结束）。两种情形的资产含义完全相反——前者利好中下游毛利修复，后者重回通缩叙事。
* **三季度GDP及10月中旬数据大礼包的落地数值**（本环境未接入，下次更新必须补齐核数）。

### 5.2 政策底线转换：
* **政治局会议**是否出现对"民间资本"或"数字经济/平台经济"的实质性松绑信号
* **中央财政是否直接向居民端大规模发放消费券或现金**（政策从"补生产"转向"补消费"）
* 输入性通胀是否倒逼政策转向"保供稳价"（行政手段压上游价格）
* 房地产：现房销售新政推广节奏、核心城市地价是否趋势性回稳（当前联合拿地+地方国企补位是领先样本）

### 5.3 外部地缘与商品冲击：
* **布伦特原油是否站稳/跌破100美元**——输入性通胀脉冲的源头
* **特朗普新关税的落地节奏与亚洲抢出口的持续性**——抢出口透支的是2027年上半年的外需，需警惕数据虚高后的断崖
* **10月FOMC决议（10-27/28）及12月加息路径**对人民币汇率与资本流动的传导；会前市场预期10月按兵不动约8成
* 美国9月CPI已于10-14公布（本环境未接入具体数值，待核）——若通胀超预期回升，12月加息概率上修，对A/H外部流动性构成二次压力

## 6. 使用指南

1. **Agent 分析审查**：在评估具体行业（如科技、消费、制造）时，禁止使用"随着经济复苏……"等假设。必须假设当前处于"L型筑底 + 上游涨价挤压中下游"的存量博弈环境。**不要引用"中国处于单边通缩"的旧框架**——2026年4月起PPI已转正，正确表述是"内需通缩 + 输入性通胀并存"。
2. **出海逻辑优先**：分析企业成长性时，需重点拆解"真实全球化出海（海外获利能力）"与"国内产能降本"的双重能力；并剥离抢出口带来的短期出口虚高。
3. **产业链位置决定涨价受益度**：PPI转正环境下，上游资源品利润修复、中下游毛利承压——行业分析必须区分产业链位置，勿将PPI转正笼统解读为"企业利润整体改善"。
4. **区分政策叙事与基本面**：10月以来机器人/核能/数据要素/消费电子的政策催化密集，信号面证实率数据提示 policy_regulation 类高优先级信号证实率仅约36%——引用此类信号支撑行业判断时需降权，回归订单、产能利用率、利润率等硬数据。

## 7. 数据时效说明

* **当前截点（2026-10-27）**：物价数据截至2026年9月（PPI同比+3.8%、CPI同比+0.8%，4月以来连续第6个月PPI转正）。全球背景：EIA 10月月报对2026年Brent均价预估91.01美元/桶、WTI 84.65；美联储9月加息25bp，10月FOMC（10-27/28）决议在即、会前预期按兵不动约8成，12月再加息预期约6-7成。政策与市场面已纳入10月中下旬信号（现房销售新政重塑拿地、机器人行动方案、数据要素Token交易探索、核电核准加速、特朗普新关税引发亚洲抢出口、民营银行异地存款收紧）。
* **待核数据（下次更新必须补齐）**：① 中国三季度GDP及10月中旬数据大礼包具体数值；② 美国9月CPI具体数值（10-14已公布）；③ 10月FOMC决议结果（本周内落地）。
* **下次全面更新**：2026-11-10 前后（补齐三季度核数 + FOMC结果 + 10月中国物价数据发布后复核全篇）。
