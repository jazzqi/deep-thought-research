# 中国宏观背景文档 (CN Macro Backdrop)

> 最后更新：2026-10-12 | 维护者：zhou_jintao  
> 用途：团队共享参考文档，为所有涉及中国宏观分析的 Agent 提供最新背景基准（偏重市场体感与周期穿透，剔除修饰性表述）

---

## 1. 总体态势：名义底部震荡，"输入性通胀 + 内需通缩"并存（2026-10 关键更新）

2026年中国宏观经济在"内需长周期筑底"与"外需高位抵抗"的拉锯中运行。官方大盘实际GDP增速（上半年4.7%）虽在目标区间内，但微观体感（名义增速与利润率）明显弱于实际增速。

* **物价结构发生质变（2026年4月起）**：PPI同比已连续6个月转正——4月+2.8%、5月+3.9%、6月+4.1%、7月+3.5%、8月+3.8%、9月+3.8%；而CPI仅+0.8%。这是**成本推动的输入性通胀**（布油100美元上下、EIA对2026年Brent均价预估91.01美元/桶、全球商品超级周期脉冲），而非需求拉动。PPI-CPI剪刀差约+3pp且为正向——上游资源品利润修复，中下游制造毛利受挤压。这与2025年"PPI长期负值、通缩单边"的格局已根本背离，旧叙事"中国深陷通缩"需修正为"**内需通缩 + 上游输入性通胀的结构性分化**"。
* **名义与实际GDP的平减指数**：核心矛盾仍是GDI（国内总收入）和企业真实利润回吐。除上游资源品外，大部分行业仍呈"量增价跌"、微观高度"内卷"的特征。
* **就业与内需物价**：城镇调查失业率失真度较高，16-24岁青年就业压力、白领降薪及中年危机向消费端传导。CPI在0-1%低位徘徊——上游涨价尚未传导至终端，说明终端需求疲弱、提价能力缺失。
* **全球康波周期定位**：全球处于第五波康波的衰退末期至萧条初期。按经典长波节奏，萧条期前后常伴随商品超级周期的脉冲（资源约束+货币体系重估）——本轮布油100美元与PPI转正即此类脉冲的体现。旧的万物互联红利见顶；中国作为全球最大制造国，正承受全球总需求放缓、跨国供应链"去风险化"以及资本回报率下降的系统性压力。**外部货币环境注意**：美联储处于加息周期（主席沃什，2026年9月加息25bp，年底仍有加息预期），中美政策周期背离，人民币与资本流动压力构成国内宽松空间的外部约束。

## 2. 新旧动能转换：新动能"赚量不赚钱"，旧动能仍在"失血"

"新质生产力"在顶层设计上是核心，但从资本市场和企业生存角度看，正处于"青黄不接"的残酷阵痛期。

* **战略新兴产业的"产能过剩"与陷阱**：AI、新能源汽车、光伏及锂电等高技术制造业增加值增速虽快，但由于资本过度涌入和地方政府补贴扭曲，全行业陷入价格战和利润率恶化。新动能创造了产值和就业，但"尚未形成全社会可持续的微观利润"，无法靠自身造血完全对冲旧动能的缺口。反内卷/供给侧限产政策是当前修复利润率的主要政策工具。
* **AI产业的S曲线尴尬**：算力投资（大模型、服务器、数据中心）在政府和巨头合力下录得高增长，但商业化落地（C端/B端变现路径）依然处于S曲线的中下部，尚未引发全行业的生产率革命。
* **旧动能（房地产/传统基建）的新稳态未至**：房地产历经四年多调整，核心一二线城市价格仍在寻找底部。房企信用链条断裂的后遗症正向城投公司、地方中小金融机构蔓延。

## 3. 结构性不平衡：供需错配，资产负债表防御

市场最核心的撕裂点在于"生产端的强韧性"与"需求端的防御性"严重失衡。

【强韧端】出口景气度 + 政府基建投资 + 上游涨价利润修复 ──► 维持基本面"量"的下限
                                           ▲
                                           │ (严重供需错配)
                                           ▼
【偏弱端】居民缩表 + 民间投资资本退潮 + 中下游毛利挤压 ──► 维持微观体感"价"的流失

* **外需**：从"全面出口"转为"夹缝出海"。尽管中国出口韧性超预期，但面临欧美全面高关税和地缘壁垒，利润正在向海外本土化工厂转移，国内总部仅留存微薄的供应链溢价。
* **内需**：居民部门"预防性储蓄"演变为"主动缩表"。房价下跌的负财富效应，叠加对未来收入预期的恶化，导致居民减少杠杆、提前还贷。消费呈现结构性"下沉消费"（追求极致性价比）与"情绪消费"并存，传统大宗消费（汽车、高端奢侈品、耐用品）全面疲软。CPI仅+0.8%即是终端需求疲弱的直接证据。
* **投资**：民间投资意愿处于历史低位。缺乏明确的暴利赛道，民营企业家以"保现金流、防踩坑"为主，固定资产投资几乎全靠国央企和专项债托底。
* **新增维度：输入性成本冲击**。上游PPI+3.8%而中下游CPI+0.8%，中下游制造与消费板块承受"成本上行、提价不能"的双重挤压；只有资源品、煤炭、油气、部分化工上游直接受益于涨价。

## 4. 政策框架：在"稳债务"与"刺激经济"的既要又要中走钢丝

宏观调控已彻底告别大开大合的"强刺激"迷恋，政策出台具有极强的阶段性、补丁式和克制性。

* **财政政策**：以"化债"为主旋律，防范系统性风险。中央对地方政府的债务约束极其严格，地方政府的核心精力在"以时间换空间"化解隐性债务、应付基层"三保"（保工资、保运转、保基本民生）。因此，基建投资边际效果大打折扣，部分地区甚至出现基建停工现象。
* **货币政策**：陷入"流动性陷阱"与传导受阻。尽管央行多次降准、下调LPR和存量房贷利率，但资金大量滞留在金融体系内部（M2高企但M1低迷，社融结构中企业中长期贷款意愿弱）。微观主体（居民与企业）缺乏借贷意愿，货币乘数下降。**新增约束**：美联储加息周期 + 布油100美元输入性通胀，客观上压缩了央行进一步大幅宽松的空间——"宽松无力"与"不敢宽松"并存。
* **反内卷政策落地**：政策层面开始通过环保、能耗、价格反垄断等刚性手段强行限制恶性价格战（如限制光伏、锂电盲目扩产），试图通过供给侧被动出清来修复行业利润率。PPI转正部分受益于此供给侧逻辑。

## 5. 更新触发条件与动态观察指标

所有 Agent 在执行分析时，若发现以下高频或结构性指标发生突变，必须触发逻辑重估：

### 5.1 信用与物价（核心领先指标）：
* **M1 增速是否拐点向上？**（这是判断企业活跃度和内生动力复苏的最关键指标）
* **PPI-CPI剪刀差的方向反转**：当前PPI约+3.8%、CPI约+0.8%，正剪刀差约+3pp。需观察：(a) PPI涨价向CPI的传导是否启动（需求终于跟上）；(b) 还是PPI因全球商品回落而重新转正为负（输入性通胀脉冲结束）。这两种情形的资产含义完全相反——前者利好中下游毛利修复，后者重回通缩叙事。

### 5.2 政策底线转换：
* **政治局会议**是否出现对"民间资本"或"数字经济/平台经济"的实质性松绑信号
* **中央财政是否直接向居民端大规模发放消费券或现金**（即宏观政策从"补生产"转向"补消费"）
* 输入性通胀是否倒逼政策转向"保供稳价"（行政手段压上游价格）

### 5.3 外部地缘与商品冲击：
* **布伦特原油是否站稳/跌破100美元**——输入性通胀脉冲的源头
* **对非美市场（东盟、拉美）的关税壁垒**是否出现连锁反应
* **美联储加息路径**（10月FOMC按兵不动预期约8成，12月再加息预期约6-7成）对人民币汇率与资本流动的传导

## 6. 使用指南

1. **Agent 分析审查**：在评估具体行业（如科技、消费、制造）时，禁止使用"随着经济复苏……"等假设。必须假设当前处于"L型筑底 + 上游涨价挤压中下游"的存量博弈环境。**注意：不要再引用"中国处于单边通缩"的旧框架**——2026年4月起PPI已转正，正确的表述是"内需通缩 + 输入性通胀并存"。
2. **出海逻辑优先**：鉴于国内内卷加剧，分析企业成长性时，需重点拆解其"真实全球化出海（海外获利能力）"与"国内产能降本"的双重能力。
3. **产业链位置决定涨价受益度**：PPI转正环境下，上游资源品利润修复、中下游毛利承压——行业分析必须区分在产业链的位置，勿将PPI转正笼统解读为"企业利润整体改善"。
